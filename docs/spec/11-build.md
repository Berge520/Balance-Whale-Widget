## 十一、构建与自测

1. `npm install`；`npm run dev`（Vite watch，构建到 `dist/`）配合 uTools 开发者工具入口选 `dist/`。**`plugin.json` 不含 `development` 字段**，按正常模式加载目录，开发态与发布态同源；改 `src/` 后 watch 自动重建，重载即可。
2. 改 preload 后必须在 uTools 里重载插件（不热更，`lib/*.js` 同理）。
3. 类型检查 `npm run typecheck`（`vue-tsc --noEmit`）。
4. 单测：`npm test`（Node 内置 `node --test`，零依赖，用例在 `test/*.test.mjs`，**清单与项数以 `test/` 实际内容为准**）。覆盖**二十一组**，一至十一组同一条主链（余额 / 用量 / dsh 管理）：前四组是「算错 / 取错不报错，只把钱显示错」：`lib/pricing.js`（峰谷判定 / 切换时刻 / 模型定价 / 自定义单价与按模型覆盖的子串命中）、`lib/api.js`（`pickBalanceInfo` 多币种优先级、`pickPath` 路径语法、`pathNum` 区分 0 与空）、`lib/store.js`（`normTokenPrice` / `normPriceModels` / `normBubbleSystem` / `normBubble`）、`lib/backup.js`（`_encryptSecrets` / `_decryptSecrets` / `applyBackup`：往返一致、salt/iv 每次新生成、错密码与改一位密文必失败、旧明文备份能解、坏结构报「没有可用的凭据」；另钉 `applyBackup` 写入结果判定（§十二 B11/B12），挂 `utools` 桩 + `failWrite`，走真实入口 `pickBackup`；config / ledger / window / timer 四项先验进 `applied`、再验写失败进 `errors` 且 `ok:false`：写入函数都不抛错，只能判返回值）；第五组 `lib/hosts.js`：`normSources` 剥 `community:` 与顺序归一化、`normCustomSources` URL 校验 / 去重 / 上限、`srcChainLabel` 按开关与顺序生成标题（标题不许写死来源链）；**第六组 `lib/util.js`**：`homeDir` 保守合并（`expand` / `relative` 默认 false）、**`os.homedir()` 抛错不掀候选表**（清空 `USERPROFILE` 会抛；早先返回空串被读成「没配 `DSH_HOME`」）、`dayKeyFromTs` / `dayAdd` 时区与跨月跨年、`num` 区分 `null` / 空串 / 非数字、`readTextSafe`（仅 `ENOENT` / `ENOTDIR` 静默，其余 `logErr` 并回报 `reason`）、`walkDir` 上限、`normalizePath`；**这组刻意不挂 `utools` 桩**（引 `log` / `utools` / `constants` 会在 `require` 阶段炸）；**第七组 `lib/diagnostics.js`**：`severestLevel` / `severityOf` 分档、`orderResults` 按 severity 倒序、`scanPatchLines` 只认 `- id: X`、`sameFingerprint`（同包同版本 error、不同版本 warn）、`extractPatchIds` / `dshNotFoundIds`（拿不到 dump 必须回 `null` 走「无法判定」，不得退化成「没问题」或「全对不上」）、C5 降级（探测失败 → warning + reason，不让整轮 `ok:false`；单项抛错标 `threw`，不影响其余）、`looksLikeDsh` 三态（含 dsh → true；真实 `npm-cli.js` / `vite.js` / 裸 `node -e` → false；拿不到 → null）、`portDsh`（`false` → `[✗]` 被非 dsh 占用、`null` → `[!]` 无法判定；同名不同 `portDsh` 须从 `[✓]` 变 `[!]`）；**第八组 `lib/dsh-backup.js`**：钉四个静默失效约定：白名单（快照目录只有 manifest + 三个受管文件，不含凭据串）、sha256 自校验（篡改后还原必失败）、整文件覆盖（还原后逐字等于快照）、缺文件是预期分支（建快照 `ok:false` 不算失败；还原跳过不建空文件）；另含穿越防护（`../x` / `a/b` / 空串拒）、坏 manifest 容错、`pruneSnapshots` 保留最新 N 份、同秒连建不撞名、列表 `dirName` 以磁盘目录名为准（manifest 改成 `../evil` → 误删完好快照）；追加：`keep` 配额不被固定项侵占、`meta.json` 与 `manifest.json` 分离、`setMeta` 部分更新、`before-*` 改名不免死（否则关掉轮转）、`_isPinned`、名字截断与空白折叠、`meta` 清空即删、`retentionKeep` 回落 20、`protectPinned:false` 退回纯列表计数；**第九组 `lib/dsh-patch.js`** 覆盖 `parsePatch` / `applyToggle` / `validId` / `disabledValue`，钉「只动一行」（行数不变 + 唯一 diff 行，重排 / 重序列化都被抓住）、`disabled:` 归属（归上方最近 `- id:`，`config:` 子块缩进不误判）、已有 `disabled:` 行沿用原缩进改值、条目在但无 `disabled:` 时插在 `id` 之后、条目不存在时末尾追加（不以换行结尾先补，避免两行粘连）、非法 id 全拒（换行 / Tab / `#` / `-` 开头 / 超长等 8 种）、CRLF 保持、幂等（重复设同一状态返回 `noop`，逐字不变）；**第十组 `lib/dsh-isolate.js`**：①–④ 组 `applyBatchDisable` 落笔（只动该动的行 / 新增条目 / **行号不错位** / 非法 id、CRLF、幂等、注释保留）、⑤ 组 `candidatesOf` 并集与顺序（**patch 先、plugin 后**，`patchItems` / `patchIds` 两种写法都进候选）、⑥ 组 `selectBatch` 缺省全选 / 显式勾选 / 超 `MAX_BATCH` 截断与 `dropped` 计数、⑦ 组分档与三态：`tierOfBundle`（`@deepseek-ai/` 作用域与白名单算 `core`；**`dsh-` 前缀不判官方**（第三方大量占用）；判不出算 `third`，钉「宁可不折叠也不把插件藏起来」）、patch 条目无条件归 `patched`、排序 `patched → third → core`、`hasConfig` 不再硬编码 `false`、**候选不再截断**、没给 `disabledOf` 时 `disabled` 必须是 `undefined`（未知）而非 `false`（三态可区分）；另钉四类静默失效：**行号错位**、一次改完再落盘（逐字比对而非只比行数）、非法 id 整批拒绝（不得写一半）、勾选项不被截断静默丢弃（先保勾选再截断，如实报 `dropped`；否则勾了不生效，回归 §十二 B9）；**第十一组 `lib/dsh-dump.js`**：dump 分层解析、层内去重与截断、D2 差异（**只列 config 的 key，绝不写取值**）；**第十二组 `lib/dsh-market.js`**：`parseInstallSpec`（剥 shell 引号，不剥即 404）、`specKindOf` 三分类、`specNeedsBuild`（**只有 github / tarball 需构建**）、`normCatalog`、`filterPlugins` 的**「状态读不到就整条跳过」**：`state` 非 `all` 且未安装即 `continue`，不得把未知冒充「未安装」、`installedMap` / `matchInstalled` / `matchInstalledBySpec` / `matchDepByNpm`（**两种入参形状不能混用**：原始表喂 `matchInstalled` 会让 `depVersion` 恒 undefined 而静默失效；候选键含 spec 原文、去 scope 短名、`owner/repo` 与 `repo`、tarball 文件名去扩展名与去版本）、`updateState`（三参 `depVersion` / `catalogVersion` / `realized`，**优先比实装**，返回带 `range` / `basis`）、`realizedVersionBySpec`、`untarOne`（手写 512 字节 tar 头，只找 `package/plugins.json`）；**第十三组 `lib/dsh.js` 的 `validPkgSpec`**（放行

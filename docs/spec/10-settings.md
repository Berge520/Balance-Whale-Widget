## 十、设置页（src/）

**深浅色由 `uiMode` 合成（判定源 `utools.isDarkColors()`）**：`auto`（默认）跟随 `utools.isDarkColors()`，`light`/`dark` 手动固定（兼作 `isDarkColors()` 异常时的逃生门），`fantasy`（未至之境）恒为暗色并额外挂 `<html>` 的 `fantasy` 类供主题令牌覆写；生效值切 `<html>` 的 `dark` 类，`main.css` 与 App.vue scoped 的深色规则**全部**以 `html.dark` 为前缀。判定源**不跟系统** `prefers-color-scheme` —— 否则「系统暗 + uTools 亮」恒为暗色，用户以为主题坏了。uTools 无主题变更事件，只能轮询（同步布尔读，开销可忽略）：App.vue 启动即应用并 1s 轮询，`onUnmounted` 清定时器。「外观」卡「界面深浅色」下拉（跟随 uTools / 浅色 / 深色 / 未至之境）走 `onUiModeChange` 本地立即应用再落库 —— 等轮询 / 回推才变会让人以为没生效；挂件菜单不加该行（7 行已满且极低频）。非 uTools 环境（类型检查 / 浏览器预览）`isDarkColors()` 抛错，按浅色处理。背景氛围走 `config.bgMode`（`off` / `deep` / `aurora` / `stars` / `mist` / `polar` / `warm` / `video` / `custom`），类挂在 `<html>`，深色与未至之境走 `html.dark.bg-*` 深海配色、浅色走 `html:not(.dark).bg-*` 淡彩配色，不再限定 fantasy；「设置页视觉」卡提供背景画廊（九张缩略卡，替代下拉），默认 `off`。前三种纯 CSS/内置素材；`video` 需用户点「下载视频壁纸」（约 6.3 MB，CC BY-NC-SA 4.0）；`custom` 从「资源 → 背景与片头」导入的本地图片/视频中选择。`bgScrim` / `bgBlur` / `bgBrightness` / `bgVignette` 控制遮罩、模糊、亮度、暗角；自定义媒体另支持 `bgFit` / `bgFocusX` / `bgFocusY` / `bgZoom` 和「智能适配」。背景视频选中即尝试播放（减少动态效果只影响启动片头）；自动播放被拦或解码失败时框内有常驻的「播放 / 重新播放」按钮，并显示失败原因。下方「启动片头」开关（`config.bootIntroOn`，默认关）控制设置页首次打开时的片头，来源 `bootIntroSource`（auto/media/css）；「纯净播放」`bootIntroClean` 开启时片头期间隐藏 `#app`（所有 Tab/卡片），首帧由 index.html 预涂 `boot-intro-pending`，退场时先恢复设置页；`bootIntroConsume()` 在宿主进程内消费，保证每次插件启动只自动播一次；「预览片头」不受该限制；旁边「系统动画设置」调用 `openSystemAnimationSettings()` 打开系统动画页（Win10 `ms-settings:easeofaccess-display` / Win11 `ms-settings:easeofaccess-visualeffects`）。

**Tab 默认顺序 = 使用频率**：外观（冷启动落点）→ 用量（余额 / 模型 / 通知 / 专注）→ 资源 → 数据（凭据 / 备份）→ 窗口 → 帮助 → 开发者。用户可在显示管理里自定义顺序（`cfg.tabOrder`），默认顺序只决定首次 / 恢复默认时的排列；`test/display.test.mjs` 钉住这份顺序。窄窗口下 Tab 行**换行**而不是横向滚动（隐藏滚动条会让「帮助 / 开发者」永远看不见）；每组 Tab 的 `title` 标出 `Ctrl+1..7`，键盘可直达当前可见分组。切组（点击 / 快捷键 / 隐藏当前组后的自动跳组）一律回到页面顶部，避免停在上一组的滚动位置；深链定位卡片（挂件菜单「气泡设置」/「计时设置」、外观页「去挑形象」等）仍由各自的 `scrollToCard` 滚到目标卡。设置页还会用 `localStorage`（`whale:lastTab`）记住最后停留的分组，重开设置页 / 重启插件后回到原位置；值非法或读取失败时回「外观」。

**副标题（`.tab-desc`）与卡片名必须对得上**：`.tab-desc` 只列**真实存在的卡片**、用卡片标题（`<h2>` / `.fold-title`）的原词，顺序与渲染顺序一致 —— 写「组内分区」或已下线的卡名，用户照着找找不到。唯一例外是资源组：desc 按「我的素材 / 下载素材」分区写（模板顺序里形象排在气泡图前，但分区展示时归到下载素材），与 `TABS.assets.desc` 一致。`TABS` / `SEARCH_INDEX` / `CORE_CARDS` / `CORE_TABS` / `CARD_DEPENDENCIES` 定义在 `src/constants/display.ts`（供 `App.vue` 与 `DisplayManager.vue` 共用），**本表抄的是 `TABS` 的 `label` / `desc` 原词，只是镜像；改 Tab 以该文件的 `TABS` 为准，写死必漂移。**

**自定义显示（降噪）**：Tab 栏右侧的「⚙ 显示管理」按钮（`.display-manager-btn`：文字用 `--fg`、虚线边框 `--fg-faint`，不用 `--fg-dim` / `--line` —— 12px 小字压在深色 `--bar-bg(#303133)` 上会暗到看不出是按钮）打开 `DisplayManager.vue`（Teleport 到 body 的居中弹窗，点遮罩 / 按 Esc / 右上 `×` 关闭；搜索框有内容时 Esc 先清搜索、再按才关）。弹窗按 Tab 分组列出复选框，勾掉即写 `cfg.hiddenTabs` / `cfg.hiddenCards`（见 §六 `06-storage-config.md`），并支持：**分组排序**（每组标题行 `↑` / `↓` 改 `cfg.tabOrder`，基于完整 Tab 顺序交换、含已隐藏组；排序结果同时作用于主界面 Tab 条与弹窗内列表）、**分组级「全显示」**（只放出本组卡片）、**搜索过滤**（按卡片名 / 关键词过滤，同时匹配 Tab 名）、**顶部计数**（共 N 张 / 已隐藏 N 张 / N 个分组被整体隐藏）、**底部「全部显示」与「恢复默认」**（恢复默认在弹窗内二次确认，不用原生 `confirm()`；「恢复默认」清 `tabOrder` / `pinnedCards` / `cardOrder` / `foldDefaults` 并把 `foldRemember` 复位 true（「回到刚装好时的样子」，只清隐藏等于只恢复一半），「全部显示」只清两个隐藏列表 —— 用户只是想把藏起来的放出来，没说顺序也重来）。三条约束：① **核心卡片不可隐藏** —— `CORE_CARDS`（`credentials` / `window` / `look`）在卡片列表里恒显示为已显示且不可勾；② **含核心卡片的 Tab 不可整体隐藏** —— `CORE_TABS` 由 `CORE_CARDS` 反查 `SEARCH_INDEX` 得出，不另抄一份名单；`App.vue#applyConfig` 回填配置时还会再从两个隐藏列表 / 顺序表里剔掉非法 id（老备份 / 手改配置可能带着）；③ **搜索兜底** —— 搜索结果里命中的隐藏卡片标「已隐藏」并给显式「显示」按钮（点击发 `{type:'card', hidden:false}`）；`App.vue#unhideCard()` 则是卡片和它所属 Tab 一起放出来（只放卡片、Tab 还藏着的话仍然渲染不出来）。`devOnly` 的「开发者」Tab 在未配置 dsh 时整组禁用（勾了也没有内容）。**卡片置顶**：每张卡有「📌 置顶」开关，写入 `cfg.pinnedCards`（字符串数组，顺序 = 用户点击置顶的先后），勾上即在该卡所在 Tab 内排到最前、左侧加一条强调色竖条（`.card-pinned`）；取消置顶后落回「卡片顺序」里的位置（清掉内联 `order` 即回到该卡在 `cfg.cardOrder` 中的位次）。**卡片拖拽调序**：每行左侧有 `⋮⋮` 手柄（`.drag-handle`），拖到另一行即插到该行之前，写 `cfg.cardOrder[tabKey]`（**只存非置顶卡** —— 置顶卡由 `pinnedCards` 单独排，混存会让「取消置顶」的卡跳到最前，与「回到原来的位置」矛盾）；置顶区与普通区**互不相通**（跨区拖不放行，要换区先加 / 取消置顶），搜索过滤态下不可拖（列表已不是真实顺序），与出厂顺序一致的组不落库（删键）。合并卡（计时 + 专注）只跟主卡一起动：`timer` 行不给手柄，落点按 `cardRootKey` 归一（拖到「计时设置」等于拖到主卡），`cardOrder` 里也按卡根去重，避免主界面再归一时落点错一格。**每卡默认展开 / 收起**：卡片行右侧「默认展开 / 默认收起」按钮写 `cfg.foldDefaults[foldKey]`（`foldKey` 见 `src/constants/display.ts#CARD_FOLDS`，合并卡共用 `focusTimer`），只对能折叠的卡显示；出厂默认值表 `FOLD_DEFAULTS` 与各 `useFold(key, defaultOpen)` 第二参由 `test/display.test.mjs` 扫源码钉死。**记忆开关**：搜索框下方的「记住每张卡上次的展开状态」写 `cfg.foldRemember`（默认开）；关掉后 `useFold` 既不读也不写 `localStorage` 的 `whale-fold-*`、全部回落到默认值，并清掉已存的折叠缓存（此时「默认展开 / 收起」按钮显示为减淡态，提示它才是实际生效的）。**排序只写 CSS `order`，不搬 DOM**：`.pin-scope` 是 flex 列容器（`.tab-desc` / 搜索区 / `.pin-head` 用更小的固定负 order 永远排在置顶块之前），`App.vue#syncPinned()` 只给当前 Tab 的**卡根**写 `order`（置顶卡 `PIN_ORDER_BASE = -1000`、多张置顶按点击先后递增；普通卡按 `cfg.cardOrder` 写 `CARD_ORDER_BASE = 10`、步长 `CARD_ORDER_STEP = 10`，该组没有自定义顺序就不写、保持 DOM（模板）顺序）。**跨组不行**（A Tab 的卡不能被置顶进 B Tab）—— 分组语义优先。**禁止用 `insertBefore` 搬卡根** —— v-if 分支靠注释锚点定位（`getNextHostNode` 取 `vnode.anchor || vnode.el` 的 nextSibling），把 Vue 管理的节点搬离锚点后，生产构建里切 Tab 会旧卡残留 / 重复（2026-11-02 真机事故：切哪一组都只看到「挂件外观 + 设置页视觉」，dev 不复现）。合并卡（计时 + 专注）按 `closest('.card')` 解析卡根，卡根挂的所有 `data-search` 都纳入判断（置顶任一子块 = 整卡提前）。`assets` 组的 5 张卡在 `AssetsView` 的外包容器 `.assets-scope`（同为 flex 列）里：`syncPinned` 给置顶卡根写负 order，并把容器本身也提前（取组内最小 order），否则负 order 只在容器内部生效。「我的素材」分区标题直接写在模板里（在卡之前），普通卡按 `cardOrder` 排（未自定义时保持模板顺序）、置顶卡（负 order）自然排到标题之上；`MINE_CARDS`（`assetsOverview` / `assetsMedia` / `assetsBubbles`）中任一被置顶时（非搜索态）标题**整块不渲染** —— 置顶卡必然紧贴「📌 置顶」那行，标题只能插在两者之间、把置顶块割裂成两段（搜索态下置顶不参与排序，标题照常显示）。**隐藏了当前所在 Tab 时**，`watch(visibleTabs)` 就近切到相邻可见组，并在 `.tab-desc` 位置给出回执（`displayFlash`，同一行兼作提示与报错显示）。

**弹窗的配色与状态提示**：面板底色一律走 `background: var(--input-bg)`、文字走 `var(--fg)`，与 `SkinCropper` / `SoundTrimmer` / `FirstRunGuide` 的 `.panel` 同源 —— **不要引用 `--bg`**（`main.css` 的 `:root` / `html.dark` 都没有这个变量，深色下会回退成白底 + 浅色字）；主按钮（「关闭」）与「确定恢复」写死 `#536ba9` + 白字，因为深色主题的 `--accent(#8aa4e6)` / `--err(#ff6b66)` 都偏亮，压白字对比不足（与 `main.css` 的 `.utils-primary` 同口径）。状态提示分三档、别混用：分组头「N 张已隐藏」（`--warn`，只数**单独**藏掉的卡，整组隐藏由「整组已隐藏」单独提示、不重复报数）；卡片行「已隐藏」徽标（`--warn`，与说明性的核心徽标同形不同色）+ 整行名字减淡（`--fg-faint`，仍保可读，不用 `opacity` 压到读不出）；卡片行右侧给显式「显示」按钮（比让用户去把整行可点的勾选框重新勾上直观）。搜索无结果时给「清空搜索」按钮。底部按钮分左右两组：「全部显示 / 恢复默认（含二次确认）」成组在左（勾掉越多越常来这儿点），「关闭」单独在右，中间 `margin-left:auto` 顶开，窄窗口换行不交错。

分组就是把 `v-if="cardOn('tab', 'key')"` 直接挂在每张卡片上（`cardOn` 普通态按 Tab 命中、搜索态按 `searchHits` 命中；不额外套容器层）。**渲染顺序由 `TABS` 数组的 key 决定，与模板源码位置无关** —— 不同组的卡片在模板里交错排布（「数据」凭据卡在最前、「帮助」关于卡在最后）。Tab 条 `.tab-bar` 吸顶（`position:sticky; top:0; z-index:5`），底色用 CSS 变量 `--bar-bg` —— **必须与 `src/main.css` 里 `body` 背景一致**（浅色 `#f4f4f4` / 深色 `#303133`），否则滚动时内容从导航下面透出来。


**背景与片头媒体库**：「资源」Tab 新增卡，导入图片（png/jpg/jpeg/webp/gif，≤10MB）与视频（mp4/webm，≤10MB），最多 20 项；文件落 `userData/whale-media/`，元信息 `whale:media`。列表可设为背景/片头或删除；删除正在使用的媒体时宿主把 `bgMode` 回退 `off`、`bootIntroSource` 回退 `auto` 并广播。图片缩略图由设置页 canvas 生成，视频不抽帧；媒体卡「预览」用带控件的 `<video>`/大图弹层直接查看；「清除未使用」会一并清掉没在用的媒体；媒体不随素材包导出。背景与启动片头收在「外观」Tab 的「设置页视觉」独立卡（与「挂件外观」各自显隐 / 置顶，默认收起），收起时显示当前背景/片头摘要。

## 八、悬浮窗页面（floating.css + floating-bubble.css + floating-page.js）

`floating.html` 只是薄壳（`<link>` 引 `floating.css` / `floating-bubble.css`，`<script src>` 依次 `bubble-render.js` → `offwork-core.js` → `floating-page.js`）。脚本为 IIFE + 幂等守卫 `window.__dshWhaleWidget`。资源相对路径 `./whale/...`。

- **共享气泡渲染器**：DOM 构建、`applyLines`、换图状态机 `setGifSrc`、字号自适应 `fitText`、gif 淡出计时的单一来源是 `src/bubble/bubble-render.js`（导出 `THEMES` / `BUBBLE_FONT` / `buildBubbleDom` / `createBubbleRenderer`）。悬浮窗不能用 ES module（file:// 硬约束）：`vite.config.js` 的 `buildBubbleRenderIife` 在 `closeBundle` 用 esbuild 打成 IIFE `dist/bubble-render.js`（不压缩、全局名 `window.BubbleRender`），`floating.html` 以普通 `<script>` 在 `floating-page.js` 前挂载；设置页直接 ESM import 同一源文件（`BubblePreview.vue`）：共享**源码**而非副本。渲染器不依赖页面状态：gif 失败文案与「气泡是否正开着」经 `gifFailLines` / `onGifError` 交页面；页面只做接线（`applyBubbleLines` / `fitBubbleText` / `resetBubbleFont`）与绑 click。三处副本由 `check-shared.mjs` 钉住：`BUBBLE_FONT` ↔ `.dshwv-label/amount/period/hint` 字号、`THEMES.default` ↔ `.dshwv-bubble` 变量默认值、`/ 1026` 除数 ↔ `--dshw-u`；气泡样式独立成 `floating-bubble.css`。

DOM：`.dshwv-root`（窗口内**居中**，四周留 `--whale-pad` 透明留白；贴左吸附时整体 `scaleX(-1)` 镜像）> `.dshwv-body`（Q 弹缩放）> `img.dshwv-img` + `.dshwv-bubble`（SVG + `.dshwv-gif` + `.dshwv-text` 三行）；`.dshwv-menu-btn` 三点按钮（穿透中加 `.dshwv-menu-btn-pass`）；`.dshwv-menu` **挂 body**（不在 root 内：全局透明度靠 CSS 变量同时作用于两者，不写内联 opacity）。`.dshwv-body` 内、`img` 之后还有两层装饰：`.dshwv-refresh-mask`（手动刷新的呼吸圈，`pointer-events:none`，挂 `.dshwv-refreshing` 时走 `box-shadow` 动画）与 `svg.dshwv-ring`（计时环形进度，`stroke-dashoffset` 控进度，专注/短休/长休由 JS 写 `--dshw-ring-color` 换色）。

- 命中测试：鲸鱼图画到 610×610 canvas，`getImageData` 读 alpha>10（左镜像时 x 翻转）；据此决定拖拽/穿透/光标。
- 拖拽：pointerdown 在鲸鱼上 → 记 `screenX/Y` 与 `clientX/Y`，立即上报 `drag-begin`（宿主进入拖拽冻结态）；移动按 `目标窗口左上角 = screenX − clientX0`（拖拽中恒定）rAF 节流上报 `drag-move`；位移平方 <9 判点击（开气泡 + 刷新），否则松手上报 `drag-end`。**`dragLock` 开启时不累计位移、不上报 `drag-move`、禁用滚轮缩放**（位置与大小都固定），松手仍按点击处理，窗口不动。
- **拖拽期窗口尺寸缓存**（`dragWinSize`）：`drag-begin` 读一次 `getSize()`，拖拽期复用，`drag-end` 清空：原先 `dragMoveTo` 每帧 `win.getSize()` 是同步 IPC 往返，而 `dragFrozen` 下尺寸恒不变。配套：工作区缓存 `dragWin`（跨屏才重算）、位置相同则跳过 `setPosition`。
- **拖拽位置只保留一条最简链路**：页面 rAF 节流上报（每帧最多一发），宿主在 `whale:drag-move` 处理器里**直接同步 `setPosition`**。**两个已推翻的方案，别再回头**：(a)「发一帧 → 等 ack → 再发下一帧」严格背压：直线甩动中间帧可丢，但**画圈时相邻帧方向完全不同、无可合并**，吞吐被单个往返锁死；(b) 宿主侧 `setTimeout` 自驱循环（~120Hz）apply 最新目标，与页面 rAF 形成**第二条节奏源**，`dragTarget` 为空也空转 tick，更卡。结论：任何「第二条节奏源」或「逐帧回执」都会变差。
- **拖拽冻结缩放**：拖拽期滚轮缩放与实时缩放一律冻结（滚轮在 `drag.active` 时 return，`sendLiveScale` 短路；宿主 `applyScaleToWindow` 见 `dragFrozen` 只记目标值）。修的是「拖动时不由自主变大、大小描述却不变」：拖拽难免带出滚轮（触控板尤易误触），而实时缩放**不写存储、不回推配置**，一触发就「窗口真变大、`scale` 停在旧值」。被冻结的最后一个目标在 `drag-end` 补做并持久化，**顺序排在吸附之后**（补做会写 anchor、推配置，颠倒会覆盖吸附结果）。
- **拖拽期间屏蔽 `contextmenu`**：左键按住时再按右键，系统**照样**派发 `contextmenu`，菜单弹出会打断拖拽。故 `contextmenu` 在 `drag.active` 时 `preventDefault` + `stopPropagation` 后返回；**只挡「正在拖」**，拖拽结束后右键唤菜单完全保留（透明留白区本不在鲸鱼命中范围）。
- 滚轮缩放：指针命中鲸鱼且非菜单内时 `wheel`（`passive:false` + `preventDefault`）按 `deltaY` 符号 **±1 档**（先 `snapNum(curScale)` 归到当前档，档位 1–`SCALE_STEPS`）改大小，`setScale(target,true,false)` 实时预览、停手 260ms 后 `setScale(target,false,true)` 持久化（参数是档位，不是倍率）；到 1/`SCALE_STEPS` 边界不再变更；`dragLock` 开启或拖拽中直接 return 不缩放。
- Q 弹：body `scaleY(.88) scaleX(1.05)`，origin `50% 100%`，`transform .22s cubic-bezier(.34,1.56,.64,1)`。
- 音效：press=Ya1/D1、release=Ya2/D2；按住松手与短按（press 末尾提前 100ms 接 release）两节奏；vol=0 静音；`new Audio` 失败静默。音色可切「自定义」（`soundSet:'custom'`）：音源来自宿主推送的 base64 data URL（`whale:init.sounds` / `whale:sounds`），**以按压音为准**，缺失时整体回退小黄鸭；释放音可缺（`releaseAudio = null`，松手静音）。
- **提醒音效**：`whale:sounds` 与 `whale:init.sounds` 共六个槽位 `press / release / low / budget / peak / pass` —— 前两段是「音色」，后四段是低余额 / 预算 / 峰谷 / 穿透各自的提醒音。与音色两点差别：① **留空时回落到内置提醒音**（`ALERT_FALLBACK` → `./whale/alert-{low,budget,peak,pass}.wav`，用户导入则优先用导入的）；② 播放**只看全局「音效开关 + 音量」，不受「音色」下拉影响**（选小黄鸭仍播导入的提醒音，选「自定义」也不连带静音）。页面侧 `customSounds` 是六个键**逐个显式写死**的对象（两处收、两处推），加槽位要手动核对 `lib/sounds.js` 的 `ROLES` 与这里两处。
- **随机台词组 / 点按队列 / 台词顺序（均已删除）**：早期按组加权抽签（`buildRandomGroups()` 装配 `config.quotes.groups`，默认六组权重 45/7/7/10/3/1），另有 `clickQueueOn`（`queueNext()`）与 `quoteMode`（`random` 加权 / `sequence` 顺序，`sequenceNext()` 循环）。**整套（`cfg.quotes.groups` / `clickQueueOn` / `quoteMode`）已随台词库删除**：总开关关掉时挂件改发 `cfg.bubble.system` 的 5 池固定文案（见第六节）；`clickQueueOn` 曾因拆卡漏摘成死开关，已清掉。气泡首行默认**报时**（`timeBubbleOn`，鲸鱼娘语气按时段变化），关闭后显示「DeepSeek 余额」。
- **台词占位符（已删除）**：曾由 `linePlaceholderValue(k)` 唯一取值，11 枚：`{balance}` / `{today}` / `{peak}` / `{next}`（DeepSeek 口径）+ `{countdown}` / `{change}` / `{model}` / `{currency}` / `{date}` / `{time}` / `{weekday}`；替换在抽到那一刻（`textGroupLines` → `renderLinePlaceholders`），**未提供的占位符原样保留**（同 `alertLines` 口径）。**随 `cfg.quotes` 删除**；固定文案池（`cfg.bubble.system`）与自定义泡泡模块**不解析占位符**。
- **自定义气泡图**：`img.dshwv-gif` 有自定义图时从 `whale:bubbles` / `whale:init.bubbles` 数组**随机抽一张**（`pickBubbleUrl()`，空数组回退内置 `./whale/rua.webp`），无「当前用哪张」，导入即参与随机、删光即回退。与内置图共用同一 `<img>`，`setGifSrc()` 用 `gifSrcSet` 记「原始 src」判断是否真要换图：`img.src` 读出来是绝对 `file://` URL，与 `./whale/rua.webp` 永不相等，不记一份就会每次重载（data URL 白解码）。加载失败 `onerror` **当场**换成「动图降级」文案（`bubble.system.gifFail`，经 `onGifError` 交页面）：此时气泡已切到「只显示图」，光记失败标记会留空白；换图时复位标记。
- **拖拽台词**：真拖拽松手（`endDrag` 非点击分支）且位移 ≥100px 时，按随机台词样式弹「被拖拽」台词（`DRAG_LINES` 四条，样式 A 自动换行，停留 `DRAG_QUOTE_MS` 7 秒，比随机台词 5 秒长）。三个刻意设计：① **阈值 100px** 不复用 `drag.moved`（3px 即置位）；② **60s 冷却**（`lastDragQuoteAt`），连拖只弹第一句；③ **优先级同提醒入口**（`bubbleOn` / `timerActive()` / `bubbleRemindActive` 任一命中即静默跳过）。`dragLock` 下不累计位移、恒走点击分支，`pointercancel` 有独立收尾，天然不触发。**不进 `bubble.system`**：不可编辑、不进设置页固定文案池，塞进去会被 check-shared 逼着在宿主默认值放死副本。气泡已开着时走 `swapBubbleContent` 原地换词。
- **气泡自适应**（渲染器 `fitText`，页面薄壳 `fitBubbleText`）：三行字号固定（A/B/P/C，见第九节），长文案换行会撑出气泡；`applyLines` 末尾按 `FIT_W×FIT_H`（660×430u）测文本块，超出时缩字（只缩不放）。**分三级**（口径见第九节「气泡文字自适应」）：① 逐块独立缩：三行每行 / v2 每行 / 按压气泡每个模块行各自算系数（旧「全部行共用一个系数」已废）；② 单块缩到 `FIT_HARD_MIN=0.34` 仍超框即停；③ 转交 `fitRowOverflow`：**先换行、仍超高才省略号截断**。字号写成行内 `calc(var(--dshw-u) * N)`，挂件缩放后无需重测；`resetFont()`（薄壳 `resetBubbleFont`）在退出气泡文案（`render` 默认分支、`restoreBubbleLines`）时清掉行内字号并复位 `dataset.k` 累积系数。
- **下班倒计时接管主体**：`cfg.offworkOn` 开启且当前在「常规三行」路径时，`labelEl` / `amountEl` / 第三行改由共享 `OffworkCore.display()` 写出（「距离下班 / 距离上班 / 已下班 / 休息日」+ `hh:mm:ss` + hint），**不新起定时器**：复用既有的每秒 `bubbleTtlSweep`（`offworkStep` 在「开关关 / 气泡未开」时立即返回），阶段 / 秒数 / 临近档位变化才写 DOM（`offworkKeyOf` 比对）。优先级低于自定义泡泡（`bubbleModelOn`）/ 计时 / 提醒 / 试播 / 随机台词（`offworkCanRender()` 统一判定），不会顶掉这些显示；关闭时 `offworkView` 恒 `null`，`render()` 走与未开启完全一致的余额路径。开启期间余额变动**不闪烁 / 不滚动 / 不自动弹「余额大幅变动」气泡**（状态照常更新、菜单顶部仍是真实余额），低余额 / 预算 / 峰谷提醒气泡照常。`applyOffworkConfig()` 在每次配置推送时归一八键，仅在开关或配置变化后切运行态；`setTimeBubbleOn` 与 `applyConfig` 的「即时回填首行报时」都带 `!offworkCanRender()` 守卫，避免把「距离下班」顶成时间。倒计时不继承低余额红色，临近档位只切 `root` 上的两枚类（见第九节）。

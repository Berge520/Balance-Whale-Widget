## 六、存储结构（续）· 素材包 / 内置形象 / 共享素材

**素材包**（`lib/assets.js`）：把 `userData/whale-skins/`、`userData/whale-bubbles/` 与 `userData/whale-sounds/` 里的文件打成一个单文件包（扩展名 `.whaleassets`，落用户选定路径），换机器或重装时一次带走。容器格式为 `[11 字节魔数 'WHALEASSET1'][4 字节清单长度 uint32LE][JSON 清单][各文件字节按顺序平铺]`，清单里每项记 `off/len`，读取时按偏移切片。**不压缩**（图片与音频本身已是压缩格式），**不用 zip**：preload 只有 Node 内置模块，自写 zip 要处理 CRC32 与中央目录，不值。清单 `kind` = `balance-whale-widget-assets`、`schema` = 1，高于当前 `schema` 的包直接拒收并提示升级插件。**`bubbles` 是后加的清单项，不升 `schema`**：老包里没有它，`parsePack` 用 `Array.isArray(...) ? ... : []` 兜底成空数组；老插件读新包只校验 `skins` / `sounds`。**素材包不落任何存储键**，故不涉「配置四处同步铁律」。导入语义：**形象与气泡图是「补充」**（每张生成新 id，不动已有画廊与在用那张，分别受 `MAX_ITEMS = 20` / `8` 约束）、**音效是「同槽位覆盖」**（与 `importSound` 同语义，换格式不留旧文件）。

**内置形象素材包**（`lib/skin-packs.js`）：13 张内置形象原全随包分发，**只留默认那张 `DSniang1` 随包**，其余打成素材包挂 GitHub Release，用户在新手引导完成页或设置页「资源」Tab 按需下载。**该可下载包只有 1 张**（`DSniang02`）：原 12 张里 11 张与「共享角色包」（`resources/assets-skins.whaleassets` 的 36 张）**重复**，原图已随共享角色包整包分发且内置版是重压低质 webp，故一律改由共享角色包提供，免得画廊出现两张一样的图（判据：64×64 灰度感知哈希 + 肉眼复核）。**复用上面的 `.whaleassets` 容器格式**（不是 zip，理由同上），素材包由 `scripts/build-skin-pack.py` **离线生成**（源图在 `resources/skins-src/`，不在 `public/` 下故不进插件包；产物 `public/whale-pack/skins-pack.whaleassets`，每次 Release 由 `release.mjs` 本地补传）；脚本每次跑会**清理 `whale-pack/thumbs/` 里不在清单内的陈旧缩略图**（否则随 Vite 进插件包）。

- **下载源（候选链）**：拆成「真源 + 加速前缀」两段 —— `SKIN_PACK_ORIGIN` = `https://github.com/Berge520/Balance-Whale-Widget/releases/latest/download/skins-pack.whaleassets`（真源直连，国内不稳）、`SKIN_PACK_DEFAULT_PREFIX` = `https://ghfast.top/`（内置默认加速前缀）。`SKIN_PACK_URL` = 两者拼接。`skin-packs.js#sourceChain(prefix)` 拼出候选链并**逐个尝试，任一取到合法包（双 sha256 过关）即停**：① 用户自填前缀（`config.skinPackSrc`，空则跳过）→ ② 内置默认前缀 → ③ 真源直连 → ④ raw 直连 → ⑤ raw 走默认前缀 → ⑥ raw 走用户自填（`SKIN_PACK_RAW_MAIN` = `https://raw.githubusercontent.com/Berge520/Balance-Whale-Widget/main/public/whale-pack/skins-pack.whaleassets`，与 Release 走不同 CDN 路由，恒指向自身、不像 `latest` 会因发版改名）。**raw 同为 github 域名、国内同样不稳，故也有被前缀包装的候选**（⑤⑥）。全失败时报错串起各源标签（自定义加速源 / 默认加速 ghfast.top / 直连 github.com / main 分支 raw 直连 / 走默认加速）。`latest` 指向最新一版，**每次发版必须重传该资产**，否则下载入口 404：上传由 `release.mjs` 本地完成（素材包不入库，CI 拿不到），`verify-release-zip.mjs` 核对它确在 Release 里。
- **常量真源**：`constants.js` 的 `SKIN_PACK_SKINS`（1 项，每项 `{id,file,sha256,size}`）是「哪些形象可下载」的唯一真源（决定落盘时的 id 校验与逐张 sha256）。**设置页不再持有它的字面量副本**：「形象」卡整组由宿主 `listSkinPacks()` 的运行时清单渲染（`id` / `name` / `size` / `installed` 都从那来），原先 `App.vue` 那份**只含 `{id,size}`** 的副本已无消费方；`check-shared.mjs` 对应比对一并去掉。
- **`id` 必须能安全落盘**：`id` 会拼进文件名（`skins.js` 的 `writeFileSync` / `readFileUrl`）并要过 `skins.normItem` 的 `/^[A-Za-z0-9_-]{1,40}$/` 白名单，**含中文等字符的 id 会让该张在 `readRaw` 归一化时被静默丢弃**：表现为「下载报成功、画廊却少一张，且每次判成未装、反复重下」，不抛异常。历史踩坑：内置包第 12 张原 id 为中文「无稽之谈改」，改为拼音首字母 `wjztg`（与 `glby` / `ciya` / `liuy` 同风格）；该张已随重复项移除，故当前清单已无 `wjztg`。**`file` 与 `id` 是两件事**：`file` 是包内原文文件名（可含中文，`skin-packs.js` 按 `it.name` 匹配清单），只有 `id` 受白名单约束。该中文 id 从未发布过。回归见 `test/skin-packs.test.mjs`（白名单 + 容器内 id 与 constants 一致）。
- **缩略图随包**：缩略图（`public/whale-pack/thumbs/<id>.webp`；v1.8.0 起精简到 1 张）**随插件包分发**，设置页按相对路径加载。`build-skin-pack.py` 每次跑会删除不在当前清单内的陈旧缩略图。`vite.config.js` 因此**不能整目录排除 `whale-pack/`**，只能排除两件大件：素材包本体 `skins-pack.whaleassets`（发 Release 用）与中间产物 `manifest.json`。`verify-release-zip.mjs` 专门钉住这点（缺 thumbs 报错、多了那两件也报错）。
- **素材包自报内置身份**：容器清单每项带 `id` 与 `builtin:true`（由 `build-skin-pack.py` 写入）。`skins.exportItems()` 也输出这两项、`importBuffer()` 接收并透传给 `addItem` ：「用户自己导出的素材包」换机器导入后，这些图仍被识别成内置图（固定 id、不占自建配额、`builtinIds()` 能认出来不重复下载）。
- **导入不顶掉当前形象**：`skins.importBuffer` 的 `addItem` 必须带 `keepCurrent:true`：与下载链路 `installBuiltin` 对齐。素材包一次会进好几张，`addItem` 默认「新增即切当前形象」，漏掉 `keepCurrent` 会让用户点一次「导入素材包」就把正用着的形象悄悄换掉；画廊原本为空时仍自然落到第一项。单测见 §十一 第二十一组。
- **双重校验**：① 整包 sha256（`SKIN_PACK_SHA256`）挡代理返回 HTML 错误页 / 截断；② 逐张 sha256（`SKIN_PACK_SKINS[].sha256`）只跳过坏的那张，不连累整包。另有 `SKIN_PACK_MAX_BYTES`(4MB) 上限兜底。
- **落盘去向**：下载的形象落进**自定义画廊**（`whale:skins`，带 `builtin:true` 标记），**不放进浮动页的相对路径表**：挂件读不到插件包外的 `file://` 资源（见 `skins.js` 文件头），只能走 data URL 推送。故不必改 `floating-page.js` / `normSkin` / IPC：下载形象在配置里对应 `skin:'custom'`。
- **配额豁免**：`builtin:true` 的项**不占 `MAX_ITEMS` 配额**（用户自建形象仍限 20 张）。
- **老用户兼容**：升级后 `config.skin` 若是已移出包的内置 id，`normSkin` 原样保留、不打回默认（下拉里回显「`<id>`（未下载）」），用户重新下载后即恢复使用。**但「保留配置值」不等于「用户看得见」**：挂件找不到那张图只能回退默认形象；而「可下载形象」默认收起（`galleryFolds.skins`），提示藏里面等于没有。故补**当前形象缺失提示**：判据不新增存储键，用 `LEGACY_BUILTIN_SKINS`（历史内置全集，含 `BUILTIN_SKINS`）∩ 非随包 且 `skinPackInstalled[cfg.skin] !== true` 现算；命中时 **① 首次自动展开折叠区（`browseSkinsTick` 自增一次性指令）、② 顶部提示条「你正在使用的形象「x」随新版移出了插件包，挂件暂用默认形象显示。点下方它的缩略图即可下载找回」、③ 该张缩略图挂「正在使用 · 未下载」警示色标签**（不新加存储、不跑宿主 IPC）。自动展开只在「从未展开过」时做一次，之后尊重手动收起。
- **`window.services` 入口**：`listSkinPacks()`（返回 `{ok,items:[{id,name,size,installed}],totalSize,installedCount}`，`name` 供「可下载形象」网格显示）+ `downloadSkinPackItem(id, prefix?, thumb?)`（**单张下载**：点任一随包内置缩略图走它，只取这一张原图（`SKIN_PACK_RAW_ITEM_BASE` + `<id>.png` 单张 raw 直链，源图在 `public/whale-pack/src/`），不为一张图下整包）→ 逐张 sha256 过关后 `skins.installBuiltin(...)` 落盘并重推 `whale:skin`；`thumb` 是设置页读到的缩略图 data URL。**非 async fire-and-forget**（内部 `.then` 链），避免与整批下载的 `busy` 守卫互锁。+ `downloadSkinPacks(prefix?)`（**整批下载**，卡头「下载剩余 N 张」走它；`prefix` 为空 / 缺省 = 只用内置候选链；返回 `{ok,installed,skipped,total,errors?,error?}`；成功后若当前用的正是刚下载的形象则重推 `whale:skin`）。宿主不读配置：设置页把 `cfg.skinPackSrc` 传进来（归一化在 `store.js#normSkinPackPrefix`）。
- **与 `assets.js` 的关系**：两条独立链路（这里「按 id 取远程包 → 落画廊」、`assets.js`「用户自选文件 → 勾选导入」），只共用容器格式，解析逻辑刻意各写一份（`assets.js` 那份要保留 raw 供设置页预览勾选，）。

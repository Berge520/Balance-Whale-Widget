**卡片合并 / 拆分（v1.5.0 整理）**：

> **v1.14.0（2026-11-01）现状**：合并卡标题改为 **「专注与待办」**（只有计时子卡可见时叫「计时」）；组件顺序 **`FocusView` → `TimerView`**；FocusView 分区为 **今日 → 待办清单 → 专注统计 → 专注明细**，计时设置沉底。下面第 8 条的 v1.14 顺序是历史记录，当前实现以本条为准。

- 「自定义素材」**并入「挂件外观」**：素材导入 / 删除原先另占一张卡，现并入，卡头「清除全部素材」按钮由 `hasAssets` 控制显隐。随后素材区从「挂件外观」整块移出、独立成 **「资源」Tab**：「挂件外观」只留「用哪个」（形象下拉 + 音色下拉 + 指向「资源」页的提示），「资源」页管导入、体积、删除与迁移。
- 「台词库」+「提醒文案」**合并为「文案」卡**（v1.5.0）：提醒文案侧 6 个 `textarea`；台词库侧是**可增删的随机组列表 + 2 个固定文案 `textarea`**。**该独立「文案」卡已拆解下线**：台词库整套编辑 UI（随机组列表 / 行×段编辑器 / 行条件 / random 段 / 导出台词包）已**从设置页移除**，`cfg.quotes` 的**数据模型（加权抽组 `groups` / `clickQueueOn` / `quoteMode`）也已在 v1.12.x 从宿主彻底删除**（总开关关掉时挂件改发 `cfg.bubble.system` 的 5 池固定文案）；提醒文案侧 6 个 `textarea` 归入「提醒与通知」卡；**「按压气泡（自定义泡泡）」卡**（`data-search="bubbleCustom"`）成为台词类内容的唯一编辑入口，卡内只留总开关 + 泡泡队列 + 模块编辑 + 使用说明，不再内嵌台词库分区（卡头换回 `bubbleCardFolds.open` 单纯折叠）。**⚠️ 拆卡时漏摘过一处**：`clickQueueOn`（「点按依次播放」）复选框留在「挂件外观」卡、配置层还在写，`public/` 侧已无读取方 —— **死开关**；v1.13.0 已连同 `cfg.clickQueueOn` 一并清掉（见第五节删除说明）。
- 「挂件行为」**拆开**：`usageMode` 口径下拉并入「用量与账本」；峰谷切换提醒 / 计时到点通知 / 记住计时状态 / 低余额预警 / 今日预算提醒 / 余额大幅波动通知 / 提醒停留时长 / 免打扰时段归入新增的**「提醒与通知」卡**。
- 「挂件窗口」**瘦身**：使用说明 / 快捷键绑定 / 故障排查 / 挂件错误查看移入新增的**「使用帮助」卡**，卡内只剩窗口相关项（避让 / 间距 / 透明度 / 穿透 / 复位）。
- 「用量趋势」**改名「用量与账本」**（趋势图 + 本月汇总 + 额度 + 今日模型占比 + 账本明细 + 导入导出都在这一张）。
- 「DeepSeek Harness（dsh）」归**「开发者」Tab**；「关于与更新」归**「帮助」Tab**。
- 「计时」+「专注与待办」**合并为一张「专注与待办」单卡**（v1.14.0 起合并、改名与重排）：`App.vue` 的父卡 `section.card.focus-timer-card` 出**唯一标题**「专注与待办」+ 一句主线说明，`FocusView` / `TimerView` 改为 `section.card-embedded[data-search]` 分区容器（**不再各自带 `<h2>` 与外框**，`.card-embedded` 负责去边框 / 阴影 / 底色 / 内外边距，`.focus-timer-card .card-embedded + .card-embedded` 补 1px 分隔线）。**分区顺序固定为行动优先**：今日（专注记录开关 + 今日摘要 + 每日目标 + 待办计划）→ 待办清单 → 专注统计（柱图 + 热力图）→ 专注明细 → 计时设置（默认与快捷档位 → 计时到点 → 休息与番茄 → 计时气泡与状态）。原两张子卡之间的**互跳按钮已删除**（同卡内滚动没有意义；计时卡改为「见上面的『专注统计』」的指向性文案）。**统计降噪**：原独立「对比回顾」段并入今日摘要行（今日 / 连续 / 近 7 天趋势 / 日均一行说完），柱图 / 热力图 / 明细保留。**机制**：两个子块继续保留 `data-search="timer|focus"` 作为搜索锚点与深链落点；`gen-search-index` 额外提取 `<h3 class="card-sub">`（卡头 h2 只剩一个，子块靠分区标题词保住检索命中），切片边界改为任意 `<section>`（合并卡这类有卡头、无锚点的容器必须截断，否则它的 h2 会漏进上一张卡的索引文本）；`syncPinned` 把 `data-search` 解析到 `closest('.card')` 并去重 —— **置顶任一子块 = 整卡置顶**，父卡承担 `.card-pinned` 标记；「显示管理」仍保留「计时 / 专注与待办」两个条目，分别控制两个区块的显隐。这张合并卡里的计时区是计时**默认值**的唯一写入方，挂件菜单只管「这一轮」（见 §八）。**每张卡都可折叠**：所有设置卡统一走 `useFold(key, defaultOpen)`（localStorage 记住用户手动开合；`card-toggle` 标题 + `.caret` 箭头 + 收起态 `.card-sum` 摘要）。默认策略按使用频率：展开 = 挂件外观 / 用量与账本 / 挂件窗口 / 专注与待办；收起 = 提醒与通知 / 模型与余额 / 按压气泡 / 备份与恢复 / 清除数据 / 使用帮助 / 关于与更新 / GitHub 加速 / dsh 各卡 / 资源画廊。**用户手动开合过就以用户为准**，默认值只影响没动过的卡。**低频分区默认折叠**：「休息与番茄」「计时气泡与状态」两块收起，标题整行可点（`role=button` + `aria-expanded`），收起时尾注一行状态摘要（休息档位/番茄循环、气泡三开关），搜索命中时强制展开（同 `AssetsView` 的 `galleryOpen` 口径）；显示管理里该块条目名为「计时设置」。待办行同理：预估/计时/提醒/改名收进每行「更多」，折叠态摘要显示非默认值；填了预估时主行显示 `X/Y 轮`。
- 「下班倒计时」**独立成卡**（v1.14.0，`OffworkView.vue`，`data-search="offwork"`，归「用量」Tab，排在「专注与待办」之后）：卡头可折叠（`useFold('offwork', true)`，`FOLD_DEFAULTS.offwork=true`；收起摘要「已开启 · 09:00–18:00 / 未开启」）。卡内九项：总开关、上下班时间（`type=time`）、工作日七个 chip（`Date.getDay()` 口径，0=周日；**至少保留一天**，取消最后一天不生效）、显示秒、附加「距周末」「距发薪日」、发薪日 1–31 下拉、时薪（元/小时，留空 = 不估算「今日已赚」；只接受正数 / 最多两位小数 / ≤100000，非法输入不落盘并复用 Flash 回执）。所有改动均 `emit('patch')`（`offwork*` 九键走 `defaultConfig` / `readConfig` / `writeConfig` / `patchConfig` 四处同步），不直接改 `cfg`。显示管理里按普通卡片参与隐藏 / 置顶 / 排序 / 折叠；`CARD_DEPENDENCIES.offwork` 的隐藏提示为「隐藏后无法设置上下班时间与工作日，但已开启的挂件倒计时仍会显示」。

**卡片内折叠（v1.5.0 后续整理）**：Tab 分组解决了「一屏看到底」，但组内仍有几张超长卡片。沿用既有的 `.fold` + `.link-btn` + `v-if` 折叠模式（与「用量与账本」的账本明细、素材包、使用说明同一套），把低频项收进折叠：

| 折叠态 | 位置 | 默认 | 收起原因 |
|---|---|---|---|
| `toolOpen.credentials` | 「数据」Tab → 凭据卡 | 收起 | 凭据填一次就不动，日常进这个 Tab 多半是为了清数据 / 备份 |

**共享素材**（`lib/assets-packs.js`）：把上游 QQ 群的共享素材（36 张形象 + 45 段音效）从仓库移出，改为**按张 / 按段在线下载**。**v1.9.0 起不再打整包**（整包 40.6MB 挂 GitHub Release，国内慢，用户多半只要几张）：源图由 `scripts/export-shared-assets.mjs` 按 `id.ext`（ASCII 短名，避开中文 / 全角括号在 raw 直链上的 percent-encode 与 CDN 兼容性问题）重命名导出到 `public/shared/skins/<id>.png` 与 `public/shared/sounds/<id>.<ext>`，**随仓库入库**（`.gitignore` 里 `!public/shared/**` 放行），走 `SHARED_RAW_BASE` = `raw.githubusercontent.com/.../main/public/shared/` 单张直链取用（最大单张约 2.6MB，不触 jsDelivr 单文件 20MB 限制）。整包链路（容器解析 / 整包 sha256 / `build-assets-pack.py`）随之删除。**`SHARED_SKIN_PACK_SKINS`（`{id,name,file,sha256,size}`）与 `SHARED_SOUND_LIB`（`{id,name,ext,sha256,size}`）各自是「哪些共享角色 / 音效可下载」的唯一真源**（`constants.js`，`name` 仅作展示、`file` 保留原始中文名备查，落盘与 URL 一律用 `id`）；下载源候选链同 `skin-packs.js#sourceChain` 的**单张版**，顺序为 **jsDelivr CDN（`SHARED_CDN_BASE`）→ 用户自填前缀 → ghfast.top → `SHARED_RAW_BASE` 真源直连**：实测最大单张走 jsDelivr 最快，raw 直连超时、ghfast 居中，故 jsDelivr 首位、真源直连垫底。**下载源前缀仍沿用 `config.skinPackSrc`**（与内置形象包共用同一个加速前缀设置）。⚠️ jsDelivr 对刚 push 的内容有缓存延迟（数分钟~数小时），期间 404，靠后续候选顺延；急用可临时用自填前缀顶。
- **形象落盘去向**：走 `skins.installBuiltin(id, ext, buf, thumb, name)`（与内置形象包同一条路，带 `builtin:true` 标记、不占 `MAX_ITEMS` 配额、落进 `whale:skins` 画廊）；**第 5 参传清单里的中文原名**（`SHARED_SKIN_PACK_SKINS[].name`），画廊显示「名」而非 id 短哈希，缺省不传回落成 id。**第 4 参 `thumb` 是缩略图的 data URL 字符串（png / webp），不是 Buffer** —— 由调用方决定 MIME，`writeThumb` 按 data URL 前缀决定落盘扩展名（`.thumb.png` / `.thumb.webp`）并清掉另一格式的旧文件。**为什么必须由调用方给**：宿主（preload）定位不到插件目录（只有 `utools.getPath('userData'/'temp'/'downloads')`，无 plugin 路径 API），相对路径 `./resources/thumbs/<id>.webp` 只有**渲染进程（设置页）**能解析，故缩略图必须由设置页读成 data URL 传下来。空串 = 这张没有缩略图（画廊回落读原图）。
- **音效落盘去向**：走 `sounds.installBuiltin(name, ext, buf)`，落进 `whale:sounds` 里**独立的 `shared` 槽位** —— `sounds.js` 的 `ROLES` 含 `'shared'`，另定义 `PLAY_ROLES = ['press','release','low','budget','peak','pass']`。**`shared` 只是素材池、不是实播槽位**：`getSoundData()` / `exportItems()` 都只遍历 `PLAY_ROLES`（避免共享库一导入就参与挂件播放、把六段音色/提醒音冲掉），用户须在设置页给某段**勾选参加哪些实播槽位**（`sounds.setSharedRoles(file, roles)` 写 `roles` 关联，见第十节「音效」卡条），才会在这些槽位的随机播放里被抽到。**`installBuiltin` 必须传 `{append: true}`**：`shared` 是唯一允许多段的槽位（下载第二段不能抹掉第一段），实播槽位则走 `saveOne` 的默认「整条替换」语义。
- **`window.services` 入口**：`listSharedSkins()` / `listSharedSounds()`（返回 `{ok,items,total,installedCount,error?}`，形象的 `installed` 由 `skins.builtinIds()` 现算）+ `downloadSharedSkin(id, prefix?, thumb?)`（单张，成功推 `whale:skin`；**第 3 参 `thumb` 是缩略图的 data URL**，由设置页读打包资源 `resources/thumbs/<id>.webp` 传来 —— 宿主定位不到插件目录，不给的话下载回来的形象没有缩略图，画廊只能回落读原图）+ `downloadSharedSound(id, prefix?)`（单段，**不推挂件**，只落 `shared` 槽位）+ `setSharedRoles(file, roles)`（写「这段参加哪些实播槽位」的 `roles` 关联，**共用同一段落盘、不复制音频**，成功推 `whale:sounds`）+ `readSharedSoundData(file)`（试听用，按**落盘文件名**临时读一段 data URL、**不缓存**；`shared` 槽位不在宿主推送的 `soundData` 里，故必须另开这条只读通道。**参数是 `file` 不是 `name`** —— 素材池允许同名，按 `name` 会永远命中第一条）+ `removeSharedSound(file)`（删段，无连带清理，见 §5 通道表）+ `setSkinThumb(id, thumb)`（**老数据懒补**：只服务 `builtin:true` 的官方图，已有缩略图文件时返回 `{ok:true,skipped:true}` 短路；设置页打开画廊时发现哪张缺就补哪张，见下「缩略图懒补」）。`prefix` 同 `downloadSkinPacks`：设置页传 `cfg.skinPackSrc`，宿主不读配置。已装的 id / 名走 `skipped` 短路，不重复下载、不重写。
- **缩略图懒补（bug 10 修复）**：共享角色网格走静态 `./resources/thumbs/<id>.webp`（几 KB，渲染进程直接读、不经宿主，一直正常），而**本地画廊**（导入的形象 / 已下载的共享角色）走 `skinsDir()` 下的 `<id>.thumb.png|webp`，经宿主 `listSkins()` 读回。**两条独立错叠加**导致画廊全「无预览」：① `assets-packs.js` 下载时第 4 参写死 `null` → 下载的共享角色从不落缩略图；② `skins.readThumb` 只认 `.thumb.png`，而打包的缩略图是 `.webp` → 即便落盘也读不回。两者叠加后 `listSkins()` 只能**回落读原图**，而原图 0.9–2.7MB 一张、回落预算 `fallbackBudget = 8MB` 逐张判断，**约第 4 张就耗光**，之后全返回 `thumb: ''`。修复分三层：
  - **下载落盘**：设置页读 `resources/thumbs/<id>.webp` → data URL → 传宿主 → `installBuiltin` 落盘（新增 `App.vue#sharedSkinThumbDataUrl(id)`）。
  - **老数据懒补**：`App.vue#refreshSkin()` 每次刷新时对 `!it.thumb && it.builtin === true` 的项调 `setSkinThumb` 补一次（`backfillingThumbs` 防重入、只跑一轮、读不到资源不报错 —— 后台自愈不该打扰用户）。
  - **读回兼容**：`readThumb` / `removeSkin` / `exportItems` 全部支持 png + webp 双格式；新增 `hasThumbFile(id)` 做**纯文件存在性**检查（不能用 `readThumb(id)` 非空来判断 —— `listSkins` 的 `thumb` 字段带回落，光看列表分不出「真没有」还是「回落来的」）。回归测试见 `test/skins.test.mjs`（webp 读回 / 跳过 / 补写 / 不存在 / 非法数据 / 双格式清理）与 `test/assets-packs.test.mjs`（`opts.thumb` 落盘）。
- **缩略图分发**：36 张形象缩略图 `resources/thumbs/<id>.webp` 随插件包分发，设置页按 `./resources/thumbs/<id>.webp` 加载；`vite.config.js` 的 `copyResourcesExceptSkip` 只拷 `thumbs/`，`manifest.json` 排除。`.gitignore` 忽略 `resources/manifest.json`（保留 `resources/thumbs/` 与 `public/shared/` 入库）。

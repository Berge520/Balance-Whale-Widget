`randomIncludeBuiltin` = 「随机抽签」是否把**随包内置形象**算进池子（**默认 true**；归一 `!== false`，缺键按「参与」处理，`store.js` 四处同步）。只影响后续抽签，不动在用那张；池子在 `App.vue` 的 `allSkinChoices` 组装：开着先并入 `BUILTIN_SKINS`，再并入画廊 `random !== false` 的项并按 id 去重。**挂件侧不读这个键**：其「随机一张」复用宿主 `skins` 同一份池子（见 §10）。

`tapAdvance` / `bubbleDwell` / `dragLines` = 气泡交互三项（`store.js` 四处同步）：`tapAdvance`（**默认 false**，按 `=== true` 归一）＝ 点本体是否也翻下一条自定义泡泡（默认只点气泡翻）；`bubbleDwell`（**默认 5**，`Math.round` 后 clamp 3–60，非法回 5）＝ 气泡默认停留秒数，即 `BUBBLE_MS`(5000) 的运行期覆盖值，没配行级 `d` 的屏按它收起；`dragLines`（**默认 `DRAG_LINES_DEFAULT`** 四条、上限 `DRAG_LINES_MAX` 10）＝ 拖拽台词，经 `normLineList(p.dragLines, DRAG_LINES_DEFAULT, DRAG_LINES_MAX)` 清洗。

> **UI 归属**：这三项与「小鲸鱼报时」（`timeBubbleOn`）的控件已从「外观 → 气泡与文案」卡删除（与 `bubble.tapAdvance` / `bubble.dwell` 重名；报时另做成 `time` 模块），但**顶层键全部保留**（仍在 `defaultConfig`、被 `floating-page.js` 旧式气泡路径读取）：老用户已设的值不受影响，只是改不了。

`bubble` = **「按压气泡」配置对象**（原「文案」卡已下线，本卡是唯一入口）。出口恒定形态 `{v:1, on, items, lib, tapAdvance, dwell, dragLines, system}`（`store.js` 的 `normBubble` 归一，四处同步）：

- `on`（**默认 false**，按 `=== true` 归一）= **「启用自定义泡泡」总开关**：开 = 挂件走本模型渲染与队列；关 = **不接管**，退回顶层「思考气泡」（`cfg.bubbleOn`）。挂件侧用 `bubbleModelOn` 记它，与 `bubbleOn`（点挂件弹不弹的总闸）分开，否则会连顶层思考气泡一起关死。
- `items` = **步骤队列**（上限 `BUBBLE_STEP_MAX`），每步是 `WhaleBubbleStep`：**单泡**（`WhaleBubbleBubble`）或 **A/B 并列泡**（`WhaleBubbleChoice`，含 `options[]` 与权重 `w`、可「拆开」成独立步）。出厂默认（`store.js#bubbleDefaultItems`，**逐字对齐上游**）**2 步**：<br>**① 首次点击泡**＝ `custom` 单泡、**5 模块 4 行**：`text`「DeepSeek 余额」(size 8) / `balance` 大号余额 (size 20, `rgb: indigo` 跑马灯) / `today`「今日已用」(size 12) / 两个 `peak` 共享 `row: 4` 同行（`peakStyle: mini` 徽章 size 10 + `peakStyle: count` 倒计时 size 12）。<br>**② 再次点击泡**＝ `choice` 并列 **A/B**：A 权重 10 = `random` 模块（大肥鱼台词 `BUBBLE_DFT_RANDOM_LINES`，**每条自带 size 7–22 与配色**，模块级 size 8 只作兜底）；B 权重 1 = `randimg`（从已装共享角色池随机抽一张）。<br>**三处有意偏离上游**（其余含台词 `w` / `size` / `rgb` 与字段顺序逐字照搬）：① B 候选本应挂 `image` + `imgId: 'bimg_petpet'`，但本项目 `imgId` 是**数字下标**、无具名内置图，照搬会解析成 0 → 整泡空白，故换 `randimg`；② 首泡三个注脚模块字号上调（today 4→12、peak mini 2→10、peak count 4→12）：缩到 `MIN_SCALE` 0.6 时 size 2/4 只剩 5–6px，这 5 个模块走**模块级 size 直出**，只能改数值；**别顺手抬高 `balance`(20) 或 `text`(8)**：主角 / 标题层级是上游设计；③ 首泡保留 5 模块 4 行，不用「单行纯色余额」简化。**别用并列泡挂 `randimg` 以外的空源模块**：共享角色池为空时抽中即整泡空白、白费一次点击（出厂 `DSniang1` 是 `skin` 静态文件、不落 builtin 画廊）。
- `lib` = **模块库**（另存 / 复用的 `WhaleBubbleLibItem[]`）。
- `tapAdvance` / `dwell` / `dragLines` = 交互项（点按推进 / 停留时长 / 拖拽台词）。默认 `BUBBLE_TAP_ADVANCE_DFT` / `BUBBLE_DWELL_DFT=5`（MIN 3 – MAX 60）/ `DRAG_LINES_DEFAULT`，`DRAG_LINES_MAX` 10。
- `system` = **固定文案池**（原 `cfg.quotes` 的固定文案迁入）。键集 `QUOTE_TEXT_KEYS` = `time`（白天报时模板，`{t}` → `HH:MM`）/ `timeEarly` / `timeMorning` / `timeEve`（深夜 / 清晨 / 早上）/ `gifFail`（自定义气泡动图加载失败的顶替文案）。每项是字符串数组，`normBubbleSystem(v, cur)` 清洗：逐条 `trim`、丢空、截 60 字、空数组回 `QUOTE_TEXT_DEFAULT`。**原 `cfg.quotes` 的随机抽组（`groups`）与 `clickQueueOn` / `quoteMode` 已移除**，读取时丢弃，只有五个固定池迁进 `system`。
- **单泡结构** `WhaleBubbleBubble` = 行×模块两层：`modules[]` 经 `row` 键扁平化，行键 = 行下标 + 1（**单模块行与图片类行无 `row` 键**），`normBubbleModules` 保存时重建 `row` 键，设置页 `bubbleApplyRowLayout` 同口径镜像；行上限 `BUBBLE_ROW_MAX` 6、每行 `BUBBLE_MOD_MAX` 6；图片类模块（`image` / `randimg`）**独占一行并打断行合并**。
- **模块类型**（`BUBBLE_MOD_TYPES`）：`text, time, balance, bonus, recharge, today, peak, session, random, link, image, randimg, quota, plan`。`bonus` / `recharge` / `quota` / `plan` 等**数据源类**无数据时渲染「—」（实现全做、无源占位）。`time` 是**本插件自有扩展**（上游无此类型）：自动文本 = 按当前时段取「报时文案池」一句（`{t}` → `HH:MM`），套模板即成自定义报时，内容锁定、只留 `tpl` 可调。模块字号换算 `modFontU(size) = Math.round(40 + (n - 1) * 200 / 49)`（n clamp 1–50）。
- **模块字段**（`normBubbleMod` 清洗）：`type, size, color, rgb, bg, bgRgb, bold, italic, ul, fontFamily, row, tpl, text, lines, url, text2, imgId, imgs, imgScale, peakColor, offColor, peakRgb, offRgb, peakBg, offBgRgb, offBg, peakStyle, len, modelId, planWin`。`BUBBLE_PEAK_STYLES` = `mini|text|count`；`BUBBLE_PLAN_WINS` = `all|5h|week|month`；`BUBBLE_RGB_SCHEMES` 跑马灯配色方案（`['', 'macaron','candy','rouge','bamboo','aurora','deepsea','sunset','forest','champagne','lavender','mint','lava','galaxy','ink','indigo','blaze','amber']`）；`BUBBLE_FONT_FAMILIES`。
- **「已归位」与「空壳」的区别**：`text2` 与 `modelId` 属**空壳**，**别以为「白名单收了」功能就已实现**。判据 = 有无「数据源 + 渲染消费点」：
  - `text2`：`normBubbleMod` 收了它（能存、能过清洗、进备份），但**渲染侧零消费点**：`bubble-render.js` 不读、浮页 `bubbleModText` 只出主文本；要用得先定它与主文本的关系。
  - `modelId`：仅 `quota` 模块用到，浮页 `bubbleQuotaModuleText()` **无条件返 `'—'`** —— 模块是纯数据、不与模型绑定，额度按模型算、浮页也无模型快照。现状属「实现全做、无源占位」。要接上得给模块加「绑定哪个模型」字段。
  - 已归位三项（**别误当空壳**）：`imgId`（语义同 v1 台词 `img`：`''`/`'0'` 随机、`1..N` 指定第 N 张，浮页 `bubbleImgSrc(imgId)` 消费）、峰谷两态配色 `peakColor/offColor/peakRgb/offRgb/peakBg/offBg/offBgRgb`（渲染器经可选契约 `opts.modStyle(m)` 回调消费，宿主按 `state.isPeak` 回覆盖值）、模块底色 `bg/bgRgb`（渲染侧 `needBg` 消费，`bgRgb` 优先于 `bg`）。
- **渲染单一源**：`src/bubble/bubble-render.js`（esbuild → `dist/bubble-render.js`，全局 `window.BubbleRender`），设置页 ESM import 复用，挂件与预览共用。
- **预演链路**：见 §五 `whale:bubble-preview`。

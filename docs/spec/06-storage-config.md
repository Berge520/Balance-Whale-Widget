`todoAutoNext`（`=== true`，**默认 false**）= **待办到点自动接下一条**，与上面的番茄循环正交：番茄循环管「专注轮 → 休息轮」，这一项管「A 待办的计时结束 → B 待办的计时开始」。开启后，一条待办计时走完，气泡里给 5 秒等待期并显示「取消衔接」，期内点取消或切走则不接；期满自动把下一条未完成的待办设为专注并按它的参数启动计时（不计时的条目不接，停在原地）。v1.15 删掉过同类自动衔接（`timerAutoNext`，休息完自动回专注），根因是「无条件生效」，所以这次配显式开关 + 等待期 + 取消按钮。

`offworkOn` / `offworkStart` / `offworkEnd` / `offworkDays` / `offworkShowSec` / `offworkRing` / `offworkWeekendOn` / `offworkPaydayOn` / `offworkPaydayDay` / `offworkHourlyWage` = **下班倒计时十键**（`store.js` 四处同步，**默认全关**）。`offworkOn`（`=== true`）= 总开关：开 = 气泡队列末尾多一张**独立倒计时页**（排在所有步骤页之后，第一页仍是步骤页、任何位置都不出现倒计时），该页首行（标题行）是「距离下班 hh:mm:ss · 09:00–18:00」（下班后 / 未上班用对应 phase 措辞），余额与「今日已用」照常，关 = 完全走原有余额路径。`offworkStart` / `offworkEnd` = 上下班时刻（`HH:MM`，`normHm` 归一：接受 `9:00`，时 0–23、分 0–59，非法回默认 `09:00` / `18:00`）；`offworkEnd <= offworkStart` 视为**跨日班**（下班落次日）。`offworkDays` = 工作日（JS `getDay()` 口径，0=周日；`normDays` 去重升序，**空数组回默认周一至周五**，保证至少有一天，否则倒计时永远找不到目标）。`offworkShowSec`（默认 `true`，`!== false` 归一）= 是否显示秒，关掉只显示 `hh:mm`。`offworkRing`（默认 `true`，`!== false` 归一）= **挂件外圈工时进度环**是否显示：开 = 挂件外圈那条环在空闲时由下班倒计时接管（画当天工时进度），关 = 环只归计时，工时进度改看倒计时页里的细进度条 `.dshwv-offwork-progress`（那条细条一直都在，圈可画时它会自动收掉，避免同一份进度画两遍）。`offworkWeekendOn` / `offworkPaydayOn`（默认 `false`，`=== true` 归一）= 是否在第三行「今日已用」之后附加「距周末」「距发薪日」。`offworkPaydayDay`（1–31，默认 10，`normPayday` 取整 clamp，遇到小月自动落到当月最后一天）。`offworkHourlyWage` = **时薪（元/小时，默认 0 = 未配置）**，只用于挂件第三行的「今日已赚」估算；`normWage` 只接受正数、最多两位小数、≤ 100000，空 / 0 → 未配置，其余非法值在写入时**保持现值**（读盘时按未配置处理）；未配置时整项不显示（不占位、不显示 0）。**计算口径单一源** `public/preload/lib/offwork.js`（`normCfg` / `display`）：宿主 `require` 使用，挂件页用构建期打成的 `dist/offwork-core.js`（全局 `OffworkCore`）共用同一份源码；设置页 `App.vue` 只做同口径的轻量归一，不另写时间算法。时间一律用本地 `Date` 构造、每个 tick 重算（国内无 DST；系统时区变了下一轮自然跟上），不做 UTC 偏移换算。`test/offwork.test.mjs` 覆盖上班前 / 工作中 / 下班后 / 跨日 / 非工作日 / 最后一分钟 / 说明行附加项 / 关闭开关不渲染。

`ringWidth` / `ringFollowTheme` = **挂件外圈进度环的画法两键**（`store.js` 四处同步，默认 `'normal'` / `true`）。计时与下班倒计时**共用同一圈**（谁在跑归谁，见 `offworkOwnsRing`），所以样式归设置页「挂件外观」卡、`offworkRing`（要不要给倒计时画）仍归「下班倒计时」卡。`ringWidth` 只认 `'thin'` / `'normal'` / `'thick'`（→ stroke-width 2.5 / 3.5 / 5，表在 `floating-rings.js` 的 `RING_WIDTHS`），其余值一律归一为 `'normal'`；页面经 `WhaleRings.setWidth` 写内联变量 `--dshw-ring-width`，`floating.css` 缺省 3.5 与旧版硬编码一致。`ringFollowTheme`（`!== false` 归一）= 深色系主题（`themeId` 为 `dark` / `fantasy`）下把圈色换成亮一档（`RING_DARK`），关掉后所有主题用原色；进度口径与配色取法都在 `public/floating-rings.js`（`timerFrame` / `workFrame`）。

`hiddenTabs` / `hiddenCards` = **「自定义显示」隐藏的 Tab 与卡片 id**（字符串数组，默认空 = 全部显示；`store.js` 四处只做「是数组 → 留下字符串项」的过滤，**不做 id 合法性判断**）。语义与保护在设置页：`hiddenCards` 命中即不渲染该卡；`hiddenTabs` 命中则整组卡片都不渲染（搜索结果仍会列出并标「已隐藏」，可一键取消）。**核心卡片不可隐藏**：`DisplayManager` 禁用含核心卡片的 Tab 复选框，`App.vue#applyConfig` 回填时再从 `hiddenTabs` 里剔掉 `CORE_TABS`（老备份 / 手改配置可能带着它们）；`hiddenCards` 同样剔掉 `CORE_CARDS`，保证核心卡片不会被整体藏没。

`tabOrder` = **「自定义显示」里手工排的 Tab 顺序**（字符串数组，默认空 = 默认顺序）。`store.js` 四处经 `normTabOrder` 归一：只留字符串、`trim`、去重保首次位置、上限 `TAB_ORDER_MAX` 32 条，**非数组一律回 [] / 保持现值**（`patchConfig` 收到非数组时不动现值）。消费在设置页：`sortByOrder(TABS, cfg.tabOrder, …)` 同时用于主界面 `visibleTabs` 与 `DisplayManager.orderedTabs`（两处同一份顺序，避免弹窗内外顺序不一致）；**排序基于完整 Tab 顺序（含已隐藏的）**，隐藏一组不会丢掉它的位置；排序表里没登记的 Tab 排在已登记项之后、保持原有相对次序。`App.vue#applyConfig` 回填时剔除不是合法 Tab key 的项。改名 / 删除 Tab 时不清理本表（未命中的 key 自然被 `sortByOrder` 忽略）。

`pinnedCards` = **「自定义显示」里置顶的卡片 id**（字符串数组，默认空 = 无置顶）。归一直接复用 `normTabOrder`（只留字符串、`trim`、去重保首次位置、上限 `TAB_ORDER_MAX`，非数组回 []），`store.js` 四处同步。**数组顺序 = 显示顺序**：新置顶的卡追加到末尾，于是连点几张得到的正是「点击先后」，用户不必再自己排。消费在设置页：`pinnedInTab(pinned, activeTab, hiddenTabs, hiddenCards)`（`src/constants/display.ts`）算出**当前 Tab 内**可见的置顶卡，`App.vue#syncPinned()` 据此重排 DOM，`DisplayManager` 的置顶计数与「第 N 位」共用同一函数。置顶**不跨 Tab**：不属于当前 Tab 的 key 不会被搬动，隐藏的卡也不会出现在结果里。`App.vue#applyConfig` 回填时剔掉不是合法卡片 key 的项；`resetDisplayToDefault()` 一并清空本表。

`dshExportCred` / `dshExportNoMod` = dsh **全量导出**（`lib/dsh-export.js`，见 §10.3 第 ⑬ 段）两个勾选：前者 = **是否把凭据文件打进包**（**默认 false**，包内是**明文** `.credentials.yaml`，`isCredFile` 判据见该段）；后者 = **是否跳过 `node_modules`**（**默认 true**，体积是配置的几十倍）。归一：前者 `=== true`、后者 `!== false`，缺键不翻面。`store.js` 四处（`defaultConfig` / `readConfig` / `writeConfig` / `patchConfig`）同步。

`dshElevated` = **「以管理员身份启动 dsh」**（**默认 false**，按 `=== true` 归一，`store.js` 四处同步）。Windows 进程令牌在创建时固定，**没有「原地提权」**，所以开启后每次启动 / 重启都由 `runas` 起一个新实例、弹一次 UAC；点「否」（1223）与启动失败都**回落普通权限启动**，不会停在半启动状态；非 Windows、或当前 uTools 本身已是管理员时直接普通启动、不弹窗。提权实例**不会在 uTools 退出时被结束**（`stopOnQuit` 跳过），下次点「结束」仍需过一次 UAC 做 `taskkill`。重启 / 更新遇到慢 UAC 时，旧实例真正退出后会自动接着启动（只补一次）；超过等待上限仍未退出则明确报错并提示再点一次，不会静默停在「未运行」。实现与排障见 `docs/guide-dsh-admin.md`。

`cardOrder` / `foldDefaults` / `foldRemember` = **「管理显示内容」的卡片调序与折叠三项**（`store.js` 四处同步）：
- `cardOrder` = `{ [tabKey]: cardId[] }`（默认空对象 = 各组默认顺序）。只存**非置顶卡**：置顶卡由 `pinnedCards` 单独排序，混在一起会让「取消置顶」的卡落到最前，与「取消置顶回到原位置」的承诺矛盾。归一 `normCardOrder`：只收普通对象、每组只留字符串、`trim`、去重、空数组丢弃、Tab 组数上限 `CARD_ORDER_TABS_MAX`(16)、每组上限 `CARD_ORDER_MAX`(64)。消费在 `App.vue#syncPinned()`（写 CSS `order`，**不搬 DOM**）与 `DisplayManager.cardsOf()`（弹窗列表顺序），两处都经 `sortCardsByOrder` 按 `cardRootKey` 归一（合并卡 focus/timer 只算一张）。与出厂顺序一致的组在保存时**直接删键**，避免留一堆无意义的自定义顺序。
- `foldDefaults` = `{ [foldKey]: boolean }`（默认空对象 = 用 `FOLD_DEFAULTS` 出厂值）。`foldKey` 见 `src/constants/display.ts#CARD_FOLDS`（合并卡 focus/timer 共用 `focusTimer`）。归一 `normFoldDefaults`：只收普通对象、值必须是布尔、key `trim` 非空、上限 `FOLD_DEFAULTS_MAX`(64)。
- `foldRemember` = **是否记住上次展开 / 收起状态**（**默认 true**）。归一 `!== false`（缺键按开启）。关掉时 `useFold` 既不读也不写 `localStorage` 的 `whale-fold-*`，全部回落到 `foldDefaults` / 出厂默认，并清掉已存的折叠缓存。

`resetDisplayToDefault()` 一并清空这三项（`cardOrder` / `foldDefaults` 清空、`foldRemember` 复位 true）——「恢复默认」对用户就是「回到刚装好时的样子」。

`randomIncludeBuiltin` = 「随机抽签」是否把**随包内置形象**算进池子（**默认 true**；归一 `!== false`，缺键按「参与」处理，`store.js` 四处同步）。只影响后续抽签，不动在用那张；池子在 `App.vue` 的 `allSkinChoices` 组装：开着先并入 `BUILTIN_SKINS`，再并入画廊 `random !== false` 的项并按 id 去重。**挂件侧不读这个键**：其「随机一张」复用宿主 `skins` 同一份池子（见 §10）。

`tapAdvance` / `bubbleDwell` / `dragLines` = 气泡交互三项（`store.js` 四处同步）：`tapAdvance`（**默认 false**，按 `=== true` 归一）＝ 点本体是否也翻下一条自定义泡泡（默认只点气泡翻）；`bubbleDwell`（**默认 5**，`Math.round` 后 clamp 3–60，非法回 5）＝ 气泡默认停留秒数，即 `BUBBLE_MS`(5000) 的运行期覆盖值，没配行级 `d` 的屏按它收起；`dragLines`（**默认 `DRAG_LINES_DEFAULT`** 四条、上限 `DRAG_LINES_MAX` 10）＝ 拖拽台词，经 `normLineList(p.dragLines, DRAG_LINES_DEFAULT, DRAG_LINES_MAX)` 清洗。

> **UI 归属**：这三项与「小鲸鱼报时」（`timeBubbleOn`）的控件已从「外观 → 气泡与文案」卡删除（与 `bubble.tapAdvance` / `bubble.dwell` 重名；报时另做成 `time` 模块），但**顶层键全部保留**（仍在 `defaultConfig`、被 `floating-page.js` 旧式气泡路径读取）：老用户已设的值不受影响，只是改不了。

`bubble` = **「按压气泡」配置对象**（原「文案」卡已下线，本卡是唯一入口）。出口恒定形态 `{v:1, on, items, lib, tapAdvance, dwell, dragLines, system}`（`store.js` 的 `normBubble` 归一，四处同步）：

- `on`（**默认 false**，按 `=== true` 归一）= **「启用自定义泡泡」总开关**：开 = 挂件走本模型渲染与队列；关 = **不接管**，退回顶层「思考气泡」（`cfg.bubbleOn`）。挂件侧用 `bubbleModelOn` 记它，与 `bubbleOn`（点挂件弹不弹的总闸）分开，否则会连顶层思考气泡一起关死。
- `items` = **步骤队列**（上限 `BUBBLE_STEP_MAX`），每步是 `WhaleBubbleStep`：**单泡**（`WhaleBubbleBubble`）或 **A/B 并列泡**（`WhaleBubbleChoice`，含 `options[]` 与权重 `w`、可「拆开」成独立步）。出厂默认（`store.js#bubbleDefaultItems`，**逐字对齐上游**）**2 步**：<br>**① 首次点击泡**＝ `custom` 单泡、**5 模块 4 行**：`text`「DeepSeek 余额」(size 8) / `balance` 大号余额 (size 20, `rgb: indigo` 跑马灯) / `today`「今日已用」(size 12) / 两个 `peak` 共享 `row: 4` 同行（`peakStyle: mini` 徽章 size 10 + `peakStyle: count` 倒计时 size 12）。<br>**② 再次点击泡**＝ `choice` 并列 **A/B**：A 权重 10 = `random` 模块（大肥鱼台词 `BUBBLE_DFT_RANDOM_LINES`，**每条自带 size 7–22 与配色**，模块级 size 8 只作兜底）；B 权重 1 = `randimg`（从已装共享角色池随机抽一张）。<br>**三处有意偏离上游**（其余含台词 `w` / `size` / `rgb` 与字段顺序逐字照搬）：① B 候选本应挂 `image` + `imgId: 'bimg_petpet'`，但本项目 `imgId` 是**数字下标**、无具名内置图，照搬会解析成 0 → 整泡空白，故换 `randimg`；② 首泡三个注脚模块字号上调（today 4→12、peak mini 2→10、peak count 4→12）：缩到 `MIN_SCALE` 0.6 时 size 2/4 只剩 5–6px，这 5 个模块走**模块级 size 直出**，只能改数值；**别顺手抬高 `balance`(20) 或 `text`(8)**：主角 / 标题层级是上游设计；③ 首泡保留 5 模块 4 行，不用「单行纯色余额」简化。**别用并列泡挂 `randimg` 以外的空源模块**：共享角色池为空时抽中即整泡空白、白费一次点击（出厂 `DSniang1` 是 `skin` 静态文件、不落 builtin 画廊）。
- `lib` = **模块库**（另存 / 复用的 `WhaleBubbleLibItem[]`）。
- `tapAdvance` / `dwell` / `dragLines` = 交互项（点按推进 / 停留时长 / 拖拽台词）。默认 `BUBBLE_TAP_ADVANCE_DFT` / `BUBBLE_DWELL_DFT=5`（MIN 3 – MAX 60）/ `DRAG_LINES_DEFAULT`，`DRAG_LINES_MAX` 10。
- `system` = **固定文案池**（原 `cfg.quotes` 的固定文案迁入）。键集 `QUOTE_TEXT_KEYS` = `time`（白天报时模板，`{t}` → `HH:MM`）/ `timeEarly` / `timeMorning` / `timeEve`（深夜 / 清晨 / 早上）/ `gifFail`（自定义气泡动图加载失败的顶替文案）。每项是字符串数组，`normBubbleSystem(v, cur)` 清洗：逐条 `trim`、丢空、截 60 字、空数组回 `QUOTE_TEXT_DEFAULT`。**原 `cfg.quotes` 的随机抽组（`groups`）与 `clickQueueOn` / `quoteMode` 已移除**，读取时丢弃，只有五个固定池迁进 `system`。
- **单泡结构** `WhaleBubbleBubble` = 行×模块两层：`modules[]` 经 `row` 键扁平化，行键 = 行下标 + 1（**单模块行与图片类行无 `row` 键**），`normBubbleModules` 保存时重建 `row` 键，设置页 `bubbleApplyRowLayout` 同口径镜像；行上限 `BUBBLE_ROW_MAX` 6、每行 `BUBBLE_MOD_MAX` 6；图片类模块（`image` / `randimg`）**独占一行并打断行合并**。
- **模块类型**（`BUBBLE_MOD_TYPES`）：`text, time, balance, bonus, recharge, today, peak, session, random, link, image, randimg, quota, plan`。`bonus` / `recharge` / `quota` / `plan` 等**数据源类**无数据时渲染「—」（实现全做、无源占位）。`time` 是**本插件自有扩展**（上游无此类型）：自动文本 = 按当前时段取「报时文案池」一句（`{t}` → `HH:MM`），套模板即成自定义报时，内容锁定、只留 `tpl` 可调。模块字号换算 `modFontU(size) = Math.round(40 + (n - 1) * 200 / 49)`（n clamp 1–50）。
- **模块字段**（`normBubbleMod` 清洗）：`type, size, color, rgb, bg, bgRgb, bold, italic, ul, fontFamily, row, tpl, text, lines, url, text2, imgId, imgs, imgScale, peakColor, offColor, peakRgb, offRgb, peakBg, offBgRgb, offBg, peakStyle, len, modelId, planWin`。`BUBBLE_PEAK_STYLES` = `mini|text|count`；`BUBBLE_PLAN_WINS` = `all|5h|week|month`；`BUBBLE_RGB_SCHEMES` 跑马灯配色方案（`['', 'macaron','candy','rouge','bamboo','aurora','deepsea','sunset','forest','champagne','lavender','mint','lava','galaxy','ink','indigo','blaze','amber']`）；`BUBBLE_FONT_FAMILIES`。
- **「已归位」与「空壳」的区别**：`text2` 与 `modelId` 属**空壳**，**别以为「白名单收了」功能就已实现**。判据 = 有无「数据源 + 渲染消费点」：
  - `text2`：`normBubbleMod` 收了它（能存、能过清洗、进备份），但**渲染侧零消费点**：`bubble-render.js` 不读、浮页 `bubbleModText` 只出主文本；要用得先定它与主文本的关系。
  - `modelId`：仅 `quota` 模块用到，浮页 `bubbleQuotaModuleText()` **无条件返 `'—'`** —— 模块是纯数据、不与模型绑定，额度按模型算、浮页也无模型快照。现状属「实现全做、无源占位」。要接上得给模块加「绑定哪个模型」字段。
  - 已归位三项（**别误当空壳**）：`imgId`（语义同 v1 台词 `img`：`''`/`'0'` 随机、`1..N` 指定第 N 张，浮页 `bubbleImgSrc(imgId)` 消费）、峰谷两态配色 `peakColor/offColor/peakRgb/offRgb/peakBg/offBg/offBgRgb`（渲染器经可选契约 `opts.modStyle(m)` 回调消费，宿主按 `state.isPeak` 回覆盖值）、模块底色 `bg/bgRgb`（渲染侧 `needBg` 消费，`bgRgb` 优先于 `bg`）。

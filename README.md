# 小鲸鱼余额挂件 · uTools 插件

桌面上一个透明、无边框、置顶的小鲸鱼挂件，常驻显示 **DeepSeek API 余额** 与 **今日已用**。移植自 DSH 版 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)，改为独立的 [uTools](https://u.tools) 插件（Vue 3 + Vite 6）。

## 特性

**余额与用量**

- 💰 **余额**：60 秒自动刷新（窗口隐藏时自动暂停，重新可见立即刷新）+ 点击鲸鱼手动刷新；余额变化时数字**滚动动画**；网络抖动自动沿用最近余额不报错
- 📊 **今日已用** 双模式：
  - **小鲸鱼记账（推荐，免令牌）**：余额差值本地记账，跨天自动归档（保留 30 天），切换币种只重置基准
  - **实时·令牌**：填平台网页令牌后按**峰谷定价**精确换算；令牌失效自动回落记账
- 🛡️ **记账防误判**：**赠送额度整块到期 / 被平台收回**、**短时间异常跳变**（默认 60 秒内 ¥20，间隔越久上限越宽，约每小时 +¥5）、**更换 API Key** 三种情况不会被误记成「今日用量」——判据分别取自余额接口的 `granted_balance`、间隔放宽的可信上限、API Key 的 sha1 前 8 位指纹（换 Key 只重置比较基准）。被拦下的变动会单列为「未计入的余额变动」，并在挂件气泡里解释一句
- 🎯 **手动校准今日已用**：记账漏采或误判后可一键改成真实金额（只改当天累计、留校准记录，**不动余额基准**，之后继续实时累加；令牌模式下以平台返回为准，无需校准）
- 📈 **近 7 天用量趋势**：设置页柱状图展示每日用量，支持**导出 / 导入 CSV**（UTF-8 BOM，Excel 直接打开）
- ⏰ **峰谷时段提醒**：进入峰时 / 谷时（北京时间，工作日 9–12、14–18 点为峰时）时，气泡提示当前时段与价格区间（可单独关闭）
- ⏱️ **计时 / 定时 / 倒计时**：在思考气泡里显示并每秒刷新 —— 正计时、按分钟倒计时、指定时刻定时；支持**暂停 / 继续 / 重置**，模式与参数（模式 / 分钟数 / 时刻 / 提醒时长）会被记住；到点响提示音、可选**系统通知**并弹出「时间到！」（停留时长可选 5 / 8 / 15 秒或常驻，跨天定时显示「明天 HH:MM」）；开启「记住计时状态」后重载插件仍继续计时
- 🫧 **计时气泡显示方式**（两个开关可自由组合）：「**只显计时**」开启时气泡只显示计时，关闭后计时期间气泡照常显示余额 / 今日用量等全部内容（计时状态变化时先弹 2 秒计时，再切回常规内容）；「**气泡常驻**」控制计时气泡是否自动收起
- ⚠️ **低余额预警**：余额低于可配阈值时，数字与「今日已用」变红提醒（开关 + 阈值可调）

**窗口与交互**

- 🐋 **桌面常驻小窗**：独立透明置顶窗口（置顶可关），不依附任何网页；透明区域**点击穿透**，不挡桌面操作
- 🫥 **窗口透明度**：20%–100%（设置页滑块**拖动实时预览** + 挂件菜单档位 100/80/60/40/20%），作用于整个窗口（含气泡与菜单）
- 🚫 **鼠标穿透**：开启后挂件**完全不接收鼠标**——点击 / 拖拽 / 菜单全部穿透给下层应用；在鲸鱼上**停留约 1 秒可临时接管**（此时可点、可拖、可开菜单），移开约 0.7 秒自动交回穿透。穿透中菜单按钮以半透明虚线常显作为提示，切换时弹一次说明气泡 + 系统通知
- 🖱️ **拖拽 + 四边四分之一吸附**（四角可组合），也可拖到屏幕中间**自由摆放**；贴左缘整体**水平镜像翻转**；**滚轮可直接缩放**挂件大小
- 🔒 **锁定位置**：开启后禁止拖拽与滚轮缩放，避免误拖误缩放；点击刷新照常可用
- 🧲 **任务栏避让 + 四边贴边间距**：可关的「自动避让任务栏」（**实时识别任务栏隐藏/显示** —— 收起时挂件贴满边，任务栏一弹出就自动让位，设置页会显示当前识别结果）；另有「贴边间距」（上/右/下/左，px，0＝紧贴）可自定义挂件与可用区四边的距离
- 🧸 **按压 Q 弹** + 按压 / 松手双段音效（音效开关与音色可选）；💬 **思考气泡**（含 rua.gif 随机台词，长文案自动缩放字号，不会撑出气泡）
- 🎵 **自定义音效**：按压 / 释放两段可分别导入（mp3 / wav / ogg / m4a / flac，单文件 ≤5MB，建议 1 秒左右），文件会**复制到本地数据目录**（不引用源文件，源文件删了也不影响）；释放音可缺（松手静音），按压音缺失时回退「小黄鸭」
- 🕐 **小鲸鱼报时**：点击鲸鱼时气泡首行报当前时间（鲸鱼娘语气，深夜 / 清晨换台词）

**设置与集成**

- 🔑 **凭据加密存储**（uTools `dbCryptoStorage`）；「测试连接」分项验证 **API Key**（余额接口）与**平台 Token**（用量接口）
- 🎚️ **挂件菜单**（悬停鲸鱼右上角按钮，或右键）：大小 / 音效 / 音量 / 透明度 / 用量 / 峰谷文案 / 气泡 / 峰谷提醒 / 报时 / 计时（含只显计时、气泡常驻） / 锁定 / dsh（开发者） / 打开设置
- ⌨️ **全局快捷键**：可为「显示/隐藏挂件」与「切换鼠标穿透」两条指令绑定 uTools 全局快捷键，触发时不弹出搜索框；后者是穿透开启后的**快捷逃生通道**（设置页「挂件窗口」里可直接跳转绑定）
- 🔀 **进入方式可选**：**设置窗口 + 挂件**（默认）/ **只显示挂件** / **只显示设置窗口**；选「只显示挂件」时点挂件菜单 →「打开设置」唤回设置窗口
- 🔄 **自动检查更新**：每次呼出插件检查一次（12 小时内最多一次），发现新版本弹出系统通知（可关闭）

**开发者集成（dsh，可选）**

- 🧩 **DeepSeek Harness 一键管理**：挂件菜单「dsh（开发者）」分组可直接 **启动 / 重启 / 结束 / 更新** dsh 并**打开 Web UI**（自动使用 dsh 打印的带 token 地址，不会停在「需要认证」）
- 🔍 **外部进程也能管**：按 `127.0.0.1:3080` 探测运行中的 dsh —— 在**别的终端里启动**的 dsh 也能被结束 / 重启（重启＝结束它，再按当前配置启动）；端口被**非 dsh 进程**占用时拒绝操作，不会误杀
- 🛡️ **权限兜底**：普通权限被系统拒绝（拒绝访问）时，自动改用管理员权限重试一次（会弹一次 UAC 确认）
- ⚙️ **可配置**：dsh **优先复用你已全局安装的那份**（零重复占用，终端里跑的和插件跑的是同一份），没有全局安装才装到插件数据目录；启动直接 `node` 跑它的 CLI，不经过 `npx`（不会产生缓存副本）。另有「启动时不自动打开浏览器」、npm 注册源（官方 / 淘宝镜像）、dsh 版本（默认「自动」＝安装/更新时取 `latest`，也可固定具体版本，可先拉取版本列表）、Node.js 目录（自动探测 PATH 与常见安装位置，也可手动指定）、更新前重新下载、uTools 退出后是否保留 dsh
- 💾 **备份与恢复**：一键导出「挂件设置 / 账本 / 窗口位置 / 计时」为一个 JSON 文件；凭据（API Key / Token）默认不导出，勾选后需设密码并用 scrypt + AES-256-GCM 加密写入；导入时列出备份内容、勾选要恢复的项，同名覆盖
- 📜 **运行日志**：带时间戳、自动清理 ANSI 转义并识别中文 Windows 的 GBK 输出；启动后显示「3080 已就绪（用时 x.xs）」与最近执行的命令，方便对照排查

## 环境要求

- [uTools](https://u.tools) 桌面端（开发调试需在 uTools 内安装官方「uTools 开发者工具」）
- Node.js 18+：仅本地开发与打包需要；**使用「dsh（开发者）」功能时本机也需要 Node.js**（插件会自动探测 PATH 与常见安装位置，也可在设置页手动指定目录）
- PowerShell / 任意终端（示例命令为 PowerShell 写法，其他 shell 等价）

## 安装

### 方式一：插件应用市场（推荐）

在 uTools 中搜索「插件应用市场」，搜 **小鲸鱼余额挂件** 安装即可。

### 方式二：本地开发（热更新）

```powershell
npm install
npm run dev      # Vite dev server，http://localhost:5173
```

在 uTools 中：打开 **开发者工具** → 新建项目，**插件入口目录选本项目的 `public/`** → 用指令 `余额挂件` / `小鲸鱼` 呼出。

设置页走 dev server 热更；**悬浮窗页面与 preload 不热更**，改动后需在 uTools 里**重新加载插件**。

### 方式三：打包安装

```powershell
npm run build      # 产物输出到 dist/
npm run typecheck  # 可选：vue-tsc --noEmit 类型检查
```

uTools 开发者工具中把插件入口目录指向 **`dist/`**。需要分发时可再「打包」为 `.upx`，拖入 uTools 主输入框即可安装。

## 配置

呼出插件后，主窗口即设置页。

1. **DeepSeek API Key（必需）**：[platform.deepseek.com](https://platform.deepseek.com) →「API keys」创建（`sk-` 开头）→ 粘贴到 **API Key** 框 →「保存凭据（加密存储）」。
2. **平台 Token（可选，仅「实时·令牌」用量模式）**：登录 [platform.deepseek.com](https://platform.deepseek.com) → `F12` → Network → 打开「用量」页 → 找 `usage/by_api_key/amount` 请求 → 复制其 Request Headers 里 `Authorization` 的值（形如 `Bearer eyJ...`，前缀可带可不带）→ 粘贴到 **平台 Token** 框保存。

令牌是网页会话，重新登录平台后可能失效（届时会自动回落记账模式）。填好后点「测试连接」可分别验证两项凭据。

## 使用

- **呼出**：`余额挂件` / `小鲸鱼` / `小鲸鱼余额` / `DeepSeek余额` / `whale`
- **点鲸鱼**：弹余额气泡 + 手动刷新 + 报时（气泡首行显示当前时间）；点气泡切随机台词，再点关闭（5 秒自动收起）
- **拖鲸鱼**：松手按屏幕 1/4 区吸附四边（四角可组合）、贴左镜像；拖中间则自由摆放
- **滚轮缩放**：指针停在鲸鱼上滚动即可放大 / 缩小（1–20 档），滚动时实时预览、停手后自动保存（**锁定位置时禁用**）
- **锁定位置**：菜单或设置页开启后禁止拖拽与滚轮缩放；点击刷新气泡不受影响
- **贴边间距**（设置页「挂件窗口」卡片）：上/右/下/左四个数值（0–400px，0＝紧贴该边），挂件吸附/贴到该边时按它留出距离；改了立即重摆（不用重启）。开着「自动避让任务栏」时，任务栏占位的那条边会自动让位，收起后回到这里设定的位置
- **调整透明度**：设置页「挂件窗口」拖动滑块（20%–100%，拖动时挂件实时预览、松手保存），或在挂件菜单「外观与音效 → 透明度」选档位（100/80/60/40/20%），两处共用同一设置
- **鼠标穿透**（设置页「挂件窗口」）：勾选后挂件**完全不接收鼠标**，点击 / 拖拽 / 菜单都穿透给下层应用。要操作挂件时，把鼠标**停在鲸鱼上约 1 秒**即可临时接管（菜单按钮会从虚线变实心），移开约 0.7 秒自动交回穿透；也可为「切换鼠标穿透」绑定全局快捷键一键开关（设置页该处有「复制指令名 / 新增快捷键」）。**注意**：穿透开启后挂件菜单也点不到，绑快捷键是最稳的退出方式（其次是在鲸鱼上停留接管后回设置页关闭）
- **自定义音效**（设置页「音色」选「自定义」后展开）：分别导入「按压音」（按下时播）与「释放音」（松开时接上，可缺），支持 mp3 / wav / ogg / m4a / flac，单文件 ≤5MB；文件复制到本机数据目录，删掉源文件不影响；未导入按压音时自动回退「小黄鸭」
- **校准今日已用**（设置页「近 7 天用量」卡片，仅记账模式显示）：记账漏采或误判后，填入真实金额点「校准」即可改当天累计；同时会显示「今日另有 ¥x 余额变动未计入用量」及原因（赠送额到期 / 异常跳变）与时间
- **悬停鲸鱼 → 右上角菜单按钮**：大小 / 音效开关 / 音色（含「自定义」）/ 音量 / 透明度 / 用量模式 / 峰谷文案 / 气泡 / 峰谷提醒 / 报时 / 计时 / 锁定 / dsh（开发者） / 打开设置（按钮本身可在设置页隐藏，隐藏后右键鲸鱼仍可打开菜单）
- **计时 / 定时 / 倒计时**：菜单「计时」选模式（正计时 / 倒计时 / 定时）→「目标」填分钟数或 `HH:MM`（已过点顺延到明天）→ 点「开始」，气泡立即显示并每秒刷新；按钮在开始时变「暂停」、暂停后变「继续」，「目标」行同时提供「重置」；点气泡收起不中断计时，再点鲸鱼重新显示；到点响提示音、可选弹系统通知并显示「时间到！」。菜单里的「到点通知」（含提醒停留时长：5 / 8 / 15 秒或常驻）「只显计时」「气泡常驻」「计时保存」分别控制**系统通知**、**计时是否独占气泡**、**计时气泡是否自动收起**与**重载插件后是否继续计时**。
- **dsh（开发者）**：悬停鲸鱼 → 右上角菜单 →「dsh（开发者）」分组：`启动` / `重启` / `结束` / `更新` 四个按钮 + `打开页面`（自动使用 dsh 打印的带 token 地址），下面两行显示**运行状态**（未运行 / 运行中 · pid / 外部 dsh · pid / 启动中…）与**最近执行的命令**。启动后 3080 就绪前显示「启动中…」，方便区分「还在下载」与「已经跑起来」。
- **dsh 设置页**：「DeepSeek Harness（dsh）」卡片可配置 npm 注册源、dsh 版本（默认「自动」＝安装/更新时取 `latest`，也可固定成某个具体版本；先「查询可用版本」再选，下拉里会标出**已安装**的版本，查询结果会缓存，重载插件后依然可选）、Node.js 目录（「选择目录」或「改为自动探测」）、是否在启动时带 `--no-open`（勾选＝启动后不自动弹浏览器，用「打开 Web UI」查看）、更新前重新下载（仅在用插件目录那份时生效）、uTools 退出后是否保留 dsh；卡片里还能看到**插件目录 / 全局安装 / 实际使用（含来源）**、**最新**、**状态 / 最近命令 / 页面地址**，并支持**复制地址 / 查看日志 / 复制日志**。
- **设置页**：显示 / 隐藏挂件；「复制指令名」「新增快捷键」用于绑定全局快捷键；进入设置页时自动检查挂件状态，仅在创建失败时展开红色错误详情与「复制错误信息」按钮，平时只显示一行浅色「挂件异常？查看错误详情」链接
- **全局快捷键**：按 `Ctrl+,` 打开 uTools 设置 → **全局功能** → 新增 → 指令填「显示/隐藏挂件」（可点设置页「复制指令名」快速复制）→ 按下组合键。若绑定被删除，点「新增快捷键」可直接跳转重新添加（注意每次点击都会新增一条待绑定项）

## 数据与隐私

- **存了什么**：API Key 与平台 Token（uTools `dbCryptoStorage` 加密）、挂件设置、本地账本（用量 / 余额基准 / 校准与「未计入」记录）、计时状态（开启「记住计时状态」时）、窗口位置与更新缓存，以及导入的**自定义音效文件**（复制到插件数据目录 `userData/whale-sounds/`），全部只保存在本机，不会上传到第三方服务器；除余额接口（`api.deepseek.com`）、用量接口（`platform.deepseek.com`）与更新检查（GitHub raw）外无任何外部请求。
- **导出 / 导入账本**：设置页「近 7 天用量」卡片右上角可在 CSV 与账本之间互转（日期 / 用量 / 币种三列，带 BOM，Excel 直接打开）；导入按日期合并（同日覆盖），只保留最近 30 天。
- **卸载不删数据**：在 uTools 里移除插件**不会**自动清除上述数据。设置页「数据与隐私」可**勾选要清除的项目**（凭据 / 挂件设置 / 账本用量记录 / 窗口位置与更新缓存 / 自定义音效），点「清除选中数据」并二次确认后只清除勾选项（确认时会列出**将清除哪些项**）；清除挂件设置或窗口位置后会按默认值重建挂件，只想重置挂件外观时不必重填凭据；清除自定义音效会删掉导入的音频文件，并把音色一并回退为「小黄鸭」（其余设置不动，所以不会只剩一个没有音源的「自定义」）。
- **备份与恢复**（设置页「数据与隐私」→「备份与恢复」）：
  - 导出会把「挂件设置 / 账本 / 窗口位置 / 计时」写成一个 JSON 文件（不含 dsh 开发者配置与 Node 路径）。
  - **凭据默认不导出**；勾选「包含凭据」后必须设密码（≥6 位），凭据用 **scrypt 派生密钥 + AES-256-GCM** 加密后才写入文件——文件里没有明文，改一位就解不开；密码不保存在任何地方，忘记只能放弃凭据（其余项仍可恢复）。
  - 导入时先读取备份并列出「导出时间 / 插件版本 / 包含项」，勾选要恢复的项后写入（**同名覆盖**，账本同日覆盖并保留最近 30 天）；恢复「挂件设置」或「窗口位置」会重建一次挂件，立即生效。
  - 备份文件本身含你的设置与用量记录（凭据除外为加密块），请妥善保管。
- **dsh 相关**：只在本机执行（`node` 运行 dsh / 需要时用 `npm` 安装或更新它 / `taskkill`），不会把任何内容发到第三方服务器。dsh 的输出日志**仅保存在内存**（最多 160 行，供设置页查看），重新加载插件即清空；「打开页面」所用带 token 的地址取自 dsh 自身的输出，同样只存内存、不写入本地存储。dsh 自己的配置与数据由 dsh 管理（默认在用户目录 `~/.dsh`），本插件不做改动。

## 常见问题

- **挂件不出现**：确认入口目录（dev = `public/`，打包 = `dist/`）；点设置页「显示挂件」；点「挂件异常？查看错误详情」看宿主记录的失败原因并复制，或主窗右键 → 检查看 `[whale][widget]` 日志。
- **悬浮窗调试**：焦点在挂件窗口上按 `Ctrl+Shift+I`。
- **开启鼠标穿透后挂件点不动**：这是预期行为（连挂件菜单也穿透了）。用「切换鼠标穿透」全局快捷键关掉，或把鼠标**停在鲸鱼上约 1 秒**临时接管后，从挂件菜单「打开设置」回设置页关闭。建议先在设置页「挂件窗口 → 鼠标穿透」处点「新增快捷键」绑好，再开启穿透。
- **听不到自定义音效**：确认「音效开关」为开、音量不为 0、音色选的是「自定义」且**已导入「按压音」**（未导入时会回退「小黄鸭」）；只导入按压音、没导入释放音时，松手那一下是静音（这是预期）。若导入的是 flac/m4a 而系统解不了码，换 mp3 / wav 再试。
- **今日已用突然变大**：v1.4.0 起「赠送额度整块到期 / 被平台收回」与「短时间异常跳变」不会再计入；若仍异常，说明下降幅度落在可信范围内被判成了消费，可用设置页「近 7 天用量」卡片的「校准今日已用」改成真实金额（会留校准记录），并把「今日另有 … 未计入用量」那行提示一起反馈回来。
- **透明度调了没反应 / 挂件整窗看不见**：请确认版本为 v1.4.0 且已在 uTools 里**重新加载插件**（preload 与 `floating.css` 都不热更）。旧实现用窗口级 `setOpacity`，在 Windows 的分层透明窗上会导致整窗不显示，v1.4.0 已改为页面 CSS 透明度。
- **401 API Key 无效**：确认填的是 `sk-` 开头的 **API Key**（不是平台 Token）；用「测试连接」看服务器原文。
- **今日已用显示 `--`**：记账模式需先有一次余额观测（60 秒内）；令牌模式需配好平台 Token，失败会回落记账。
- **峰谷提醒不出现**：提醒依赖**思考气泡**，需同时开启「思考气泡」与「峰谷切换提醒」；且只在时段**切换**的瞬间提示一次，刚启动时不会补弹。
- **计时到点没声音 / 没通知**：提示音走挂件音效，需「音效开关」为开且音量不为 0；系统通知由「计时到点通知」开关控制（关闭时只响提示音 + 气泡）。挂件窗口在后台被系统节流时，到点可能略有延迟，切回挂件即会立即补响。
- **重载插件后计时没了**：确认「记住计时状态」为开；关闭后计时只在本次运行内有效。
- **没声音**：音量不为 0；Electron 首次需先有一次交互。
- **改了 preload 不生效**：preload 不热更，需在 uTools 开发者工具里重新加载插件。
- **dsh 提示「未找到 Node.js」**：设置页「DeepSeek Harness」→「选择目录」指定 Node.js 安装目录（如 `D:\nodejs`），或点「改为自动探测」；卡片里会显示实际生效的目录与版本。
- **dsh 提示 3080 端口被占用**：说明已有 dsh 在运行（可能是在别的终端里启动的）。点「结束」或「重启」即可接管；若占用端口的是**非 dsh 程序**，插件会拒绝操作并提示，避免误杀。
- **点「结束」提示「权限不足 / 拒绝访问」**：那个 dsh 是**管理员权限**启动的。插件会自动改用管理员权限重试（弹一次 UAC 确认框）；也可以管理员身份运行 uTools，或直接在 dsh 自己的终端里按 `Ctrl+C`。
- **打开页面提示 authentication required**：dsh 的 Web UI 首次访问需要带 `?token=` 的地址。由插件启动的 dsh 会自动捕获该地址（设置页「页面地址」可查看 / 复制）；外部终端启动的 dsh 请使用它自己打印的地址，或在插件里「重启」一次以接管。
- **dsh 首次启动很慢 / 「启动中…」很久**：首次会自动下载安装（约 500 多个包，之后启动就快了）；国内建议把「npm 注册源」改成淘宝镜像。启动完成后状态会变成「运行中」，并在日志里记录「3080 已就绪（用时 x.xs）」。
- **结束 dsh 后 dsh 又起来了**：说明它有守护进程 / 你是在某个会自动重启它的工具里启动的，请在它自己的终端里 `Ctrl+C` 关闭。

- 新增「**只显计时**」「**气泡常驻**」开关：计时期间气泡可只显示计时，也可照常显示余额 / 今日用量等全部内容（计时状态变化时先弹 2 秒计时，再切回常规内容）
- 思考气泡按内容自适应：长文案自动等比缩小字号、不再撑出气泡（报时 / 余额等常规内容同样生效）
- 新增**「dsh（开发者）」集成**：挂件菜单与设置页可直接 **启动 / 重启 / 结束 / 更新** DeepSeek Harness（`dsh web`）并打开 Web UI（自动使用 dsh 打印的带 token 地址）
- **结束 / 重启支持外部终端启动的 dsh**（按 `127.0.0.1:3080` 探测；端口被非 dsh 进程占用时拒绝操作）；普通权限被拒时自动提权重试（UAC）
- dsh 可配置：运行方式（`npx` / 全局安装）、npm 注册源（官方 / 淘宝镜像）、指定版本（可先查询版本列表）、Node.js 目录（自动探测 / 手动指定）、更新前清理 npx 缓存、uTools 退出后保留进程
- 修复「实时·令牌」模式下刷新今日总量后，设置页近 7 天用量不更新、当天柱与挂件显示不一致的问题
- 修复：只选计时模式未开始却重载插件就误报「时间到」；三点菜单被长文本撑宽、面板顶部圆角被裁成直角
- 体验：气泡圆圈整体放大 18%（长文案不再一味缩小到看不清）；计时每秒只刷新时钟文本；设置页打开即自动探测 dsh 状态（并每 4 秒刷新）

# 小鲸鱼余额挂件 · uTools 插件

## 特性

**余额与用量**

- 💰 **余额**：60 秒自动刷新（窗口隐藏时自动暂停，重新可见立即刷新）+ 点击鲸鱼手动刷新；余额变化时数字**滚动动画**；网络抖动自动沿用最近余额不报错
- 📊 **今日已用** 双模式：
  - **小鲸鱼记账（推荐，免令牌）**：余额差值本地记账，跨天自动归档（**保留期可配，默认 365 天**，35–730 天；趋势图的 7 / 14 / 30 天档位与导出 / 导入 CSV 的区间上限都跟着它走）
  - **实时·令牌**：填平台网页令牌后按**峰谷定价**精确换算；令牌失效自动回落记账
- 🛡️ **记账防误判**：**赠送额度整块到期 / 被平台收回**、**短时间异常跳变**（默认 60 秒内 ¥20，间隔越久上限越宽，约每小时 +¥5）、**更换 API Key** 三种情况不会被误记成「今日用量」——判据分别取自余额接口的 `granted_balance`、间隔放宽的可信上限、API Key 的 sha1 前 8 位指纹（换 Key 只重置比较基准）。被拦下的变动会单列为「未计入的余额变动」，并在挂件气泡里解释一句
- 🎯 **手动校准今日已用**：记账漏采或误判后可一键改成真实金额（只改当天累计、留校准记录，**不动余额基准**，之后继续实时累加；令牌模式下以平台返回为准，无需校准）
- 📈 **用量与账本**：设置页柱状图可选 **7 / 14 / 30 天**（不超过账本保留期，保留期调小后档位跟着减少），下方给出**本月汇总**（本月累计 / 日均（按已过天数摊）/ 最高单日 / **累计已用**）；支持**导出 / 导入 CSV**（UTF-8 BOM，Excel 直接打开）
- 🔎 **账本明细与筛选**（设置页「用量与账本」卡片，可折叠）：展开后按日列出每日用量，并标出当天「**未计入用量的余额变动**」（赠送额到期 / 异常跳变，红色标签）与「**手动校准**」记录（灰色标签）；点某天展开可见**每条变动的时间与原因**。筛选有两件套：**类型下拉**（全部记录 / 只看未计入 / 只看校准）与**关键词检索**（日期或原因，如 `09-12`、`到期`）——命中做到**条目级**，整天没有命中条目就整天不显示，且命中的天会**自动展开**，不用再一天天点开找是哪条。区间跟随上方 7 / 14 / 30 天档位，明细日志跨天保留天数**跟随「历史保留」设置**（默认 365 天）
- 🥧 **今日模型占比**（设置页「用量与账本」卡片，**仅实时·令牌模式**）：按模型列出今日金额占比（占比条 + 百分比 + 金额），行尾合计与标题行「共 ¥x」一致；模型名显示**友好名称**（如 `deepseek-v4-flash` → DeepSeek V4 Flash），鼠标悬浮可见原始模型 id；模型明细只有平台用量接口会给，记账模式拿不到，故该块只在令牌模式出现
- 🎫 **额度进度**（设置页「用量与账本」卡片）：填「资源包 / 订阅」总量（元）并选**每月重置 / 每日重置 / 不重置**，即显示「已用 / 总量 · 剩余（百分比）」进度条（≥90% 换暖色）；已用按所选周期从账本现算（不重置 = 累计已用），**只做展示**，不影响余额、记账与预警口径
- 🧩 **多厂商余额 / 额度**（设置页「模型与余额」卡片，v1.5.0 新增）：除内置 DeepSeek 外**最多再添加 9 个模型**（合计 10 个），可**在挂件菜单里切换主显示** —— 余额型显示原币种余额（附「~今日已用」，按相邻两次余额差估算），额度型（订阅）显示**剩余百分比**与重置时刻。内置 11 个厂商模板（OpenRouter / Moonshot 大陆站与国际站 / 阶跃星辰 / Novita / 智谱 GLM Coding / Kimi Coding / MiniMax Coding / OpenAI 兼容中转站 / 自定义 HTTP），只收录**能用 API key 直接查到余额或订阅额度**的厂商；余额按厂商币种显示（`¥ ` / `$`），低余额预警阈值也按币种分开（人民币 10 / 美元 2）。切回 DeepSeek 时余额与今日已用照常刷新，其它模型不参与记账、不写账本
- 🧾 **Codex 订阅窗口**（v1.5.0 新增）：装了 Codex CLI 的机器上，直接读它自己写的本地会话日志（`~/.codex/sessions` 下的 rollout JSONL）里的 `rate_limits`，取出 **5 小时窗口 / 周窗口**的已用百分比与重置时刻 —— **不用配 Key、不发请求、不碰账号**。窗口跟着 Codex 那一条一起出现在挂件上（说明行「已用 5h 62% · 周 31%」）与设置页「dsh」Tab 的 Codex 卡片里；窗口名优先按日志给的窗口分钟数推断，给不出来才按位置叫「5h / 周」（各版本 Codex 给的值不一样）。解析结果按文件 size / mtime **增量缓存**（会话日志几十 MB，不缓存会每次全量读）
- ⏰ **峰谷时段提醒**：进入峰时 / 谷时（北京时间，工作日 9–12、14–18 点为峰时）时，气泡提示当前时段与价格区间（可单独关闭）；峰谷台词第三行还会显示**距下次切换的倒计时**（如「距峰时 1h20m」），切换时刻由宿主按同一套峰谷规则算出后下发
- ⏱️ **计时 / 定时 / 倒计时**：在思考气泡里显示并每秒刷新 —— 正计时、按分钟倒计时、指定时刻定时；支持**暂停 / 继续 / 重置**，模式与参数（模式 / 分钟数 / 时刻 / 提醒时长）会被记住；到点响提示音、可选**系统通知**并弹出「时间到！」（停留时长可选 5 / 8 / 15 秒或常驻，跨天定时显示「明天 HH:MM」）；开启「记住计时状态」后重载插件仍继续计时
- 🫧 **计时气泡显示方式**（两个开关可自由组合）：「**只显计时**」开启时气泡只显示计时，关闭后计时期间气泡照常显示余额 / 今日用量等全部内容（计时状态变化时先弹 2 秒计时，再切回常规内容）；「**气泡常驻**」控制计时气泡是否自动收起
- ⚠️ **低余额预警**：余额低于可配阈值时，数字与「今日已用」变红提醒，并弹一次提醒气泡 + **每天弹一次系统通知**（开关 + 阈值可调；阈值单位**跟随账本币种**显示「元 / 美元」，默认值按币种取——人民币 10 / 美元 2，与多厂商模型的阈值口径一致）
- 📉 **余额大幅波动通知**：可设「下降阈值」（元），单次采样余额下降 ≥ 阈值就弹一次系统通知（**不做每天一次去重** —— 每次下降只采样到一次，不会重复刷屏）；文案会区分「正常消费」与「被防误判拦下的变动」。同样受免打扰时段约束
- 🎯 **今日预算提醒**：可设**每日预算**金额，当天用量超出时气泡提醒一次 + 第三行常驻「超预算 ¥x」，并**每天弹一次系统通知**（可关闭；金额为 0 视为未设置，打开开关时会自动补一个默认值）
- ⏳ **提醒停留时长可调**：峰谷切换 / 今日预算 / 低余额 / 穿透说明几类提醒气泡可选 **常驻 / 5 / 8 / 15 秒**（默认 8 秒）
- 🌙 **免打扰时段**：可设一段（如 `23:00–07:00`，**支持跨午夜**）只弹气泡、**不弹系统通知**的时间；时段内不占用当天提醒名额，出时段后仍会补发一次（计时到点是你主动设的一次性提醒，不受影响）

**窗口与交互**

- 🐋 **桌面常驻小窗**：独立透明置顶窗口（置顶可关），不依附任何网页；透明区域**点击穿透**，不挡桌面操作
- 🫥 **窗口透明度**：20%–100%（设置页滑块**拖动实时预览** + 挂件菜单档位 100/80/60/40/20%），作用于整个窗口（含气泡与菜单）
- 🚫 **鼠标穿透**：开启后挂件**完全不接收鼠标**——点击 / 拖拽 / 菜单全部穿透给下层应用；在鲸鱼上**停留约 1 秒可临时接管**（此时可点、可拖、可开菜单），移开约 0.7 秒自动交回穿透。穿透中菜单按钮以半透明虚线常显作为提示，切换时弹一次说明气泡 + 系统通知
- 🖱️ **拖拽 + 四边吸附**（四角可组合）：松手时挂件中心落进某条边的吸附区就贴到那条边，落进中间区则**自由摆放**；**吸附区宽度可调**（1–45%，默认 25%＝左右各 1/4）也可**关闭吸附**；朝向自动**水平镜像翻转**（锚在屏幕左半边朝右、右半边朝左，自由摆放同样生效）；**滚轮可直接缩放**挂件大小
- 🔒 **锁定位置**：开启后禁止拖拽与滚轮缩放，避免误拖误缩放；点击刷新照常可用
- 🧲 **任务栏避让 + 四边贴边间距**：可关的「自动避让任务栏」（**实时识别任务栏隐藏/显示** —— 收起时挂件贴满边，任务栏一弹出就自动让位，设置页会显示当前识别结果）；另有「贴边间距」（上/右/下/左，px，0＝紧贴）可自定义挂件与可用区四边的距离
- 🧭 **一键复位窗口位置**：换显示器、改分辨率或把挂件拖出屏幕后，点设置页「复位窗口位置」即可把挂件挪回右下角默认位置
- 🧸 **按压 Q 弹** + 按压 / 松手双段音效（音效开关与音色可选）；💬 **思考气泡**（含 rua.gif 随机台词，长文案自动缩放字号，不会撑出气泡）
- 🐳 **挂件形象可选 + 形象画廊**：**13 张内置形象**（默认 `DSniang1`，即挂件本体；下拉里以图片文件名列出） / **自定义**（导入自己的图片：png / jpg / jpeg / webp / gif / apng，单文件 ≤5MB；图片会**复制到本地数据目录**，删掉源图不影响）。「资源」Tab 里是**缩略图网格**（v1.5.0 新增）：点缩略图即切换、可**置顶**（挪到第一位）与**删除**，当前使用中的那张带角标；删掉当前那张会自动顺延到剩余第一张，全删光则回退默认形象。最多存 20 张。导入时可**框选裁剪**（可一键「自动裁掉透明边」，导出为保留透明通道的 PNG）；**GIF / APNG 不做裁剪、原样复制**，保住动画。换形象后**透明区点击穿透的轮廓会按新图重算**，换成形状差异大的图也能正常穿透
- 🖼️ **自定义气泡图**（设置页「资源」Tab → 「导入的气泡图」，v1.5.0 新增）：导入自己的图片（png / jpg / jpeg / webp / gif / apng，单文件 ≤5MB），点小鲸鱼抽到「气泡图」那组台词时**从图里随机显示一张**。**一律原样复制、不裁剪不重编码**（气泡里放的多是动图或整图，过一次 canvas 就把动画帧丢了），图片会**复制到本地数据目录**，删掉源图不影响。最多 8 张，且**没有「当前用哪张」** —— 有图就随机抽、删光就回退内置 `rua.gif`，所以网格里只有缩略图与「删」（没有「使用中」角标与「置顶」）
- 🎨 **气泡主题**：默认（蓝白）/ 深色 / 樱花三套配色预设，只改气泡与文字颜色（**「低余额」的红色是状态色，不随主题变**）
- 🎵 **自定义音效**：按压 / 释放两段可分别导入（mp3 / wav / ogg / m4a / flac，单文件 ≤5MB，建议 1 秒左右），文件会**复制到本地数据目录**（不引用源文件，源文件删了也不影响）；导入时可**看波形拖选一段**（最多 10 秒，可先试听选区，导出为 WAV）并在设置页**试听**已导入的音效；释放音可缺（松手静音），按压音缺失时回退「小黄鸭」
- 🔔 **提醒音效**（v1.5.0 新增）：低余额 / 今日预算 / 峰谷切换 / 鼠标穿透四类提醒可各导一段提醒音。与音色不同，**留空即静音**（不打扰是默认）、**不受「音色」下拉影响**，只要「音效开关」为开、音量不为 0 就会响
- 🔁 **音效组**（v1.5.0 新增）：六个槽位（音色两段 + 四类提醒音）每个都能导**多段**（不再是「再导一段就覆盖前一段」），挂件每次随机播一条、且**不会连续重复同一条**；删到只剩一段就固定播它，删光按该槽位规则回落（音色回内置小黄鸭、四类提醒音静音）。老数据（每槽位一段）读取时**自动升级**，不用手动迁移
- 🗂️ **素材集中管理**（设置页「资源」Tab，v1.5.0 新增）：形象 / **气泡图** / **六段音效**（音色两段 + 四类提醒音）的导入 / 试听 / 删除都在这里，每项显示**体积与导入时间**；**不随「形象 / 音色」的选择隐藏** —— 切回内置形象或音色后素材仍列在这里、随时可删。卡片头有**「清除未使用（n）」**（只删当前设置不会用到的素材，正在使用的一律保留）与**「清除全部素材」**（只删素材、不动其它设置）；下方**素材包**把导入的形象 / 气泡图 / 音效打包成一个 `.whaleassets` 文件，换机器时一键带走；还有**内置资源对照**（内置形象与两组内置音色，可预览 / 试听，随插件附带、不可删）
- 🕐 **小鲸鱼报时**：点击鲸鱼时气泡首行报当前时间（鲸鱼娘语气，深夜 / 清晨换台词）
- 🔀 **点按依次播放台词**：开启后点气泡按**顺序**播放各台词组（每点一次切下一组，播完最后一组才收起），关闭则每次随机一组（默认关闭）
- 📝 **台词库可配置**（设置页「文案」卡片的「台词库」分组）：随机台词是**可增删的组列表** —— 每组可选**类型**（余额/时段卡 / 自定义台词 / 气泡图）、填**权重**（1–999，越大越常抽到）、文本组还能选字号（普通字号会折行 / 大字号不折行），并用「↑ / ↓」调出场次序（「依次播放」按这个顺序走）；另有**报时文案**（`{t}` 占位符）与**动图降级文案**两项不走抽签的固定文案。台词**一行一条**，最多 12 组；「保存」后立即生效，「恢复默认」填回内置六组；**台词留空的文本组保存后会被丢掉**（等于这组不出现，不会悄悄变回内置台词）
- ✏️ **提醒文案可编辑**（设置页「文案」卡片的「提醒文案」分组）：低余额 / 今日预算 / 峰谷切换 / 鼠标穿透四类提醒的**气泡与系统通知共用同一份文案**，六条都能改。**最多三行**，依次对应气泡的「标题 / 大字 / 说明」（行数不够后面的行留空，多于三行的并进说明行），系统通知取全文并把换行合并成一行；支持 `{balance}` `{threshold}` `{used}` `{budget}` `{over}` `{schedule}` 占位符，写错的会原样显示出来；「保存」后立即生效，「恢复默认」填回内置文案；清空某一条 = 该条恢复内置默认。注：多厂商模型的余额通知带模型名，不受这里影响

**设置与集成**

- 🔑 **凭据加密存储**（uTools `dbCryptoStorage`）；「测试连接」分项验证 **API Key**（余额接口）与**平台 Token**（用量接口）
- 🎚️ **挂件菜单**（悬停鲸鱼右上角按钮，或右键）：大小 / 音效 / 音量 / 透明度 / **模型**（切换主显示 / 刷新余额，只添加过模型才出现）/ 用量 / 峰谷文案 / 气泡 / 峰谷提醒 / 报时 / 计时（含只显计时、气泡常驻） / 锁定 / dsh（开发者） / 打开设置 / 隐藏挂件

**开发者集成（dsh，可选）**

- 🧩 **DeepSeek Harness 一键管理**：挂件菜单「dsh（开发者）」分组可直接 **启动 / 重启 / 结束 / 更新** dsh 并**打开 Web UI**（自动使用 dsh 打印的带 token 地址，不会停在「需要认证」）

- ⚙️ **可配置**：dsh **优先复用你已全局安装的那份**（零重复占用，终端里跑的和插件跑的是同一份），没有全局安装才装到插件数据目录；启动直接 `node` 跑它的 CLI，不经过 `npx`（不会产生缓存副本）。另有「启动时不自动打开浏览器」、npm 注册源（官方 / 淘宝镜像）、dsh 版本（默认「自动」＝安装/更新时取 `latest`，也可固定具体版本，可先拉取版本列表）、Node.js 目录（自动探测 PATH 与常见安装位置，也可手动指定）、更新前重新下载、uTools 退出后是否保留 dsh

## 配置

呼出插件后，主窗口即设置页。设置页按主题分 **7 个顶部 Tab**：**外观**（大小 / 形象与音色 / 文案）、**资源**（素材总览 / 形象画廊 / 气泡图 / 音效 / 素材包）、**用量**（趋势与账本 / 模型余额 / 提醒与通知）、**窗口**（显隐 / 位置 / 透明度 / 穿透）、**数据**（凭据 / 清除数据 / 备份与恢复）、**帮助**（使用说明 / 故障排查 / 关于与更新）、**dsh**（DeepSeek Harness / Codex 会话统计），Tab 条吸顶、下方一行小字说明本组内容。

## 使用

- **呼出**：`余额挂件` / `小鲸鱼` / `小鲸鱼余额` / `DeepSeek余额` / `whale`
- **点鲸鱼**：弹余额气泡 + 手动刷新 + 报时（气泡首行显示当前时间）；点气泡切随机台词组，再点关闭（5 秒自动收起）。开启设置页「点按依次播放」后改为**依次播放各组台词**（每点一次切下一组，播完才收起）
- **拖鲸鱼**：松手时挂件中心落进某条边的吸附区就贴到那条边（四角可组合），落进中间区则自由摆放；吸附区宽度与开关见下面「吸附与翻转」
- **滚轮缩放**：指针停在鲸鱼上滚动即可放大 / 缩小（1–20 档），滚动时实时预览、停手后自动保存（**锁定位置时禁用**）
- **锁定位置**：菜单或设置页开启后禁止拖拽与滚轮缩放；点击刷新气泡不受影响
- **吸附与翻转**（设置页「挂件窗口」卡片）：下拉选「比例吸附 / 关闭（自由摆放）」，「吸附区宽度」（1–45%，默认 25）决定松手时离边多近才吸走 —— 默认 25% 即左右各 1/4、上下各 1/4；选「关闭」则停在哪就是哪（位置仍会被记住、下次原样还原）。朝向（水平镜像）**不单独配**：锚在屏幕左半边朝右、右半边朝左，贴边与自由摆放共用这一条，鲸鱼始终朝屏幕内侧
- **贴边间距**（设置页「挂件窗口」卡片）：上/右/下/左四个数值（0–400px，0＝紧贴该边），挂件吸附/贴到该边时按它留出距离；改了立即重摆（不用重启）。开着「自动避让任务栏」时，任务栏占位的那条边会自动让位，收起后回到这里设定的位置
- **复位窗口位置**（设置页「挂件窗口」卡片）：点「复位窗口位置」把挂件挪回**右下角默认位置**。换显示器、改分辨率或把挂件拖出屏幕导致找不到时用它，比重装插件省事
- **调整透明度**：设置页「挂件窗口」拖动滑块（20%–100%，拖动时挂件实时预览、松手保存），或在挂件菜单「外观与音效 → 透明度」选档位（100/80/60/40/20%），两处共用同一设置
- **鼠标穿透**（设置页「挂件窗口」）：勾选后挂件**完全不接收鼠标**，点击 / 拖拽 / 菜单都穿透给下层应用。要操作挂件时，把鼠标**停在鲸鱼上约 1 秒**即可临时接管（菜单按钮会从虚线变实心），移开约 0.7 秒自动交回穿透；也可为「切换鼠标穿透」绑定全局快捷键一键开关（设置页该处有「复制指令名 / 新增快捷键」）。**注意**：穿透开启后挂件菜单也点不到，绑快捷键是最稳的退出方式（其次是在鲸鱼上停留接管后回设置页关闭）
- **自定义音效**（设置页「资源」Tab → 「导入的音效」）：分别导入「按压音」（按下时播）与「释放音」（松开时接上，可缺），支持 mp3 / wav / ogg / m4a / flac，单文件 ≤5MB；文件复制到本机数据目录，删掉源文件不影响；未导入按压音时自动回退「小黄鸭」。**导入时可裁剪**：选完文件会弹出波形图，拖两端手柄选一段（最多 10 秒）、点「试听选区」确认效果，确定后导出为 WAV 再落盘（中途取消不会留下半成品文件）；已导入的音效可点「试听」按当前音量直接听。**同一槽位可导多段**（音效组）：挂件每次随机播一条、不会连着重复同一条，删到只剩一段就固定播它
- **提醒音效**（设置页「资源」Tab → 「导入的音效」）：低余额 / 今日预算 / 峰谷切换 / 鼠标穿透四类提醒可各导一段提醒音，导入方式与按压音相同（可裁剪、可试听、**同样可导多段随机播**）。**留空即静音** —— 与音色不同，这四段没有内置回落；播放只看「音效开关 + 音量」，**不受「音色」下拉影响**
- **自定义气泡图**（设置页「资源」Tab → 「导入的气泡图」）：点「＋ 导入」挑一张图片（png / jpg / jpeg / webp / gif / apng，≤5MB），**不裁剪、原样复制**（动图保住动画），导入即参与随机；网格里只有缩略图与「删」（**没有「使用中」角标与「置顶」** —— 气泡图不选「当前用哪张」，有图就随机抽、删光回退内置 `rua.gif`），最多 8 张
- **挂件形象 / 气泡主题**（设置页「挂件外观」卡片）：「形象」下拉可选内置形象 / 「自定义」；**选「自定义」而还没导入图片时，下方会给一行提示指向「资源」Tab**（此时回退内置鲸鱼娘）。自定义形象的导入 / 删除 / 切换都在「资源」Tab 的「导入的形象」里（**缩略图网格**，v1.5.0 起）：点「＋ 导入」挑一张图片（png / jpg / jpeg / webp / gif / apng，≤5MB，不收 SVG），**静态图会弹出裁剪框**（拖四角 / 四边改范围、框内拖动平移，也可一键「自动裁掉透明边」，确定后导出为 PNG 保留透明通道），**GIF / APNG 不裁剪、原样复制**以保住动画；导入后立即生效并自动切到这张。网格里点缩略图即切换、角标标出「使用中」，「置顶」把该张挪到第一位，「删」删掉该张（删的是当前那张时自动顺延到剩余第一张，全删光则回退默认形象），最多存 20 张。「气泡主题」可选默认（蓝白）/ 深色 / 樱花，改完立即生效（低余额的红色不变）
- **素材集中管理**（设置页「资源」Tab，v1.5.0 整理后从「挂件外观」卡整块移出）：**五张卡** —— 「资源概览」（形象 / 气泡图 / 音效的项数与占用体积，含「清除未使用（n）」「清除全部素材」与折叠的**素材包**）、「导入的形象」（缩略图网格）、「导入的气泡图」（缩略图网格）、「导入的音效」（六个槽位，每项显示文件名、**体积与导入时间**，可「导入 / 试听 / 删除」）、「内置资源」（随插件附带的内置形象与两组内置音色，可预览 / 试听，**不可删**，只作对照）。与「挂件外观」的分工：那边只管**用哪个**（内置还是自定义），这里管**导了什么、占多大、要不要删**。这个 Tab **不跟着形象 / 音色的选择隐藏** —— 切回内置形象或音色后，导入的素材仍列在这里、随时可删（早先会整块消失，磁盘上却还占着）；素材在、但设置没在用时会各给一行提示，免得以为导入没生效。两个清除按钮的区别：「清除未使用」只删当前设置**不会用到**的素材（画廊里没在用的形象、已关掉的提醒音等），正在使用的一律保留（**气泡图不参与这个统计** —— 有图就会被随机抽到，只能靠「清除全部素材」删）；「清除全部素材」把导入的形象 / 气泡图 / 音效全删掉并把形象 / 音色回退为内置。两者都只动素材、不影响其它设置
- **素材包**（设置页「资源」Tab · 资源概览内的折叠区）：点「导出素材包…」把导入的形象 / 气泡图 / 音效打包成一个 `.whaleassets` 文件（单文件，**不压缩**，内容只有图片与音频本体）；换机器时点「导入素材包…」选中该文件 → 列出包内条目、勾选要写入的项（形象 / 气泡图 / 音效三个复选框，按包内有无该类别自动预勾 / 禁用）→ 「导入选中项」即可。**形象与气泡图是追加**（每张都进画廊 / 网格，不动当前正在用的那张）、**音效是同槽位覆盖**（同名槽位会被替换，按钮上会二次确认）；选中非素材包文件或版本过新的包会直接拒绝并说明原因
- **台词库**（设置页「文案」卡片 · 「台词库」分组）：六组文案各一个输入框，**一行一条**（保存时自动去空行、单条最多 60 字、每组最多 30 条）——短句（余额气泡第一行后的补充）、闲聊（点气泡时的随机台词）、dsh 吐槽（dsh 状态相关）、收尾（依次播放模式的最后一组）、报时文案（白天点鲸鱼时的第一行，`{t}` 会替换成当前时间）、动图降级（`rua.gif` 加载失败时的顶替文案）。改完点「保存」立即生效（挂件不用重启）；点「恢复默认」把六组全部填回内置台词；**某一组清空 = 该组恢复内置默认**（不会出现空白气泡）。输入框里是「草稿」，不点「保存」不会写入
- **提醒文案**（设置页「文案」卡片 · 「提醒文案」分组）：六条 `textarea` 分别对应**低余额预警 / 今日预算 / 进入峰时 / 进入谷时 / 穿透开启 / 穿透关闭**，气泡与系统通知共用同一份文案。**最多三行**，依次对应气泡的「标题 / 大字 / 说明」——行数不够则后面的行留空，多于三行的并进说明行（气泡只有三行，多了显示不出来）；系统通知取全文并把换行合并成一行。占位符：低余额用 `{balance}`（当前余额）`{threshold}`（阈值），预算用 `{used}`（今日已用）`{budget}`（预算额）`{over}`（超出金额），峰谷用 `{schedule}`（时段表，如 `峰时9-12/14-18点`）；**没提供的占位符会原样留着**，写错一眼能看出来。改完点「保存」立即生效（挂件开着也立即生效）；点「恢复默认」六条全部填回内置文案；**清空某一条 = 该条恢复内置默认**；输入框里是「草稿」，不点「保存」不会写入。注意：多厂商模型的余额通知文案带模型名，**不受这里影响**
- **用量趋势图**（设置页「用量与账本」卡片）：右上角切 **7 / 14 / 30 天**（档位不超过账本保留期），图表按所选区间显示每日用量；下方「本月汇总」给出本月累计、日均（按本月已过天数摊）、最高单日与**累计已用**（账本的滚动累计，跨天只增不减，不受历史保留期裁剪与上方区间影响）。柱顶金额只在 7 / 14 天档显示（30 天会太挤）
- **历史保留**（设置页「用量与账本」卡片）：账本按天归档的**保留期可配**（`historyKeepDays`，35–730 天，默认 **365**）。改小后趋势图档位、导出 / 导入 CSV 的区间上限、明细记录一并跟着缩；改大只是允许留更久（旧数据已被裁掉的补不回来）。累计已用（`quotaUsed`）**不参与裁剪**，跨天只增不减
- **账本明细**（设置页「用量与账本」卡片）：点「展开账本明细」按日列出每日用量，带红色标签「另有 ¥x 未计入」的天表示当天有被防误判拦下的余额变动，灰色标签「N 条记录」表示当天有校准 / 未计入记录；点某天展开可看**每条记录的时间与原因**。右上角**类型下拉**（全部记录 / 只看未计入 / 只看校准）+ **检索框**（按**日期或原因**，如 `09-12`、`到期`）可叠加使用：命中是**条目级**的（只显示命中的条目，整天没命中就不列出该天），且命中的天**自动展开**——不用再一天天点开找是哪条；两者都清空即回到「列出区间内所有天、手动点开」的原行为。区间跟随上方 7 / 14 / 30 天档位。明细只在展开时读取一次，收起不请求；记录跨天保留天数**跟随「历史保留」设置**（默认 365 天）
- **校准今日已用**（设置页「用量与账本」卡片，仅记账模式显示）：记账漏采或误判后，填入真实金额点「校准」即可改当天累计；同时会显示「今日另有 ¥x 余额变动未计入用量」及原因（赠送额到期 / 异常跳变）与时间
- **今日模型占比**（设置页「用量与账本」卡片，**仅「实时·令牌」模式显示**）：按模型列出今日花费占比（模型名 + 占比条 + 百分比 + 金额，按金额降序），标题行显示「共 ¥x · 更新于 HH:MM」；打开设置页、切用量模式、切回本窗口时各刷新一次。切到「小鲸鱼记账」后该块自动隐藏（记账只有总额，拿不到模型明细）；未填平台 Token 时显示「读取失败：未配置平台 Token」
- **额度**（设置页「用量与账本」卡片）：填「额度总量」（元，资源包 / 订阅总面额）并选**每月重置 / 每日重置 / 不重置**，下方出现进度条与「已用 / 总量 · 剩余（百分比）」。已用按所选周期从账本现算：每月 = 本月累计、每日 = 今日、不重置 = 累计已用（跨天只增不减）。总量填 0 即不显示进度条；额度**只做展示**，不改余额、记账与任何预警口径
- **多厂商余额 / 额度**（设置页「模型与余额」卡片）：点「添加模型」→ 选**厂商模板**（自动填好接口地址与字段路径）→ 填名称与 **API Key** → 保存；列表里点行首**单选**即把该模型设为**挂件主显示**，行尾「设置 / 刷新 / 删除」（删除走行内确认条，密钥与余额记录一并清除）。行内表单可改**类型**（余额金额 / 订阅额度百分比）、**币种**（人民币 ¥ / 美元 $）；「高级设置」里可改**认证方式**（Bearer / 原始值）、各字段路径（余额 / 已用额度 / 剩余百分比 / 剩余量 / 总量 / 重置时刻）、取值倍数 `scale`、已用额度单独接口，以及**低余额提醒**（按该模型自己的阈值，每天一次系统通知）。「测试连接」会立即拉一次并显示结果；「刷新全部」批量拉取（5 分钟内不重复请求，点「刷新」强制拉）。挂件菜单「模型」分组里也能点行切换主显示、点「刷新余额」；**只有内置 DeepSeek 时该分组整组隐藏**
- **今日预算提醒**（设置页「提醒与通知」卡片）：勾选后填「每日预算」金额（元），当天用量超出时挂件弹一次提醒气泡、第三行常驻「超预算 ¥x」，并**每天弹一次系统通知**；同一天内多次超出不会重复通知，改小金额后当天也不会再补通知（跨天自动恢复）
- **低余额预警**（设置页「提醒与通知」卡片）：勾选后填「预警阈值」（单位跟随账本币种显示「元 / 美元」；默认值也按币种取，人民币 10 / 美元 2），余额低于阈值时数字与「今日已用」变红，并弹一次提醒气泡 + **每天弹一次系统通知**；与「今日预算提醒」同时命中时以低余额提醒为准（更紧急）
- **余额大幅波动通知**（设置页「提醒与通知」卡片）：勾选后填「下降阈值」（元，默认 5），单次采样余额下降 ≥ 阈值就弹一次系统通知；**不做「每天一次」去重**——每次下降只会被采样到一次，不会重复刷屏。计不计入今日用量都会通知，文案会说明是正常消费还是「被防误判拦下（未计入今日用量）」
- **提醒停留时长 / 免打扰时段**（设置页「提醒与通知」卡片）：停留时长控制峰谷切换 / 今日预算 / 低余额 / 穿透说明这几类提醒气泡的收起时间（常驻 / 5 / 8 / 15 秒，默认 8 秒；计时到点气泡由挂件菜单「到点通知」旁的档位单独控制，随机台词不受影响）；免打扰开启后可设起止时刻（`HH:MM`，**可跨午夜**，如 `23:00` 至 `07:00`），时段内「今日预算」「低余额」「余额波动」三类自动通知都不弹系统通知（前两类的气泡照常），且**不占用当天名额**——出时段后仍会补发一次
- **悬停鲸鱼 → 右上角菜单按钮**：大小 / 音效开关 / 音色（含「自定义」）/ 音量 / 透明度 / **模型** / 用量模式 / 峰谷文案 / 气泡 / 峰谷提醒 / 报时 / 计时 / 锁定 / dsh（开发者） / 打开设置 / 隐藏挂件（菜单按钮本身可在设置页隐藏，隐藏后右键鲸鱼仍可打开菜单）
- **计时 / 定时 / 倒计时**：菜单「计时」选模式（正计时 / 倒计时 / 定时）→「目标」填分钟数或 `HH:MM`（已过点顺延到明天）→ 点「开始」，气泡立即显示并每秒刷新；按钮在开始时变「暂停」、暂停后变「继续」，「目标」行同时提供「重置」；点气泡收起不中断计时，再点鲸鱼重新显示；到点响提示音、可选弹系统通知并显示「时间到！」。菜单里的「到点通知」（含提醒停留时长：5 / 8 / 15 秒或常驻）「只显计时」「气泡常驻」「计时保存」分别控制**系统通知**、**计时是否独占气泡**、**计时气泡是否自动收起**与**重载插件后是否继续计时**。
- **dsh（开发者）**：悬停鲸鱼 → 右上角菜单 →「dsh（开发者）」分组：`启动` / `重启` / `结束` / `更新` 四个按钮 + `打开页面`（自动使用 dsh 打印的带 token 地址），下面两行显示**运行状态**（未运行 / 运行中 · pid / 外部 dsh · pid / 启动中…）与**最近执行的命令**。启动后 3080 就绪前显示「启动中…」，方便区分「还在下载」与「已经跑起来」。

## 定价表

「实时·令牌」模式按平台用量接口返回的 token 数 × 下表单价换算今日已用。金额单位 **元 / 百万 token**，写成 `[谷价, 峰价]`。

- **高峰**：工作日 **9:00–12:00、14:00–18:00**（北京时间）
- **谷价**：其余时间，恰为峰价的一半；**2026-08-23 起周末全天按谷价**
- 时段判定与定价实现在 [constants.js](public/preload/lib/constants.js)（`PEAK_HOURS` / `BASE_PRICE` / `PRO_PRICE`）与 [pricing.js](public/preload/lib/pricing.js)，官方调价时改这里；「小鲸鱼记账」模式不依赖本表

| 模型 | 缓存命中 | 缓存未命中 | 输出 |
|---|---|---|---|
| `deepseek-flash`（当前模型名，含旧名 `deepseek-v4-flash` / `deepseek-v4-flash-vision-exp`） | 0.02 / 0.04 | 1 / 2 | 4 / 8 |
| `deepseek-v4-pro` | 0.15 / 0.3 | 4.5 / 9.0 | 13.5 / 27.0 |

> 模型名按**子串**匹配上表（键的顺序即优先级）；`deepseek-chat` / `deepseek-reasoner` 以及匹配不到的模型名一律按 Flash 价计，未收录的模型名会在开发者日志里留一条记录，便于官方上新 / 改名后及时发现。
>
> 对不上实际账单时（比如走了中转站或官方调价），可在设置页「用量与账本」勾选**自定义单价**：按百万 token 填谷价并选币种，峰价自动按官方规则（谷价 × 2）翻倍，选美元再填汇率（元/USD）；**账本与挂件显示统一按人民币**，不受填的币种影响。
>
> 只改了几个模型的价时，用下面的**「按模型覆盖」**：点「＋ 添加模型」填模型名（按**子串**匹配，如 `deepseek-v4-pro`）与该模型的三个单价，最多 20 条。取价是**三级顺序** —— 按模型覆盖 → 全局自定义单价 → 内置价目表，前者没命中就继续往下看（不是「填了就整表覆盖」）。模型名留空的条目保存时会被丢掉。

## 数据与隐私

- **存了什么**：API Key 与平台 Token、**各厂商模型各自的 API Key**（都在 uTools `dbCryptoStorage` 加密存储，一模型一份）、挂件设置（含模型列表与「主显示」是哪个）、本地账本（用量 / 余额基准 / 校准与「未计入」记录）、计时状态（开启「记住计时状态」时）、窗口位置与更新缓存，以及导入的**自定义音效文件**（复制到插件数据目录 `userData/whale-sounds/`）、**自定义挂件形象图片**（`userData/whale-skins/`）与**自定义气泡图**（`userData/whale-bubbles/`），全部只保存在本机，不会上传到第三方服务器；除余额接口（`api.deepseek.com`）、用量接口（`platform.deepseek.com`）、**你添加的厂商模型自己的余额 / 额度接口**与更新检查外无任何外部请求。**更新检查默认关闭**（设置页「帮助」→「自动检查更新」手动开启，开启后每次呼出最多 12 小时查一次）：它向 `ghfast.top`（GitHub 内容加速代理）拉一次本项目的 `package.json` 比版本号，**请求里不含任何用户数据**（无 body、无 Cookie、不带 Key），不开即完全不出网。模型的余额 / 额度是**运行时快照**（`whale:models`），只是缓存，不进备份、清除「挂件设置」时一并清掉。
- **导出 / 导入账本**：设置页「用量与账本」卡片右上角可在 CSV 与账本之间互转（日期 / 用量 / 币种三列，带 BOM，Excel 直接打开）；导入按日期合并（同日覆盖），只保留最近「历史保留」设置的天数（默认 365）。
- **卸载不删数据**（步骤见 [卸载](#卸载)）：在 uTools 里移除插件**不会**自动清除上述数据。设置页「数据与隐私」可**勾选要清除的项目**（凭据 / 挂件设置 / 账本用量记录 / 窗口位置与更新缓存 / 自定义音效 / 自定义形象 / 自定义气泡图），点「清除选中数据」并二次确认后只清除勾选项（确认时会列出**将清除哪些项**）；清除挂件设置或窗口位置后会按默认值重建挂件，只想重置挂件外观时不必重填凭据；清除自定义音效会删掉导入的音频文件，并把音色一并回退为「小黄鸭」，清除自定义形象会删掉图片文件并把形象回退为内置鲸鱼娘，清除自定义气泡图会删掉图片文件、挂件气泡随即回退内置动图（气泡图不选「当前用哪张」，所以不需要改任何配置）。**模型相关**：清除「凭据」会一并清掉各模型的 API Key（模型列表还在，但需重新填密钥），清除「挂件设置」会连模型列表与余额快照一起清掉（挂件回到只显示 DeepSeek）。
- **备份与恢复**（设置页「数据与隐私」→「备份与恢复」）：
  - 导出会把「挂件设置 / 账本 / 窗口位置 / 计时」写成一个 JSON 文件（不含 dsh 开发者配置与 Node 路径）。
  - **凭据默认不导出**；勾选「包含凭据」后必须设密码（≥6 位），凭据（含各厂商模型的 API Key）用 **scrypt 派生密钥 + AES-256-GCM** 加密后才写入文件——文件里没有明文，改一位就解不开；密码不保存在任何地方，忘记只能放弃凭据（其余项仍可恢复）。旧备份（不含模型密钥）恢复时**不会**抹掉你已保存的模型密钥。
  - 导入时先读取备份并列出「导出时间 / 插件版本 / 包含项」，勾选要恢复的项后写入（**同名覆盖**，账本同日覆盖并保留最近「历史保留」设置的天数）；恢复「挂件设置」或「窗口位置」会重建一次挂件，立即生效。
  - 备份文件本身含你的设置与用量记录（凭据除外为加密块），请妥善保管。
- **dsh 相关**：只在本机执行（`node` 运行 dsh / 需要时用 `npm` 安装或更新它 / `taskkill`），不会把任何内容发到第三方服务器。dsh 的输出日志**仅保存在内存**（最多 160 行，供设置页查看），重新加载插件即清空；「打开页面」所用带 token 的地址取自 dsh 自身的输出，同样只存内存、不写入本地存储。dsh 自己的配置与数据由 dsh 管理（默认在用户目录 `~/.dsh`），本插件不做改动。

## 卸载

在 uTools 里移除（卸载）本插件即可，没有额外的清理步骤。

- **移除插件不会删除数据**：凭据、挂件设置、账本、窗口位置与更新缓存、导入的自定义音效与形象图片都留在本机，重新装回来照旧可用。
- 想**连数据一起清掉**，请在**卸载前**到设置页「数据与隐私」→「清除数据」按项勾选并确认（可只清凭据 / 只清账本，或全选）；卸载后插件界面就没了，只能重装一次再清。
- 换机器或重装后想还原设置，先用「数据与隐私」→「备份与恢复」导出备份，详见 [数据与隐私](#数据与隐私)。

## 常见问题

- **挂件不出现**：确认入口目录（dev = `public/`，打包 = `dist/`）；点设置页「显示挂件」；点「挂件异常？查看错误详情」看宿主记录的失败原因并复制，或主窗右键 → 检查看 `[whale][widget]` 日志。
- **悬浮窗调试**：焦点在挂件窗口上按 `Ctrl+Shift+I`。
- **开启鼠标穿透后挂件点不动**：这是预期行为（连挂件菜单也穿透了）。用「切换鼠标穿透」全局快捷键关掉，或把鼠标**停在鲸鱼上约 1 秒**临时接管后，从挂件菜单「打开设置」回设置页关闭。建议先在设置页「挂件窗口 → 鼠标穿透」处点「新增快捷键」绑好，再开启穿透。
- **听不到自定义音效**：确认「音效开关」为开、音量不为 0、音色选的是「自定义」且**已导入「按压音」**（未导入时会回退「小黄鸭」）；只导入按压音、没导入释放音时，松手那一下是静音（这是预期）。若导入的是 flac/m4a 而系统解不了码，换 mp3 / wav 再试。
- **提醒时没声音**：四类提醒音（低余额 / 预算 / 峰谷 / 穿透）**留空就是静音**，与音色无关，得先去「资源」Tab 的「导入的音效」里各导一段；导了还听不到再查「音效开关」与音量。
- **今日已用突然变大**：v1.4.0 起「赠送额度整块到期 / 被平台收回」与「短时间异常跳变」不会再计入；若仍异常，说明下降幅度落在可信范围内被判成了消费，可用设置页「用量与账本」卡片的「校准今日已用」改成真实金额（会留校准记录），并把「今日另有 … 未计入用量」那行提示一起反馈回来。
- **透明度调了没反应 / 挂件整窗看不见**：请确认版本为 v1.4.0 且已在 uTools 里**重新加载插件**（preload 与 `floating.css` 都不热更）。旧实现用窗口级 `setOpacity`，在 Windows 的分层透明窗上会导致整窗不显示，v1.4.0 已改为页面 CSS 透明度。
- **401 API Key 无效**：确认填的是 `sk-` 开头的 **API Key**（不是平台 Token）；用「测试连接」看服务器原文。
- **添加的模型一直显示 `--`**：点该行「设置 → 测试连接」看服务器原文。常见原因：密钥没填（或填错厂商，注意 Moonshot 大陆站与国际站是两套账号、两套密钥）、字段路径与该厂商返回不一致（可用「高级设置」改路径）、自定义 HTTP 模板没填 `{base}`、或接口需要特殊认证（智谱系要选「原始值」）。挂件里显示 `--` 说明该模型这条还没取到值，其它模型不受影响。
- **今日已用显示 `--`**：记账模式需先有一次余额观测（60 秒内）；令牌模式需配好平台 Token，失败会回落记账。
- **峰谷提醒不出现**：提醒依赖**思考气泡**，需同时开启「思考气泡」与「峰谷切换提醒」；且只在时段**切换**的瞬间提示一次，刚启动时不会补弹。
- **今日预算提醒没弹 / 只弹了一次**：系统通知**每天只发一次**（同一天内继续超支不再重复，跨天自动恢复）；气泡提醒同样需要「思考气泡」开着，且计时进行中不打断计时；刚呼出插件时若已超预算不会补弹气泡，但第三行「超预算 ¥x」常驻提示照常显示。注意「每日预算」金额为 0 等于未设置，可在设置页「提醒与通知」卡片里改。
- **低余额预警没弹 / 只弹了一次**：系统通知同样**每天只发一次**（跨天自动恢复）；气泡提醒需要「思考气泡」开着，且计时进行中不打断计时。与「今日预算提醒」同时命中时只弹低余额那条。若在免打扰时段内，通知会推迟到出时段后补发。
- **免打扰时段内还是弹了通知**：免打扰只静默「今日预算」与「低余额」两类**自动**通知；计时到点是你在挂件菜单里主动设的一次性提醒，照常通知。另外请确认起止时刻不是同一个值（相同时视为未开启）。
- **提醒气泡一闪而过 / 一直不消失**：停留时长在设置页「提醒与通知」卡片的「提醒停留时长」里改（常驻 / 5 / 8 / 15 秒）；选「常驻」需手动点气泡收起。该设置不影响计时到点气泡（由挂件菜单「到点通知」旁的档位控制）。
- **计时到点没声音 / 没通知**：提示音走挂件音效，需「音效开关」为开且音量不为 0；系统通知由「计时到点通知」开关控制（关闭时只响提示音 + 气泡）。挂件窗口在后台被系统节流时，到点可能略有延迟，切回挂件即会立即补响。
- **重载插件后计时没了**：确认「记住计时状态」为开；关闭后计时只在本次运行内有效。
- **没声音**：音量不为 0；Electron 首次需先有一次交互。
- **改了 preload 不生效**：preload 不热更，需在 uTools 开发者工具里重新加载插件。
- **dsh 提示「未找到 Node.js」**：设置页「DeepSeek Harness」→「选择目录」指定 Node.js 安装目录（如 `D:\nodejs`），或点「改为自动探测」；卡片里会显示实际生效的目录与版本。
- **dsh 提示 3080 端口被占用**：说明已有 dsh 在运行（可能是在别的终端里启动的）。点「结束」或「重启」即可接管；若占用端口的是**非 dsh 程序**，插件会拒绝操作并提示，避免误杀。
- **点「结束」提示「权限不足 / 拒绝访问」**：那个 dsh 是**管理员权限**启动的。插件会自动改用管理员权限重试（弹一次 UAC 确认框）；也可以管理员身份运行 uTools，或直接在 dsh 自己的终端里按 `Ctrl+C`。
- **打开页面提示 authentication required**：dsh 的 Web UI 首次访问需要带 `?token=` 的地址。由插件启动的 dsh 会自动捕获该地址（设置页「页面地址」可查看 / 复制）；外部终端启动的 dsh 请使用它自己打印的地址，或在插件里「重启」一次以接管。
- **dsh 首次启动很慢 / 「启动中…」很久**：首次会自动下载安装（约 500 多个包，之后启动就快了）；国内建议把「npm 注册源」改成淘宝镜像。启动完成后状态会变成「运行中」，并在日志里记录「3080 已就绪（用时 x.xs）」。
- **结束 dsh 后 dsh 又起来了**：说明它有守护进程 / 你是在某个会自动重启它的工具里启动的，请在它自己的终端里 `Ctrl+C` 关闭。

## 开发与构建

```powershell
npm install
npm run dev         # Vite 开发服务器（配合 uTools 开发者工具指向 public/）
npm run lint        # eslint . 静态检查
npm run typecheck   # vue-tsc --noEmit 类型检查
npm test            # node --test 单测（test/*.test.mjs）
npm run build       # 构建到 dist/（prebuild 自动同步版本号 + 校验跨文件常量副本）
```

- 改动 `preload/` 或 `floating-*`：不热更，需在 uTools 开发者工具里**重新加载插件**才能看到效果。
- preload 文件为 CommonJS，**不可压缩混淆**，发布时保持原样。
- `npm run lint` 的配置在 `eslint.config.js`：只查真问题（未定义 / 未使用变量、重复键、不可达代码、Vue 模板里的错误用法），**不含格式规则**（缩进 / 引号交给编辑器）；按四套运行环境分块声明全局变量（设置页 / preload / 悬浮窗页面 / 构建脚本）。
- 同一份常量在宿主 / 设置页 / 浮动页 / 样式表里各有一份副本（preload 不参与打包、浮动页没有 `require`、CSS 变量宿主读不到），`scripts/check-shared.mjs` 会在构建前比对，不一致直接构建失败；新增这类副本时记得把这一对加进它的 `CHECKS`。
- **持续集成**（`.github/workflows/ci.yml`）：push 到 `main`、任何 PR、手动触发时，依次跑 `npm run lint` → `npm run typecheck` → `npm test` → `npm run build`（Node 24 + `npm ci`）。这四关就是上面这些本地命令本身，**CI 不额外引入工具链**，所以「本地能过」和「CI 能过」是同一件事；构建产物 `dist/` 不上传、不发布。
- **发版**（`.github/workflows/release.yml`）：只改 `package.json` 的 `version` → 提交 → 打同名 tag（如 `v1.5.1`）并推送。工作流会先校验 tag 与 `package.json` 版本一致（不一致直接失败），再跑与 CI 同一套检查、构建，把 `dist/` 打包成 `balance-whale-widget-<tag>.zip` 并建 Release（变更说明由 GitHub 按 commit / PR 自动生成）。**uTools 市场的 `.upx` 仍需人工**在开发者工具里打包上传。

### 1.5.0

#### 新功能

**余额与用量**

- **多厂商余额 / 额度**：除内置 DeepSeek 外最多再添加 9 个模型（`MODEL_MAX = 10`），内置 11 个厂商模板（`MODEL_TEMPLATES`：OpenRouter / Moonshot 大陆站与国际站 / 阶跃星辰 / Novita / 智谱 GLM Coding / Kimi Coding / MiniMax Coding / OpenAI 兼容中转站 / 自定义 HTTP），**只收录能用 API key 直接查到余额或订阅额度的厂商** —— 其余厂商没有这类接口，本插件也拦不到对话事件，搬过来只会是空壳。可切换**挂件主显示**：余额型显示原币种余额（附「~今日已用」，按相邻两次余额差估算），额度型（订阅）显示剩余百分比与重置时刻；主显示非 DeepSeek 时「用量与峰谷」整组收起、峰谷台词改报该模型余额 / 额度。挂件菜单新增「模型」分组（只有内置 DeepSeek 时整组隐藏），点行即设主显示。存储拆三处：注册表进 `config.models` + `config.mainModelId`（走既有四处同步与 `whale:config` 通道，**不新增存储键**）、密钥每模型一份进 `secrets.models`（`writeSecrets` 传 `undefined` 时沿用现值，避免恢复备份把已有密钥抹掉）、运行时快照进新键 `whale:models`（不进备份）。查询侧在 `lib/api.js` 新增通用 JSON 路径解析（`pickPath` 支持 `a.b[0].c`，空值显式判为「没取到」—— `Number('')` 是 0）、`bearer`/`raw` 两种认证、`{base}` 占位替换、余额型「余额 − 已用 × 倍数」与额度型三种形态归一；`refreshModels` 带 5 分钟节流与按币种分开的低余额通知（人民币 10 / 美元 2，免打扰时段不占当天名额）。
- **Codex 订阅窗口**（5 小时 / 周）：Codex CLI 会把每次请求的额度快照（`rate_limits`）写进自己的会话日志（`~/.codex/sessions` 下的 rollout JSONL），宿主 `lib/codex.js` 顺带解析，**不用配 Key、不发请求、不碰账号**。窗口跟着 Codex 那一条一起显示：挂件说明行「已用 5h 62% · 周 31%」、设置页「dsh」Tab 的 Codex 卡片各一行（含重置倒计时）。窗口名**优先按日志里的窗口分钟数推断**（`300` → 「5h」、`10080` → 「周」），日志没给才按位置叫「5h / 周」—— 各版本 Codex 给的值不一样，写死会张冠李戴。**相对秒数（`resets_in_seconds`）以快照自身的时间戳为基准换算**，不是以「现在」为基准（拿现在去减会把早已过期的快照算成「刚重置」）。解析结果按文件 size / mtime **增量缓存**在 `whale:codex`，并带 `version` 版本号：加了 `rl / rlTs` 字段后老缓存指纹没变、不会重解析，不升版本号订阅窗口会一直缺失。
- **额度进度**：填总量（元）+ 选重置周期（每月 / 每日 / 不重置）后显示进度条与剩余（≥90% 换暖色）。配置新增 `quotaTotal`（0 = 未设置）与 `quotaReset`（`normQuotaReset` 归一化，非法值回 `monthly`）；**已用不落配置**、按周期现算：`never` 取账本新字段 `quotaUsed`、`daily` 取今日、`monthly` 取本月累计。`quotaUsed` 在 `recordLedgerUsage` 跨天归档时把当天用量并入（**不能拿 `history` 求和** —— `historyKeepDays()` 会滚动删除，累计会越用越少），`readLedger` 对老账本兜底为现存 `history` 之和；`usageDays` 一并返回 `cumUsed = quotaUsed + todayUsage`。额度**只做展示**，不影响余额、记账与任何预警口径。
- **今日模型占比**（**仅实时·令牌模式显示**）：按模型列出今日金额占比（模型名 + 占比条 + 百分比 + 金额，按金额降序），标题行显示「共 ¥x · 更新于 HH:MM」。`computeTodayUsage` 在算总额的同时**按 `model` 聚合**（`byModel`，与总额同一份 `priceFor` + `isPeakTime`，`sum(byModel.amount) === amount`），`model` 缺失归为「未知模型」；宿主 `getTodayModels()` **复用 `fetchPlatformUsage`**（不新增请求通道与 IPC 通道），页面在 `onMounted` / 切用量模式 / 窗口重新可见时各拉一次，**不进轮询**。模型明细只有平台用量接口会给，记账模式拿不到，故该块只在令牌模式渲染。
- **自定义单价**（**仅「实时·令牌」模式生效**）：可覆盖内置价目表，按百万 token 填**谷价**（缓存命中 / 未命中 / 输出），峰价沿用官方规则（谷价 × 2）自动翻倍；支持 **CNY / USD**，选美元时填汇率（元/USD），**账本与挂件显示统一按人民币**（美元数额先折成人民币再记账）。配置新增 `tokenPrice`（`normTokenPrice`：单价上限 100 万、汇率上限 1000，填 0 表示该项不收费，开关关着时其余字段照常存下来）；改动后设置页「今日模型占比」立即重拉，挂件侧今日已用等下次余额刷新。实现上 `lib/pricing.js` 新增纯函数 `customPriceTable()`（返回 `[谷价, 峰价]`，开关关着或选美元却没给可用汇率时返回 `null`，调用方回落内置价目表）。
- **峰谷倒计时**：峰谷台词第三行在「今日已用」后追加「距峰时 / 距谷时 1h20m」（不足 1 小时显示分钟）。切换时刻由宿主按同一套峰谷规则（`constants.PEAK_HOURS` + 周末谷价）算出后随余额 payload 下发，页面只做换算，不再维护第二份时段表。
- **账本明细与检索**（设置页「用量与账本」卡片，可折叠）：按日列出每日用量，并标出当天「未计入用量的余额变动」（红）与「手动校准」（灰）记录，点某天展开看每条的时间与原因，支持按**日期或原因**本地检索；区间跟随上方 7 / 14 / 30 天档位。实现上把 `adjustLog` / `calibrateLog` 从「各留 20 条、跨天清空」改为**跨天保留**（`pruneDetailLog`：只留最近 `historyKeepDays()` 天内、最多 `DETAIL_LOG_KEEP`=100 条），跨天归档时**不再清空 `adjustLog`**（`todayAdjust` / `lastAdjustWhy` / `lastAdjustAt` 仍是「今日」口径，照常归零）；新增宿主出口 `getUsageDetail(days)`（`settings.js`），设置页在**展开时才取一次**，收起不请求，检索在本地过滤（不按键过 IPC）。

**提醒与通知**

- **今日预算提醒**：可设每日预算金额，当天用量超出时弹一次提醒气泡 + 第三行常驻「超预算 ¥x」，并**每天弹一次系统通知**。通知去重记在账本 `budgetNotifiedOn`（日期字符串，跨天自动失效）；气泡与通知互不依赖（气泡可能正被计时 / 峰谷提醒占用）。
- **低余额预警升级为完整提醒**：余额低于阈值时除了数字变红，还会弹一次提醒气泡 + **每天弹一次系统通知**（此前只有变红）。去重记在账本 `lowNotifiedOn`，与「今日预算提醒」各自独立；两者同时命中时以低余额为准（更紧急）。
- **余额大幅波动通知**：可设下降阈值（`dropAlertOn / dropAlertAmount`，默认 5 元），单次采样余额下降 ≥ 阈值就弹系统通知。走新的宿主出口 `notifyNow` —— **不做「每天一次」去重**（基准随采样更新，同一次下降不会被采到两次），只受免打扰约束；文案按是否计入今日用量区分（被防误判拦下时说明原因）。
- **提醒停留时长**：峰谷切换 / 今日预算 / 低余额 / 穿透说明这几类提醒气泡可选**常驻 / 5 / 8 / 15 秒**（默认 8 秒，`remindSec`）。实现上把四处重复的「清计时器 → 设状态 → 渲染 → 自动收起」合并为挂件侧统一入口 `showRemindBubble()`。**注意**：计时到点气泡仍由挂件菜单「到点通知」旁的档位（`timerRemindSec`）单独控制，两者互不影响。
- **免打扰时段**：可设起止时刻（`HH:MM`，**支持跨午夜**如 `23:00–07:00`），时段内「今日预算」「低余额」「余额波动」三类自动通知都不弹系统通知（前两类的气泡照常）；且**不占用当天名额**（出时段后仍会补发一次）。计时到点是你主动设的一次性提醒，不受影响。
- **提醒文案可编辑**：低余额 / 今日预算 / 峰谷切换 / 鼠标穿透四类提醒的**气泡与系统通知共用同一份模板**，六条（`low` / `budget` / `peakOn` / `peakOff` / `passOn` / `passOff` —— 峰谷与穿透**按状态各分两条**，免得一条模板兼顾两种语气）都能改。气泡只有三行，模板**按行映射**：第 1 行 = 标题（A 样式）/ 第 2 行 = 大字（P 样式，沿用各提醒的状态色）/ 第 3 行 = 说明（C 样式，自动换行），行数不足则对应槽位留空、**超过三行的并入说明行**；系统通知只有一行，取全文并把换行合并成空格（`alertOneLine`）。占位符 `{balance}` `{threshold}` `{used}` `{budget}` `{over}` `{schedule}`，**未提供的原样保留**（`renderAlert` 只替换真实存在的键），用户能一眼看出写错。存放位置复用 `config.alerts`（走既有 `whale:config` 通道与 `pushConfig` 广播，**不新增存储键与 IPC 通道**）；宿主 `normAlertText` 逐条 `\r\n` 归一 + `trim` + 丢空行 + 截 200 字，`normAlerts` 区分「传 `null` = 六条全回默认」与「传对象 = 只改带的键」；**空模板 = 恢复内置默认**。挂件页面读不到宿主模块，故 `floating-page.js` 里放了同内容的 `ALERTS` 兜底副本（已纳入 `check-shared.mjs` 校验）。**有意不接入**：多厂商模型的余额通知（带模型名、每个模型有各自的阈值）与余额大幅波动通知（文案按是否计入用量区分）保持写死。

**素材与形象**

- **素材集中管理（独立「资源」Tab）**：形象 + **六段音效**（音色两段 + 四类提醒音）导入素材的**集中管理入口**，四张卡 —— 「资源概览」（项数与占用体积 + 两个清除按钮 + 折叠的素材包）、「导入的形象」（缩略图网格）、「导入的音效」（六槽位）、「内置资源」（内置形象与两组内置音色，可预览 / 试听、**不可删**）。此前这些按钮分别藏在 `v-if="cfg.skin === 'custom'"` 与 `v-if="cfg.soundSet === 'custom'"` 里，一旦切回内置形象 / 音色，素材在界面上就「消失」（磁盘上还占着），既看不到也删不掉；现在这块**不做任何门控**。每项显示文件名 + `体积 · 导入时间`（体积由宿主 `readMeta()` 用 `fs.statSync` **读取时派生、不落存储**，文件被手动清掉时显示「体积未知」），素材在但设置没在用（形象不是 `custom`、音效开关没开或音色不是 `custom`）时各给一行提示。清除分两档：**「清除未使用（n）」**（`doClearUnusedAssets()`）按「当前设置会不会用到」挑出未使用项 —— 形象 = 画廊里除在用那张外的每一张；音效 = 音效开关关掉则四类提醒音全算未使用，否则 `press` / `release` 看 `soundSet` 是否为 `custom`、四类提醒音看对应的提醒开关 —— **先快照再逐个删，正在使用的一律保留**；**「清除全部素材」**（`doClearAssets()`）逐个走 `removeSkin` / `removeSound`，任一失败即报「部分素材清除失败」，全清后把 `skin` 回退 `DSniang1`、`soundSet` 回退 `duck`。两者都**只删素材、不动其它设置**。
- **素材包（导出 / 导入）**：把导入的形象与音效打包成**一个 `.whaleassets` 文件**，换机器时一次带走。新叶子模块 `lib/assets.js`（另依赖同层的 `skins` / `sounds`）：容器是自定义格式 —— `[11 字节魔数 'WHALEASSET1'][4 字节清单长度 uint32LE][JSON 清单][各文件字节按顺序平铺]`，**不压缩**；不用 zip 是因为 preload 跑在渲染进程、只有 Node 内置模块，自写 zip 要处理 CRC32 与中央目录，出错面比收益大。清单里带 `kind: 'balance-whale-widget-assets'` 与 `schema: 1`，**高于当前 schema 的包直接拒收**。导入是**两段式**（与「备份与恢复」同一套 `assetsExport` / `assetsPick` / `assetsApply` / `assetsCancel`）：`pickAssets()` 只解析、不落盘，界面列出条目让用户勾选，`applyAssets()` 才真正写入。写入语义：**形象是「补充」**（每张生成新 id 进画廊，不动已有画廊与当前使用的那张）、**音效是「同槽位覆盖」**（与 `importSound` 同语义，换格式不留旧文件）。**素材包不落任何存储键、不新增配置项**。
- **挂件形象切换**：**13 张内置形象**（默认 `DSniang1`；形象 id 即 `public/whale/` 下的图片文件名，下拉里按文件名列出） / **自定义**（导入自己的图片：png / jpg / jpeg / webp / gif / apng、≤5MB，不收 SVG）。新增叶子模块 `lib/skins.js`（与 `lib/sounds.js` 同构）：图片**复制**进 `userData/whale-skins/<id>.<ext>`，元信息落 `whale:skins`，推送时读成 base64 data URL（挂件页面加载不了插件包外的 `file://`）；导入后自动切到这张，删除后若正用「自定义」自动回退默认形象。内置形象清单在三处各有一份同值副本（挂件页面 `floating-page.js` 的 `BUILTIN_SKINS` 对象 / 宿主 `store.js` 的 `BUILTIN_SKINS` 数组 / 设置页 `App.vue` 的 `BUILTIN_SKINS` 数组 —— preload 不参与打包，设置页与挂件页都拿不到宿主常量，所以消不掉），加形象要三处一起改；v1.5.0 及更早只存过 `whale` / `whale2` 两个 id，由 `SKIN_ALIAS` 映射过去，**不做数据迁移** —— 否则老配置被判成非法值会悄悄换回默认形象，用户会以为「形象自己变了」。
- **自定义形象升级为画廊**：由「只存一张 `skin.<ext>`」改为**多张（最多 20）**，`whale:skins` 存 `{current, items:[{id, name, ext, at}]}`，文件按 `<id>.<ext>` 落在 `userData/whale-skins/`，另存 128px 缩略图供网格显示。界面是**缩略图网格**：点缩略图即切换（`setSkinCurrent`）、「置顶」把该张挪到第一位（`pinSkin`）、「删」删掉该张（`removeSkin`，删的是当前那张时宿主顺延到剩余第一张，全删光且形象仍是 `custom` 时回退 `DEFAULT_SKIN`），当前那张带「使用中」角标。老数据（单张 `skin.<ext>` + `config.skin`）由 `readRaw()` **就地归一化**成画廊，不主动写回存储。**GIF / APNG 走原样复制**（`importSkinFromPath`，不裁剪、不重编码）以保住动画，静态图仍走裁剪层。
- **形象裁剪**：两段式（`pickImageFile()` 读成 data URL 不落盘 → `SkinCropper.vue` → `importSkinFromData()` 写 `<id>.png`，只认 `data:image/png;base64,`；**GIF / APNG 绕过裁剪层**）。裁剪层支持 8 手柄拖拽缩放、框内平移、框外压暗，一键**「自动裁掉透明边」**（按 `alpha > 8` 扫包围盒，扫描前先等比缩到 ≤1024 控成本，全透明图给出提示），导出走 `canvas.toDataURL('image/png')` **保留透明通道**；画廊网格里每格带缩略图便于确认是哪张。
- **音效试听与裁剪**：已导入的按压 / 释放音可点「试听」按当前音量直接听；导入改为「选文件 → 弹波形裁剪层 → 确认落盘」两段式 —— `lib/sounds.js` 新增 `pickSoundFile()`（只把文件读成 base64 data URL 返回，**不落盘**，中途取消不留半成品）与 `importSoundFromData()`（只认 `data:audio/wav;base64,`，按**解码字节数**校验 ≤5MB）。裁剪层 `SoundTrimmer.vue` 用 `decodeAudioData` + canvas 峰值波形，拖手柄选段（上限 10 秒，超出截断提示；下限取 0.05 秒与「6px 对应时长」的较大值，防长音频里手柄叠死），可试听选区（`AudioBufferSourceNode.start(0, offset, dur)`），确认后用 `OfflineAudioContext` 渲染单声道 + 自实现 `encodeWav` 导出 **16-bit PCM WAV**（base64 分块 `btoa` 防 `apply` 爆栈）。
- **音效槽位由两段扩到六段**：新增**「提醒音效」分组**，低余额 / 今日预算 / 峰谷切换 / 鼠标穿透四类提醒各可导一段（`ALERT_SOUND_ROLES`），合成六个槽位 `press / release / low / budget / peak / pass`（`lib/sounds.js` 的 `ROLES`）。与音色的关键差别：**四段提醒音没有内置回落，留空即静音**；播放只看全局「音效开关 + 音量」，**不受「音色」下拉影响**。挂件页 `customSounds` 是六个键逐个写死的对象（两处收、两处推），加槽位要手动核对 `lib/sounds.js` 的 `ROLES` 与这里两处 —— 这处**没有副本可校验**，`check-shared.mjs` 比不了。
- **音效槽位升级为音效组**：每个槽位由「一段」改为「一个数组」（`whale:sounds` 里每键是数组，文件名 `<role>-<n>.<ext>`），同一槽位可导多段、挂件每次**随机播一条且不连续重复同一条**（沿用页面侧 `pickOne` 的 `WeakMap` 机制），删到只剩一段就固定播它。推送通道 `whale:sounds` / `whale:init.sounds` 的**每槽位载荷随之变成数组**。老结构（每槽位一个对象、文件名 `<role>.<ext>`）在 `readMeta()` 里**就地升级成单元素数组**、不主动写回存储，只在真正增删时才落盘；`<role>.<ext>` 这个文件名留给老结构那条，不参与新编号（新编号取目录里的最小空位，删掉一段后编号能复用）。
- **自定义气泡图**：新叶子模块 `lib/bubbles.js`（与 `lib/skins.js` 同构）+ 存储键 `whale:bubbles` + 文件目录 `userData/whale-bubbles/`，最多 8 张。点小鲸鱼抽到「气泡图」那组台词时从图里**随机显示一张**，删光回退内置 `rua.gif`。与形象的四处**有意不同**：① **不裁剪、不重编码**（气泡里放的多是动图或整图，过一次 canvas 就把动画帧丢了），只做格式与体积校验（png / jpg / jpeg / webp / gif / apng、≤5MB）；② **没有「当前用哪张」**（有图就随机抽，所以网格里没有「使用中」角标与「置顶」，也不需要 `current` 字段）；③ 因此**不参与「清除未使用」统计** —— 有图就会被抽到、恒为在用，只能靠「清除全部素材」删；④ 推送总量有预算 `PUSH_BUDGET = 20MB`，超出的图**跳过并 `logErr` 留痕**（挂件页面要整份 base64 塞进 IPC 载荷，全推会撑爆内存）。页面侧另有一处坑：`img.src` 读出来是绝对 `file://` URL，拿它跟 `./whale/rua.gif` 比**永远不相等**，故用一个 `gifSrcSet` 变量记「原始 src 值」判断是否真要换图，否则每次抽到同一张都会重新加载、data URL 还白解码一遍；自定义图加载失败时 `onerror` **当场**把气泡换成降级文案（此时气泡已切到「只显示图」的状态，光记失败标记会留下一片空白）。
- **气泡配色主题**：默认（蓝白）/ 深色 / 樱花。实现上把 `floating.css` 里气泡与文字的颜色全部改成 CSS 变量（`--dshwv-text/hint/fill/stroke`，样式表内带原默认值兜底），JS 只 `root.style.setProperty` 重写变量、**不重建 DOM**；「低余额」红色是状态色，不随主题变。换形象后**命中测试画布会按新图重建**（透明区穿透判定跟随新轮廓）。
- 「数据与隐私 → 清除选中数据」新增独立的**自定义形象**项（`skins`）：删图片文件 + `whale:skins` 并把空形象推给挂件；若形象正为「自定义」且未同时清「挂件设置」，宿主会顺带把它**回退为默认形象**并广播给挂件。

**文案与交互**

- **台词库可编辑**（与「提醒文案」合并为设置页「文案」一张卡）：六组文案（短句 / 闲聊 / dsh 吐槽 / 收尾 / 报时 / 动图降级）各一个 `textarea`，**一行一条**，卡片头右侧「保存 / 恢复默认」。存放位置复用 `config.quotes`（走既有 `whale:config` 通道与 `pushConfig` 广播，**不新增存储键与 IPC 通道**）；宿主 `normQuoteList` 逐条 `trim` + 丢空行 + 截 60 字 + 最多 30 条，`normQuotes` 区分「传 `null` = 六组全回默认」与「传对象 = 只改带的键」；**空组 = 恢复内置默认**（空数组会让气泡没字）。挂件页面读不到宿主模块，故 `floating-page.js` 里放了同内容的 `QUOTES` 兜底副本。
- **随机台词由写死的六组升级为可配置的「组列表」**：此前六组的台词 / 权重 / 样式 / 顺序全写死在 `floating-page.js` 的 `RANDOM_GROUPS` 里，加一句台词、调一次概率、把某组换成图片组都要改代码。现在 `config.quotes` 的结构从 `{hint, chat, dsh, short, time, gifFail}` 升级为 `{time, gifFail, groups}` —— 前两项是**不走抽签**的固定文案（报时模板 / 动图降级），`groups` 是**随机组列表**，每组 `{kind, w, style?, lines?}`：`kind` = `card`（内置余额 / 时段卡，内容按当前数据现算、文字不可编辑）/ `text`（用户台词）/ `image`（抽一张自定义气泡图）；`style` 只对文本组有效（`A` 普通字号、长句自动换行 / `B` 大字、不换行、靠挂件按可用宽度整体缩放）。抽签（累减权重）、防连抽（`pickOne` 的 `WeakMap`）、依次播放（`queueNext`）**全部复用原逻辑**，页面侧只把「读写死的数组」换成 `buildRandomGroups()` 按配置装配（没配过 / 一组不剩时回退内置六组，顺序与权重 45/7/7/10/3/1 与升级前**完全一致**）。**老配置就地升级**：只带 `hint / chat / dsh / short` 四个键的旧结构在 `normQuotes` 里直接升成六个组，不做单独的迁移步骤。归一化口径：`w` 压到 1–999（权重 0 的组抽签时会被兜底抽到，留着只会误导）、**没有有效台词的文本组整组丢掉**、组数上限 12、一组不剩回内置默认；`cloneGroups()` 深拷一层避免默认值被编辑污染。内置默认的「组的顺序 / 类型 / 权重 / 字号」在宿主 `QUOTE_GROUPS_DEFAULT` 与挂件页 `defaultRandomGroups()` 各有一份，形态不同但必须一致，故 `check-shared.mjs` 新增 `quoteGroupShape()` 把两边抽成同一串再比对。**未升存储版本号、未新增存储键与 IPC 通道**。
- **点按依次播放台词**：开启后点气泡从第一组起**按顺序**播放六组台词，每点一次切下一组、播完最后一组才收起；关闭保持原来的「每次随机一组」。
- **挂件菜单末行新增「隐藏挂件」**（与「打开设置」同排的次要按钮）：走新通道 `whale:hide-widget` → 宿主 `destroyWidget()` 销毁悬浮窗，与设置页「隐藏挂件」同一路径；下次用设置页「显示挂件」或「显示/隐藏挂件」全局快捷键唤回时**重建窗口**，因此加载的始终是最新的悬浮窗页面。
- **一键复位窗口位置**：点「复位窗口位置」把挂件挪回**右下角默认位置**（宿主把锚点写回默认值后立即重摆），用于换显示器、改分辨率或拖出屏幕后找回挂件。
- **吸附与翻转设置**：① 吸附判定原先写死「挂件中心落进各边 1/4 区就贴边」（1920 宽下中心 x<480 就被吸走），现吸附区宽度由 `snapRatio` 给（1–45%，默认 25 保持原手感；上限取 45 是因为左右各 45% 只剩中间 10% 自由区，再大两侧吸附区会重叠）；② 新增「关闭吸附」档（`snapMode='off'`），松手停在哪就是哪 —— 位置**仍按「最近边 + 净距离」记锚点**，所以照旧能原样还原，只是不再自动贴边；③ 朝向（镜像）原先只在「贴左且紧贴」时生效，**自由摆放永远不翻**。现 `flippedOf` 简化为 `hAnchor === 'left'` —— `snapRect` 的自由分支记的本来就是「离最近的那条边」，`hAnchor` 已编码「挂件中心在中线哪一侧」，不必再算一次中线，于是**吸附与翻转解耦**：关掉吸附后朝向照样跟着位置走。缩放的不动点也复用 `flippedOf`（翻转侧保持挂件左缘、否则右缘），所以自由位缩放不会朝边缘挤。**未新增存储键与 IPC 通道**，两项走现有 `whale:config`；改这两个值不触发重摆窗口。

#### 改进

- **用量趋势升级**（原「近 7 天用量」）：柱状图可选 **7 / 14 / 30 天**（宿主一次给 31 天，前端只切片、切档位不重新请求；30 天档日期标签每 5 天抽稀、不显示柱顶金额），下方新增**本月汇总**（本月累计 / 日均（按本月已过天数摊，含今天）/ 最高单日 / **累计已用**）。账本 `history` 保留天数由写死的 30 天改为**可配**（`historyKeepDays`，35–730 天，默认 **365**，上下限与默认值由 `HISTORY_KEEP_DEFAULT / _MIN / _MAX` 三个常量给）—— 30 天档 + 31 号要回溯本月 1 号，31 天窗口不够。
- 「本月汇总」补上**累计已用**（账本滚动累计 `quotaUsed + 今天`，跨天只增不减，**不受历史保留期裁剪与上方区间影响**）；该行原本只在近 31 天有用量时才显示，现改为「有用量或累计已用不为 0」即显示，避免久未使用后看不到自己的累计。
- **账本明细筛选增强**：原检索只有「关键词命中即保留整天」一条路，导致某天只要有一条命中就把当天**全部**记录都列出来、想「只看手动校准」只能靠输入「校准」二字去猜。现加一个**类型下拉**（`detailKind`：全部记录 / 只看未计入 / 只看校准），命中口径改为**条目级** —— 先按类型过滤条目、再按关键词比 `entryText`，**整天没有命中条目就整天不显示**；关键词命中**日期串**（如 `09-12`）时仍保留当天全部条目。同时**筛选态下强制展开**（`dayOpen()` = 处于筛选态或该天在 `openDays` 里），命中的天直接摊开。无任何筛选时行为与原先**完全一致**。样式上新增 `.detail-kind` 并强制 `width:auto` —— 全局 `select` 是 `width:100%`，不覆盖会把同一行的检索框挤成一条。
- **今日模型占比**的模型名改为显示**友好名称**（如 `deepseek-v4-flash` → DeepSeek V4 Flash），鼠标悬浮可见原始模型 id；只做显示层映射，不合并数据、不改金额，未收录的 id 原样显示。
- **低余额阈值**的默认值来源统一：内置 DeepSeek 那条原先写死 `10`，现与多厂商模型走同一份 `LOW_ALERT_BY_CURRENCY`（人民币 10 / 美元 2），设置页侧用同值本地副本 `LOW_ALERT_DEFAULT`（preload 不参与打包，设置页拿不到宿主常量）；阈值单位**跟随账本币种**显示「元 / 美元」（此前写死「元」）。
- **自定义单价支持按模型覆盖**：`tokenPrice` 新增 `models` 数组（`[{name,hit,miss,out}]`，最多 `TOKEN_PRICE_MODELS_MAX` = 20 条，空名条目在 `normPriceModels` 里丢掉），按模型名**子串**匹配（与内置价目表同一规则），只填三个单价（币种与汇率全局共用一份）。取价改为**三级顺序**：`customModelPrice(custom, model) || customPriceTable(custom) || priceFor(model)` —— 按模型覆盖 → 全局覆盖 → 内置价目表，前者没命中就继续往下看，而不是「填了就整表覆盖」。

#### 修复

- 修复**挂件贴在屏幕上边时三点菜单看不见**：菜单原先固定往按钮**上方**展开，而窗口留白只有上/左单侧 `WIN_PAD`(200px)，挂件吸附到屏幕顶部后菜单上半截落在屏幕外。现改为**窗口四周各留 `WIN_PAD` 透明留白、挂件本体在窗口内居中**（窗口边长 = 挂件本体 + 400），并由宿主把「挂件本体到工作区上/下边缘的空白」随 `whale:init` / `whale:snapped` 下发（`widget.js` 的 `spaceAround()`），页面据此算出上/下**真正可见**的高度：上方装得下就照旧向上（不遮小鲸鱼），装不下且下方更宽就改向按钮**下方**展开（`.dshwv-menu-down` 反转入场动画、`transform-origin` 跟着换），高度不足时压 `max-height` 在菜单内滚动（去掉了原先 120px 的硬下限）。
- 三点菜单的开关顺手做了几处修正：关菜单那一下**立即重算**鼠标穿透与菜单按钮显隐（原先要等下一次 `pointermove`，导致这一下点击被窗口吞掉、同一位置再点也传不到下层应用）；点**鲸鱼本体**关菜单时这一下照常当点击/拖拽用（不用再点两次才能拖）；菜单开着时滚轮缩放挂件会**重新贴回按钮**（监听 `resize`）；重开菜单**回到顶部**；`positionMenu()` 在菜单没开时直接返回，模型行数变化不再白量一次自然高度；dsh 状态改为**展开该分组时才拉**，收着时不再白探一次本地 3080。
- 修复**峰谷组气泡的说明行太小**（挂件缩得越小越明显）：三行字号共用 `fitBubbleText` 的**同一个**缩放系数，而第 3 行「今日已用 ¥x · 距峰时 1h20m」是三行里唯一不换行的长行 —— 它按 nowrap 撑宽后远超 660u 的可用宽，于是按它算出 **k≈0.54**，**第 2 行的大字金额被一起从 114u（`P` 档）压到约 61u**、说明行从 62u 压到约 33u。现给这组第 3 行加 `dshwv-wrap` 允许折成两行，并把说明行档位从 62u 抬到 72u —— 挂件取最大尺寸 625px 时实测渲染字号由 **23.6 / 37.4 / 20.3px** 变为 **43.9 / 69.4 / 43.9px**（说明行 2.2 倍、金额 1.86 倍）。`FIT_H` 从 390u 放宽到 430u 以兜住折行后的高度（三行全展开约 404u），`.dshwv-hint` 的 `min-height` 同步 64u→74u。折行后最紧的一处是说明行第 2 行的底缘，按 canvas 字形墨迹盒核对仍在大椭圆内（还留约 46u ≈ 28px 余量）。
- 修复**常驻主显示的说明行太小**（同一个机制漏掉的另一条路径）：上一条只让**气泡台词**的第 3 行换行，但**常驻主显示**走的是另一段代码（`render()` → `setHint()`），而 `hintEl` 的 className 在初始化与 `restoreBubbleLines()` 里都写死为 `'dshwv-hint'`、**从不带 `dshwv-wrap`** —— 于是「今日已用 ¥x · 超预算 ¥y」（DeepSeek 超预算后常驻）与「已用 x% · M-D HH:MM 重置」（多厂商额度型）仍按 nowrap 撑宽、把三行一起压小。625px 档实测：超预算场景缩放系数 **0.518**、多厂商额度场景 **0.630**。现让常驻说明行默认带 `dshwv-wrap`，两者分别回到 **0.973** 与 **1**，说明行与金额行都放大约 1.6–1.9 倍；常规文案（「今日已用 ¥123.45」「~今日已用 ¥12.34」）本来就不到 660u，不受影响、也不会折行。
- 修正 **Flash 定价偏高 50%**：`BASE_PRICE` 原先每项都正好是正确值的 1.5 倍（缓存命中 `0.05/0.1`、未命中 `1.5/3.0`、输出 `4.5/9.0`），应为 `0.02/0.04`、`1/2`、`4/8`（Pro 三项本来就一致，未受影响）。此前「实时·令牌」模式算出的今日已用会**偏高 50%**。同时补上当前模型名 `deepseek-flash`（原先靠 `_default` 恰好兜住，官方若给 Pro 改名会静默少算一半），并让 `priceFor` 在价目表未收录时**留一条日志**（同一模型名只记一次，避免刷屏），便于官方上新 / 改名后及时发现。
- 修复**多厂商模型的 DeepSeek 模板可能取到美元余额**：内置主路径一直走 `pickBalanceInfo()`（优先「人民币且 > 0」），但把 DeepSeek 当**额外模型**添加时走的是通用字段路径，而模板原先写死 `balance_infos[0].total_balance` —— 该数组会同时给多种币种且**顺序不固定**，按下标取可能拿到美元那条，金额取错不报错、只把钱显示错。现 `pickPath()` 的数组段支持**按字段挑条目**（`balance_infos[currency=CNY].total_balance`，写法 `[字段=值]` 与原有 `[0]` 可混用），模板改为按币种挑；条件不匹配时返回 `undefined`，调用方提示「字段取不到数值」，比静默取错币种好。

- 新增「**贴边间距**」（设置页「挂件窗口」）：上/右/下/左四个数值（0–400px，0＝紧贴），吸附/贴边按它留距离，改完立即重摆

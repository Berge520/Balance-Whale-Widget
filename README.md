# 小鲸鱼余额挂件 · uTools 插件

桌面上一个透明、无边框、置顶的小鲸鱼挂件，常驻显示 **DeepSeek API 余额** 与 **今日已用**。移植自 DSH 版 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)，改为独立的 [uTools](https://u.tools) 插件（Vue 3 + Vite 6）。

## 特性

**余额与用量**

- 💰 **余额**：60 秒自动刷新（窗口隐藏暂停、可见即刷新），点鲸鱼手动刷新；变化时数字滚动动画，网络抖动自动沿用最近余额
- 📊 **今日已用**（双模式）：**小鲸鱼记账**（推荐，免令牌）按余额差值本地记账、跨天自动归档，保留期可配（默认 365 天，35–730 天）；**实时·令牌**填平台令牌后按峰谷定价精确换算，令牌失效自动回落记账
- 🛡️ **记账防误判**：赠送额度到期、短时间异常跳变、更换 API Key 三种情况不会误记为「今日用量」，被拦下的变动单列为「未计入的余额变动」
- 🎯 **手动校准今日已用**：漏采或误判后可一键改成真实金额（只改当天累计、留校准记录，不动余额基准；令牌模式下无需校准）
- 📈 **用量趋势与账本**：柱状图可选 **7 / 14 / 30 天**（不超过保留期），下方给出本月累计 / 日均 / 最高单日 / 累计已用；支持导出 / 导入 CSV（UTF-8 BOM，Excel 直接打开）
- 🔎 **账本明细与筛选**：按日列出用量，标出「未计入的余额变动」（红）与「手动校准」（灰），点开可见每条的时间与原因；支持**类型下拉**（全部 / 只看未计入 / 只看校准）与**关键词检索**（日期或原因），命中做到条目级、自动展开
- 🥧 **今日模型占比**（**仅实时·令牌模式**）：按模型列出今日金额占比，模型名显示友好名称（悬浮可见原始 id）
- 🎫 **额度进度**：填「资源包 / 订阅」总量并选重置周期（每月 / 每日 / 不重置），显示「已用 / 总量 · 剩余（百分比）」进度条（≥90% 换暖色）；只做展示，不影响余额、记账与预警口径
- 🧩 **多厂商余额 / 额度**：除内置 DeepSeek 外最多再添加 9 个模型，可切换挂件主显示 —— 余额型显示原币种余额（附「~今日已用」估算），额度型显示剩余百分比与重置时刻。内置 11 个厂商模板，只收录能用 API key 直接查到余额或额度的厂商；低余额阈值按币种分开（人民币 10 / 美元 2）。其它模型不参与记账、不写账本
- 🧾 **Codex 订阅窗口**：直接读 Codex CLI 的本地会话日志（`~/.codex/sessions` 下的 rollout JSONL），取出 5 小时 / 周窗口的已用百分比与重置时刻 —— **不用配 Key、不发请求、不碰账号**；按文件 size / mtime 增量缓存
- ⏰ **峰谷时段提醒**：进入峰时 / 谷时（工作日 9–12、14–18 点为峰时）时气泡提示当前时段与价格区间（可单独关闭），并显示距下次切换的倒计时
- ⏱️ **计时 / 定时 / 倒计时**：气泡内每秒刷新 —— 正计时、按分钟倒计时、指定时刻定时；支持暂停 / 继续 / 重置，模式与参数会被记住；到点响提示音、可选系统通知；开启「记住计时状态」后重载插件仍继续计时
- 🫧 **计时气泡显示方式**：「只显计时」开启时气泡只显示计时；「气泡常驻」控制计时气泡是否自动收起
- ⚠️ **低余额预警**：余额低于可配阈值时数字变红，并弹提醒气泡 + 每天一次系统通知（阈值单位跟随账本币种，默认人民币 10 / 美元 2）
- 📉 **余额大幅波动通知**：单次采样余额下降 ≥ 阈值就弹系统通知（**不做每天一次去重**），文案区分「正常消费」与「被防误判拦下的变动」；受免打扰约束
- 🎯 **今日预算提醒**：可设每日预算，当天超出时气泡提醒一次 + 第三行常驻「超预算 ¥x」，并每天一次系统通知（金额为 0 视为未设置）
- ⏳ **提醒停留时长可调**：峰谷切换 / 今日预算 / 低余额 / 穿透说明几类提醒气泡可选 **常驻 / 5 / 8 / 15 秒**（默认 8 秒）
- 🌙 **免打扰时段**：可设一段（如 `23:00–07:00`，**支持跨午夜**）只弹气泡、不弹系统通知；时段内不占用当天提醒名额，出时段后补发一次
- 📮 **邮件通知（SMTP）**：所有提醒统一走一个出口，按配置分流到**系统通知**（默认开）与**邮件通知**（默认关）。邮件用 Node 内置 `net` / `tls` 手写最小 SMTP 客户端（**不引第三方依赖**），支持 465 直连 TLS 与 25 / 587 `STARTTLS`；服务器 / 端口 / 加密 / 账号 / 授权码加密存储，设置页提供「发送测试邮件 / 测试通知」两个按钮。**邮件失败绝不影响主流程**
- ⏱️ **计时增强**：**到点留言**（≤60 字，到点气泡大字优先显示）、**休息档**（0–120 分钟，到点动作条多一个「休息 N 分钟」接下一轮）、**到点动作条**（气泡旁弹出独立操作条，与气泡同生共死）

**窗口与交互**

- 🐋 **桌面常驻小窗**：独立透明置顶窗口（置顶可关），不依附任何网页；透明区域点击穿透，不挡桌面操作
- 🫥 **窗口透明度**：20%–100%（设置页滑块实时预览 + 挂件菜单档位 100/80/60/40/20%），作用于整个窗口
- 🚫 **鼠标穿透**：开启后挂件完全不接收鼠标，点击 / 拖拽 / 菜单都穿透给下层应用；在鲸鱼上**停留约 1 秒临时接管**，移开约 0.7 秒自动交回。穿透中菜单按钮以半透明虚线常显作提示
- 🖱️ **拖拽 + 四边吸附**：松手时挂件中心落进某条边的吸附区就贴边（四角可组合），否则自由摆放；吸附区宽度可调（1–45%，默认 25%）也可关闭；朝向自动水平镜像（锚在屏幕左半边朝右、右半边朝左）；滚轮可直接缩放
- 🔒 **锁定位置**：禁止拖拽与滚轮缩放，避免误操作；点击刷新照常可用
- 🧲 **任务栏避让 + 贴边间距**：可关的「自动避让任务栏」（实时识别任务栏隐藏 / 显示），另有上 / 右 / 下 / 左四边贴边间距（0–400px，0＝紧贴）
- 🧭 **一键复位窗口位置**：换显示器、改分辨率或把挂件拖出屏幕后，一键挪回右下角默认位置
- 🧸 **按压 Q 弹** + 按压 / 松手双段音效（音效开关与音色可选）；💬 **思考气泡**（含 rua.gif 随机台词，长文案自动缩放字号）
- 🐳 **挂件形象可选 + 形象画廊**：**13 张内置形象**（默认 `DSniang1`）或**自定义**（导入 png / jpg / jpeg / webp / gif / apng，≤5MB，图片复制到本地数据目录）。「资源」Tab 里是缩略图网格：点图即切换、可置顶与删除，当前使用中的带角标；删掉当前那张自动顺延，全删光回退默认形象；最多 20 张。导入时可框选裁剪（含一键「自动裁掉透明边」，导出保留透明通道的 PNG），**GIF / APNG 不裁剪、原样复制**以保住动画；换形象后穿透轮廓按新图重算
- 🖼️ **自定义气泡图**（「资源」Tab）：导入自己的图片（png / jpg / jpeg / webp / gif / apng，≤5MB），点小鲸鱼抽到「气泡图」那组台词时随机显示一张；**一律原样复制、不裁剪不重编码**（避免动图丢帧）；最多 8 张，没有「当前用哪张」，删光回退内置 `rua.gif`
- 🎨 **气泡主题**：默认（蓝白）/ 深色 / 樱花三套配色，只改气泡与文字颜色（低余额的红色是状态色，不随主题变）
- 🎵 **自定义音效**：按压 / 释放两段可分别导入（mp3 / wav / ogg / m4a / flac，≤5MB，建议 1 秒左右），文件复制到本地数据目录；导入时可看波形拖选一段（最多 10 秒，可试听选区，导出 WAV）并支持试听；释放音可缺（松手静音），按压音缺失时回退「小黄鸭」
- 🔔 **提醒音效**：低余额 / 今日预算 / 峰谷切换 / 鼠标穿透四类提醒可各导一段提醒音。与音色不同，**留空即静音**，且不受「音色」下拉影响，只要音效开关为开、音量不为 0 就会响
- 🔁 **音效组**：六个槽位（音色两段 + 四类提醒音）每个都能导**多段**，挂件每次随机播一条且不会连续重复；删到只剩一段就固定播它，老数据读取时自动升级
- 🗂️ **素材集中管理**（「资源」Tab）：形象 / 气泡图 / 六段音效的导入 / 试听 / 删除都在这里，每项显示体积与导入时间，**不随形象 / 音色的选择隐藏**；卡头有「清除未使用（n）」（只删当前设置不会用到的素材）与「清除全部素材」（只删素材、不动其它设置）；另有折叠的**素材包**与**内置资源对照**
- 🕐 **小鲸鱼报时**：点击鲸鱼时气泡首行报当前时间（鲸鱼娘语气，深夜 / 清晨换台词）
- 🔀 **点按依次播放台词**：开启后点气泡按顺序播放各台词组，关闭则每次随机一组（默认关闭）
- 📝 **台词库可配置**（「文案」卡片）：随机台词是**可增删的组列表** —— 每组可选类型（余额/时段卡 / 自定义台词 / 气泡图）、填权重（1–999）、文本组还能选字号，并用「↑ / ↓」调顺序；台词一行一条，最多 12 组；**留空的文本组保存后会被丢掉**
- ✏️ **提醒文案可编辑**（「文案」卡片）：四类提醒的气泡与系统通知共用一份文案，六条都能改，**最多三行**对应「标题 / 大字 / 说明」；支持 `{balance}` `{threshold}` `{used}` `{budget}` `{over}` `{schedule}` 占位符，写错的会原样显示；清空某一条＝恢复内置默认

**设置与集成**

- 🔑 **凭据加密存储**（uTools `dbCryptoStorage`）；「测试连接」分项验证 API Key 与平台 Token
- 🎚️ **挂件菜单**（悬停鲸鱼右上角按钮，或右键）：大小 / 音效 / 音量 / 透明度 / 模型 / 用量 / 峰谷文案 / 气泡 / 峰谷提醒 / 报时 / 计时 / 锁定 / dsh / 打开设置 / 隐藏挂件
- ⌨️ **全局快捷键**：可为「显示/隐藏挂件」与「切换鼠标穿透」绑定 uTools 全局快捷键，触发时不弹搜索框；后者是穿透开启后的快捷逃生通道
- 🔀 **进入方式可选**：设置窗口 + 挂件（默认）/ 只显示挂件 / 只显示设置窗口
- 🔄 **自动检查更新**：每次呼出插件检查一次（12 小时内最多一次），发现新版本弹系统通知（默认关闭）
- 🚀 **GitHub 加速（hosts 方案）**：一键改写系统 **hosts** 让 GitHub 相关域名直连可用 IP，浏览器 / git / 下载全生效，**不装代理、不改系统代理、不占常驻进程**。写入前逐条做 **DoH 实时解析 → HTTPS 探测 + 证书 SAN 校验**（避免解析到被劫持的 IP），只写真正可用且证书确实匹配该域名的 IP，同一域名保留多个备用 IP 做运行期回退；写入需一次 **UAC 确认**，关闭即删块、**不动你原有的 hosts 内容**。另有「检测连接」「刷新 IP 表」「重新写入 hosts」、IP 表手动编辑、操作日志与来源追踪表，位于设置页「帮助」Tab

**开发者集成（dsh，可选）**

- 🧩 **DeepSeek Harness 一键管理**：挂件菜单「dsh」分组可直接启动 / 重启 / 结束 / 更新 dsh 并打开 Web UI（自动使用带 token 的地址）
- 🔍 **外部进程也能管**：按 `127.0.0.1:3080` 探测运行中的 dsh，别的终端里启动的也能被结束 / 重启；端口被非 dsh 进程占用时拒绝操作，不会误杀
- 🛡️ **权限兜底**：普通权限被系统拒绝时自动改用管理员权限重试一次（弹一次 UAC 确认）
- ⚙️ **可配置**：dsh 优先复用你已全局安装的那份，没有才装到插件数据目录；启动直接跑 `node`，不经过 `npx`。另有「启动时不自动打开浏览器」、npm 注册源、dsh 版本（默认「自动」）、Node.js 目录、更新前重新下载、uTools 退出后是否保留 dsh
- 💾 **备份与恢复**：一键导出「挂件设置 / 账本 / 窗口位置 / 计时」为 JSON；凭据默认不导出，勾选后需设密码并用 scrypt + AES-256-GCM 加密写入；导入时列出备份内容、勾选要恢复的项，同名覆盖
- 📜 **运行日志**：带时间戳、自动清理 ANSI 转义并识别中文 Windows 的 GBK 输出；启动后显示「3080 已就绪（用时 x.xs）」与最近执行的命令

- PowerShell / 任意终端（示例命令为 PowerShell 写法，其他 shell 等价）

## 安装

### 方式一：插件应用市场（推荐）

在 uTools 中搜索「插件应用市场」，搜 **小鲸鱼余额挂件** 安装即可。

### 方式二：本地开发（热更新）

```powershell
npm install
npm run dev      # Vite dev server，http://localhost:5173
```

在 uTools 中：打开 **开发者工具** → 新建项目，**插件入口目录选本项目的 `public/`** → 用指令 `余额挂件` / `小鲸鱼` 呼出。

设置页走 dev server 热更；**悬浮窗页面与 preload 不热更**，改动后需在 uTools 里**重新加载插件**。

### 方式三：打包安装

```powershell
npm run build      # 产物输出到 dist/（prebuild 会先同步版本号 + 校验跨文件常量副本）
npm run lint       # 可选：eslint . 静态检查（未定义 / 未使用变量、Vue 模板错误用法等）
npm run typecheck  # 可选：vue-tsc --noEmit 类型检查
npm test           # 可选：Node 内置 node --test 跑单测（覆盖定价 / 取余额 / 归一化 / 备份加解密 / Codex 解析五组纯函数）
```

uTools 开发者工具中把插件入口目录指向 **`dist/`**。需要分发时可再「打包」为 `.upx`，拖入 uTools 主输入框即可安装。

```text
7. 以后升级：回源码目录 git pull（或重新下载）→ 再跑一次 npm run build → 在开发者工具里点「重新加载」，项目不用重建。

要求：只做上面这些，不要改仓库里的任何文件，不要跑 npm run dev（那是需要常驻窗口的开发模式）。
```

只想拿到成品、不折腾命令行的，直接走上面的「方式一：插件应用市场」。

## 配置

呼出插件后，主窗口即设置页。设置页按主题分 **7 个顶部 Tab**：**外观**（大小 / 形象与音色 / 文案）、**资源**（素材总览 / 形象画廊 / 气泡图 / 音效 / 素材包）、**用量**（趋势与账本 / 模型余额 / 提醒与通知）、**窗口**（显隐 / 位置 / 透明度 / 穿透）、**数据**（凭据 / 清除数据 / 备份与恢复）、**帮助**（使用说明 / 故障排查 / **GitHub 加速** / 关于与更新）、**dsh**（DeepSeek Harness / dsh 用量统计 / Codex 会话统计），Tab 条吸顶、下方一行小字说明本组内容。

1. **DeepSeek API Key（必需）**：[platform.deepseek.com](https://platform.deepseek.com) →「API keys」创建（`sk-` 开头）→ 粘贴到 **API Key** 框 →「保存凭据（加密存储）」。
2. **平台 Token（可选，仅「实时·令牌」用量模式）**：登录 [platform.deepseek.com](https://platform.deepseek.com) → `F12` → Network → 打开「用量」页 → 找 `usage/by_api_key/amount` 请求 → 复制其 Request Headers 里 `Authorization` 的值（形如 `Bearer eyJ...`，前缀可带可不带）→ 粘贴到 **平台 Token** 框保存。

令牌是网页会话，重新登录平台后可能失效（届时会自动回落记账模式）。填好后点「测试连接」可分别验证两项凭据。

## 使用

- **呼出**：`余额挂件` / `小鲸鱼` / `小鲸鱼余额` / `DeepSeek余额` / `whale`
- **点鲸鱼**：弹余额气泡 + 手动刷新 + 报时；点气泡切随机台词组，再点关闭（5 秒自动收起）。开启「点按依次播放」后改为依次播放各组台词
- **拖鲸鱼**：松手时挂件中心落进某条边的吸附区就贴边，否则自由摆放；吸附区宽度与开关见设置页「挂件窗口」
- **滚轮缩放**：指针停在鲸鱼上滚动即可放大 / 缩小（1–20 档），停手后自动保存（**锁定位置时禁用**）
- **锁定位置**：禁止拖拽与滚轮缩放；点击刷新气泡不受影响
- **吸附与翻转**：选「比例吸附 / 关闭（自由摆放）」，「吸附区宽度」（1–45%，默认 25）决定离边多近才吸走；选「关闭」则停在哪就是哪（位置仍会被记住）。朝向不单独配：锚在屏幕左半边朝右、右半边朝左
- **贴边间距**：上 / 右 / 下 / 左四个数值（0–400px，0＝紧贴该边），吸附 / 贴到该边时按它留出距离，改了立即生效；开着「自动避让任务栏」时任务栏那条边自动让位
- **复位窗口位置**：把挂件挪回右下角默认位置，换显示器、改分辨率或拖出屏幕导致找不到时用它
- **调整透明度**：设置页滑块（20%–100%，拖动实时预览）或挂件菜单「透明度」档位，两处共用同一设置
- **鼠标穿透**：勾选后挂件完全不接收鼠标，把鼠标停在鲸鱼上约 1 秒即可临时接管（菜单按钮由虚线变实心），移开约 0.7 秒自动交回；也可为「切换鼠标穿透」绑定全局快捷键一键开关。**注意**：穿透开启后挂件菜单也点不到，绑快捷键是最稳的退出方式
- **自定义音效**（「资源」Tab → 「导入的音效」）：分别导入「按压音」与「释放音」（可缺），支持 mp3 / wav / ogg / m4a / flac、≤5MB；选完文件会弹出波形图，拖手柄选一段（最多 10 秒）试听确认后导出 WAV 落盘，中途取消不留半成品；已导入的可点「试听」。**同一槽位可导多段**，挂件每次随机播一条且不连续重复
- **提醒音效**（「资源」Tab → 「导入的音效」）：四类提醒可各导一段，导入方式与按压音相同。**留空即静音**，播放只看音效开关与音量，不受「音色」下拉影响
- **自定义气泡图**（「资源」Tab → 「导入的气泡图」）：导入图片（png / jpg / jpeg / webp / gif / apng，≤5MB），**不裁剪、原样复制**（动图保住动画），导入即参与随机；网格里只有缩略图与「删」，最多 8 张
- **挂件形象 / 气泡主题**（「外观」Tab「挂件外观」卡片）：「形象」下拉可选内置形象或「自定义」，选「自定义」但还没导入图片时会提示前往「资源」Tab。自定义形象的导入 / 删除 / 切换都在「资源」Tab（缩略图网格）：导入后立即生效并自动切到这张；点缩略图即切换、可置顶、可删除，最多 20 张。「气泡主题」可选默认（蓝白）/ 深色 / 樱花，改完立即生效
- **素材集中管理**（「资源」Tab）：**五张卡** —— 「资源概览」（项数 / 占用体积 / 两个清除按钮 / 折叠的素材包）、「导入的形象」、「导入的气泡图」、「导入的音效」（六个槽位，每项显示文件名、体积与导入时间）、「内置资源」（内置形象与两组内置音色，可预览试听、不可删）。与「外观」Tab 的分工：那边只管用哪个，这里管导了什么、占多大、要不要删；切回内置形象或音色后素材仍列在这里。两个清除按钮：「清除未使用」只删当前设置不会用到的素材（正在使用的一律保留，气泡图不参与统计）；「清除全部素材」把导入的素材全删并把形象 / 音色回退内置。两者都只动素材
- **素材包**（「资源」Tab · 资源概览内的折叠区）：「导出素材包…」把导入的形象 / 气泡图 / 音效打包成一个 `.whaleassets` 文件（单文件、不压缩）；换机器时「导入素材包…」选中后列出包内条目、勾选要写入的项即可。形象与气泡图是**追加**，音效是**同槽位覆盖**（会二次确认）
- **台词库**（「文案」卡片 · 「台词库」分组）：六组文案各一个输入框，**一行一条**（单条最多 60 字、每组最多 30 条）——短句、闲聊、dsh 吐槽、收尾、报时文案（`{t}` 替换成当前时间）、动图降级。改完点「保存」立即生效；「恢复默认」填回内置台词；**某组清空＝该组恢复内置默认**
- **提醒文案**（「文案」卡片 · 「提醒文案」分组）：六条 `textarea` 对应低余额 / 今日预算 / 进入峰时 / 进入谷时 / 穿透开启 / 穿透关闭，气泡与系统通知共用同一份文案；**最多三行**对应「标题 / 大字 / 说明」（超过三行并入说明行），系统通知取全文并合并换行。占位符写错的会原样保留便于发现；「保存」立即生效，「恢复默认」填回内置文案，**清空某一条＝恢复内置默认**
- **用量趋势图**（「用量」Tab「用量与账本」卡片）：右上角切 **7 / 14 / 30 天**，下方「本月汇总」给出本月累计、日均（按已过天数摊）、最高单日与累计已用。柱顶金额只在 7 / 14 天档显示
- **历史保留**：账本按天归档的保留期可配（35–730 天，默认 **365**）。改小后趋势图档位、CSV 区间上限、明细记录一并跟着缩；累计已用**不参与裁剪**
- **账本明细**：点「展开账本明细」按日列出每日用量；右上角**类型下拉** + **检索框**（日期或原因）可叠加使用，命中是条目级的且自动展开；区间跟随上方档位，明细只在展开时读取一次
- **校准今日已用**（仅记账模式）：填入真实金额点「校准」即可改当天累计，同时显示「今日另有 ¥x 余额变动未计入用量」及原因与时间
- **今日模型占比**（仅「实时·令牌」模式）：按模型列出今日花费占比（按金额降序），标题行显示「共 ¥x · 更新于 HH:MM」；未填平台 Token 时显示「读取失败：未配置平台 Token」
- **额度**：填「额度总量」（元）并选重置周期，下方出现进度条与「已用 / 总量 · 剩余（百分比）」。总量填 0 即不显示；额度只做展示
- **多厂商余额 / 额度**（「用量」Tab「模型与余额」卡片）：点「添加模型」→ 选厂商模板 → 填名称与 API Key → 保存；列表里点行首单选即设为挂件主显示，行尾「设置 / 刷新 / 删除」。行内表单可改类型、币种，「高级设置」可改认证方式、字段路径、倍数与低余额提醒；「测试连接」立即拉一次，「刷新全部」批量拉取。只有内置 DeepSeek 时挂件菜单的「模型」分组整组隐藏
- **今日预算提醒**（「提醒与通知」卡片）：勾选后填金额（元），当天用量超出时弹一次提醒气泡、第三行常驻「超预算 ¥x」，并每天一次系统通知；同一天内多次超出不重复通知
- **低余额预警**（「提醒与通知」卡片）：勾选后填阈值（单位跟随账本币种，默认人民币 10 / 美元 2），余额低于阈值时数字变红并弹提醒气泡 + 每天一次系统通知；与今日预算同时命中时以低余额为准
- **余额大幅波动通知**（「提醒与通知」卡片）：勾选后填下降阈值（元，默认 5），单次采样下降 ≥ 阈值就弹系统通知，**不做每天一次去重**（每次下降只会被采样到一次）
- **提醒停留时长 / 免打扰时段**（「提醒与通知」卡片）：停留时长控制峰谷切换 / 今日预算 / 低余额 / 穿透说明几类气泡的收起时间（计时到点气泡单独控制）；免打扰可设起止时刻（可跨午夜），时段内三类自动通知都不弹系统通知、且不占用当天名额，出时段后补发一次
- **悬停鲸鱼 → 右上角菜单按钮**：大小 / 音效开关 / 音色 / 音量 / 透明度 / 模型 / 用量模式 / 峰谷文案 / 气泡 / 峰谷提醒 / 报时 / 计时 / 锁定 / dsh / 打开设置 / 隐藏挂件（菜单按钮本身可在设置页隐藏，隐藏后右键鲸鱼仍可打开）
- **计时 / 定时 / 倒计时**：菜单「计时」选模式 →「目标」填时长或 `HH:MM`（已过点顺延到明天）→ 点「开始」，气泡立即显示并每秒刷新；「暂停 / 继续 / 重置」齐全，点气泡收起不中断计时。菜单里「到点通知」「只显计时」「气泡常驻」「计时保存」分别控制系统通知、计时是否独占气泡、计时气泡是否自动收起与重载插件后是否继续计时
- **dsh**：菜单「dsh」分组有 `启动` / `重启` / `结束` / `更新` 四个按钮 + `打开页面`，下面两行显示运行状态与最近执行的命令。启动后 3080 就绪前显示「启动中…」（该分组只在本机装了 dsh 或 dsh 正在运行时才出现）
- **dsh 设置页**（「dsh」Tab）：「DeepSeek Harness（dsh）」卡片可配置 npm 注册源、dsh 版本（可先「查询可用版本」，结果会缓存）、Node.js 目录、`--no-open`、更新前重新下载、uTools 退出后是否保留 dsh；卡片里还能看到插件目录 / 全局安装 / 实际使用、最新版本、状态 / 最近命令 / 页面地址，并支持复制地址 / 查看日志 / 复制日志
- **「使用帮助」卡片**：显示 / 隐藏挂件；使用说明与故障排查两组折叠；「复制指令名」「新增快捷键」用于绑定全局快捷键；进入设置页时自动检查挂件状态，仅在创建失败时展开错误详情
- **全局快捷键**：按 `Ctrl+,` 打开 uTools 设置 → **全局功能** → 新增 → 指令填「显示/隐藏挂件」（可点「复制指令名」快速复制）→ 按下组合键

## 定价表

「实时·令牌」模式按平台用量接口返回的 token 数 × 下表单价换算今日已用。金额单位 **元 / 百万 token**，写成 `[谷价, 峰价]`。

- **高峰**：工作日 **9:00–12:00、14:00–18:00**（北京时间）
- **谷价**：其余时间，恰为峰价的一半；**2026-08-23 起周末全天按谷价**
- 时段判定与定价实现在 [constants.js](public/preload/lib/constants.js)（`PEAK_HOURS` / `BASE_PRICE` / `PRO_PRICE`）与 [pricing.js](public/preload/lib/pricing.js)，官方调价时改这里；「小鲸鱼记账」模式不依赖本表

| 模型 | 缓存命中 | 缓存未命中 | 输出 |
|---|---|---|---|
| `deepseek-flash`（当前模型名，含旧名 `deepseek-v4-flash` / `deepseek-v4-flash-vision-exp`） | 0.02 / 0.04 | 1 / 2 | 4 / 8 |
| `deepseek-v4-pro` | 0.15 / 0.3 | 4.5 / 9.0 | 13.5 / 27.0 |

> 模型名按**子串**匹配上表（键的顺序即优先级）；`deepseek-chat` / `deepseek-reasoner` 以及匹配不到的模型名一律按 Flash 价计，未收录的模型名会在开发者日志里留一条记录，便于官方上新 / 改名后及时发现。
>
> 对不上实际账单时（比如走了中转站或官方调价），可在设置页「用量与账本」勾选**自定义单价**：按百万 token 填谷价并选币种，峰价自动按官方规则（谷价 × 2）翻倍，选美元再填汇率（元/USD）；**账本与挂件显示统一按人民币**，不受填的币种影响。
>
> 只改了几个模型的价时，用下面的**「按模型覆盖」**：点「＋ 添加模型」填模型名（按**子串**匹配，如 `deepseek-v4-pro`）与该模型的三个单价，最多 20 条。取价是**三级顺序** —— 按模型覆盖 → 全局自定义单价 → 内置价目表，前者没命中就继续往下看（不是「填了就整表覆盖」）。模型名留空的条目保存时会被丢掉。

## 数据与隐私

- **存了什么**：凭据（API Key / 平台 Token / 各厂商模型各自的 API Key，一模型一份，均在 uTools `dbCryptoStorage` 加密存储）、挂件设置（含模型列表与主显示）、本地账本（用量 / 余额基准 / 校准与「未计入」记录）、计时状态、窗口位置与更新缓存，以及导入的音效 / 形象 / 气泡图文件（复制到插件数据目录 `userData/whale-sounds/`、`whale-skins/`、`whale-bubbles/`）。**全部只保存在本机，不会上传第三方**；除余额接口（`api.deepseek.com`）、用量接口（`platform.deepseek.com`）、你添加的厂商模型自己的余额 / 额度接口与更新检查外无任何外部请求；**邮件通知开启后会连接你自己配置的 SMTP 服务器**。模型的余额 / 额度是**运行时快照**（`whale:models`），只是缓存，不进备份、清除「挂件设置」时一并清掉。
- **更新检查默认关闭**（设置页「帮助」→「自动检查更新」手动开启，开启后每次呼出最多 12 小时查一次）：向 `ghfast.top`（GitHub 内容加速代理）拉一次本项目的 `package.json` 比版本号，**请求里不含任何用户数据**（无 body、无 Cookie、不带 Key），不开即完全不出网。
- **GitHub 加速**（设置页「帮助」→「GitHub 加速」，**默认关闭**）：开启后才出网 —— 向 2 个公共 **DoH**（DNS over HTTPS）端点查询待加速域名的 A 记录，并从社区 hosts 源表（GitHub520 及其镜像）拉取 IP 列表；请求只含**要解析的域名**，不含任何用户数据。改写的**只有 hosts 文件里本插件自己的标记块**（`whale-ghaccel start/end` 之间，上限 64 条），关闭即整块删除，你原有的 hosts 内容一字不动；写入需一次 **UAC 提权确认**（复用 dsh 的提权通道，临时脚本落在系统临时目录、不写仓库）。本功能**只在本机改 hosts**，不安装任何常驻进程、不改系统代理。
- **导出 / 导入账本**：设置页「用量与账本」卡片右上角可在 CSV 与账本之间互转（日期 / 用量 / 币种三列，带 BOM，Excel 直接打开）；导入按日期合并（同日覆盖），只保留最近「历史保留」设置的天数（默认 365）。
- **卸载不删数据**（步骤见 [卸载](#卸载)）：在 uTools 里移除插件**不会**自动清除上述数据。设置页「数据与隐私」可**勾选要清除的项目**（凭据 / 挂件设置 / 账本用量记录 / 窗口位置与更新缓存 / 自定义音效 / 自定义形象 / 自定义气泡图），点「清除选中数据」并二次确认后只清除勾选项（确认时会列出**将清除哪些项**）；清除挂件设置或窗口位置后会按默认值重建挂件，只想重置挂件外观时不必重填凭据；清除自定义音效会删掉导入的音频文件，并把音色一并回退为「小黄鸭」，清除自定义形象会删掉图片文件并把形象回退为内置鲸鱼娘，清除自定义气泡图会删掉图片文件、挂件气泡随即回退内置动图（气泡图不选「当前用哪张」，所以不需要改任何配置）。**模型相关**：清除「凭据」会一并清掉各模型的 API Key（模型列表还在，但需重新填密钥），清除「挂件设置」会连模型列表与余额快照一起清掉（挂件回到只显示 DeepSeek）。
- **备份与恢复**（设置页「数据与隐私」→「备份与恢复」）：
  - 导出会把「挂件设置 / 账本 / 窗口位置 / 计时」写成一个 JSON 文件（不含 dsh 开发者配置与 Node 路径）。
  - **凭据默认不导出**；勾选「包含凭据」后必须设密码（≥6 位），凭据（含各厂商模型的 API Key）用 **scrypt 派生密钥 + AES-256-GCM** 加密后才写入文件——文件里没有明文，改一位就解不开；密码不保存在任何地方，忘记只能放弃凭据（其余项仍可恢复）。旧备份（不含模型密钥）恢复时**不会**抹掉你已保存的模型密钥。
  - 导入时先读取备份并列出「导出时间 / 插件版本 / 包含项」，勾选要恢复的项后写入（**同名覆盖**，账本同日覆盖并保留最近「历史保留」设置的天数）；恢复「挂件设置」或「窗口位置」会重建一次挂件，立即生效。
  - 备份文件本身含你的设置与用量记录（凭据除外为加密块），请妥善保管。
- **dsh 相关**：只在本机执行（`node` 运行 dsh / 需要时用 `npm` 安装或更新它 / `taskkill`），不会把任何内容发到第三方服务器。dsh 的输出日志**仅保存在内存**（最多 160 行，供设置页查看），重新加载插件即清空；「打开页面」所用带 token 的地址取自 dsh 自身的输出，同样只存内存、不写入本地存储。dsh 自己的配置与数据由 dsh 管理（默认在用户目录 `~/.dsh`），本插件不做改动。

## 卸载

在 uTools 里移除（卸载）本插件即可，没有额外的清理步骤。

- **移除插件不会删除数据**：凭据、挂件设置、账本、窗口位置与更新缓存、导入的自定义音效与形象图片都留在本机，重新装回来照旧可用。
- 想**连数据一起清掉**，请在**卸载前**到设置页「数据与隐私」→「清除数据」按项勾选并确认（可只清凭据 / 只清账本，或全选）；卸载后插件界面就没了，只能重装一次再清。
- 换机器或重装后想还原设置，先用「数据与隐私」→「备份与恢复」导出备份，详见 [数据与隐私](#数据与隐私)。

## 常见问题

- **挂件不出现**：确认入口目录（dev = `public/`，打包 = `dist/`）；点设置页「显示挂件」；点「挂件异常？查看错误详情」看宿主记录的失败原因并复制，或主窗右键 → 检查看 `[whale][widget]` 日志。
- **悬浮窗调试**：焦点在挂件窗口上按 `Ctrl+Shift+I`。
- **开启鼠标穿透后挂件点不动**：这是预期行为（连挂件菜单也穿透了）。用「切换鼠标穿透」全局快捷键关掉，或把鼠标**停在鲸鱼上约 1 秒**临时接管后，从挂件菜单「打开设置」回设置页关闭。建议先在设置页「挂件窗口 → 鼠标穿透」处点「新增快捷键」绑好，再开启穿透。
- **听不到自定义音效**：确认「音效开关」为开、音量不为 0、音色选的是「自定义」且**已导入「按压音」**（未导入时会回退「小黄鸭」）；只导入按压音、没导入释放音时，松手那一下是静音（这是预期）。若导入的是 flac/m4a 而系统解不了码，换 mp3 / wav 再试。
- **提醒时没声音**：四类提醒音（低余额 / 预算 / 峰谷 / 穿透）**留空就是静音**，与音色无关，得先去「资源」Tab 的「导入的音效」里各导一段；导了还听不到再查「音效开关」与音量。
- **今日已用突然变大**：v1.4.0 起「赠送额度整块到期 / 被平台收回」与「短时间异常跳变」不会再计入；若仍异常，说明下降幅度落在可信范围内被判成了消费，可用设置页「用量与账本」卡片的「校准今日已用」改成真实金额（会留校准记录），并把「今日另有 … 未计入用量」那行提示一起反馈回来。
- **透明度调了没反应 / 挂件整窗看不见**：请确认版本为 v1.4.0 且已在 uTools 里**重新加载插件**（preload 与 `floating.css` 都不热更）。旧实现用窗口级 `setOpacity`，在 Windows 的分层透明窗上会导致整窗不显示，v1.4.0 已改为页面 CSS 透明度。
- **401 API Key 无效**：确认填的是 `sk-` 开头的 **API Key**（不是平台 Token）；用「测试连接」看服务器原文。
- **添加的模型一直显示 `--`**：点该行「设置 → 测试连接」看服务器原文。常见原因：密钥没填（或填错厂商，注意 Moonshot 大陆站与国际站是两套账号、两套密钥）、字段路径与该厂商返回不一致（可用「高级设置」改路径）、自定义 HTTP 模板没填 `{base}`、或接口需要特殊认证（智谱系要选「原始值」）。挂件里显示 `--` 说明该模型这条还没取到值，其它模型不受影响。
- **今日已用显示 `--`**：记账模式需先有一次余额观测（60 秒内）；令牌模式需配好平台 Token，失败会回落记账。
- **峰谷提醒不出现**：提醒依赖**思考气泡**，需同时开启「思考气泡」与「峰谷切换提醒」；且只在时段**切换**的瞬间提示一次，刚启动时不会补弹。
- **今日预算提醒没弹 / 只弹了一次**：系统通知**每天只发一次**（同一天内继续超支不再重复，跨天自动恢复）；气泡提醒同样需要「思考气泡」开着，且计时进行中不打断计时；刚呼出插件时若已超预算不会补弹气泡，但第三行「超预算 ¥x」常驻提示照常显示。注意「每日预算」金额为 0 等于未设置，可在设置页「提醒与通知」卡片里改。
- **低余额预警没弹 / 只弹了一次**：系统通知同样**每天只发一次**（跨天自动恢复）；气泡提醒需要「思考气泡」开着，且计时进行中不打断计时。与「今日预算提醒」同时命中时只弹低余额那条。若在免打扰时段内，通知会推迟到出时段后补发。
- **免打扰时段内还是弹了通知**：免打扰只静默「今日预算」与「低余额」两类**自动**通知；计时到点是你在挂件菜单里主动设的一次性提醒，照常通知。另外请确认起止时刻不是同一个值（相同时视为未开启）。
- **提醒气泡一闪而过 / 一直不消失**：停留时长在设置页「提醒与通知」卡片的「提醒停留时长」里改（常驻 / 5 / 8 / 15 秒）；选「常驻」需手动点气泡收起。该设置不影响计时到点气泡（由挂件菜单「到点通知」旁的档位控制）。
- **计时到点没声音 / 没通知**：提示音走挂件音效，需「音效开关」为开且音量不为 0；系统通知由「计时到点通知」开关控制（关闭时只响提示音 + 气泡）。挂件窗口在后台被系统节流时，到点可能略有延迟，切回挂件即会立即补响。
- **重载插件后计时没了**：确认「记住计时状态」为开；关闭后计时只在本次运行内有效。
- **没声音**：音量不为 0；Electron 首次需先有一次交互。
- **改了 preload 不生效**：preload 不热更，需在 uTools 开发者工具里重新加载插件。
- **dsh 提示「未找到 Node.js」**：设置页「DeepSeek Harness」→「选择目录」指定 Node.js 安装目录（如 `D:\nodejs`），或点「改为自动探测」；卡片里会显示实际生效的目录与版本。
- **dsh 提示 3080 端口被占用**：说明已有 dsh 在运行（可能是在别的终端里启动的）。点「结束」或「重启」即可接管；若占用端口的是**非 dsh 程序**，插件会拒绝操作并提示，避免误杀。
- **点「结束」提示「权限不足 / 拒绝访问」**：那个 dsh 是**管理员权限**启动的。插件会自动改用管理员权限重试（弹一次 UAC 确认框）；也可以管理员身份运行 uTools，或直接在 dsh 自己的终端里按 `Ctrl+C`。
- **打开页面提示 authentication required**：dsh 的 Web UI 首次访问需要带 `?token=` 的地址。由插件启动的 dsh 会自动捕获该地址（设置页「页面地址」可查看 / 复制）；外部终端启动的 dsh 请使用它自己打印的地址，或在插件里「重启」一次以接管。
- **dsh 首次启动很慢 / 「启动中…」很久**：首次会自动下载安装（约 500 多个包，之后启动就快了）；国内建议把「npm 注册源」改成淘宝镜像。启动完成后状态会变成「运行中」，并在日志里记录「3080 已就绪（用时 x.xs）」。
- **结束 dsh 后 dsh 又起来了**：说明它有守护进程 / 你是在某个会自动重启它的工具里启动的，请在它自己的终端里 `Ctrl+C` 关闭。

## 开发与构建

```powershell
npm install
npm run dev         # Vite 开发服务器（配合 uTools 开发者工具指向 public/）
npm run lint        # eslint . 静态检查
npm run typecheck   # vue-tsc --noEmit 类型检查
npm test            # node --test 单测（test/*.test.mjs）
npm run build       # 构建到 dist/（prebuild 自动同步版本号 + 校验跨文件常量副本）
```

- 改动 `preload/` 或 `floating-*`：不热更，需在 uTools 开发者工具里**重新加载插件**才能看到效果。
- preload 文件为 CommonJS，**不可压缩混淆**，发布时保持原样。
- `npm run lint` 的配置在 `eslint.config.js`：只查真问题（未定义 / 未使用变量、重复键、不可达代码、Vue 模板里的错误用法），**不含格式规则**（缩进 / 引号交给编辑器）；按四套运行环境分块声明全局变量（设置页 / preload / 悬浮窗页面 / 构建脚本）。
- 同一份常量在宿主 / 设置页 / 浮动页 / 样式表里各有一份副本（preload 不参与打包、浮动页没有 `require`、CSS 变量宿主读不到），`scripts/check-shared.mjs` 会在构建前比对，不一致直接构建失败；新增这类副本时记得把这一对加进它的 `CHECKS`。
- **持续集成**（`.github/workflows/ci.yml`）：push 到 `main`、任何 PR、手动触发时，依次跑 `npm run lint` → `npm run typecheck` → `npm test` → `npm run build`（Node 24 + `npm ci`）。这四关就是上面这些本地命令本身，**CI 不额外引入工具链**，所以「本地能过」和「CI 能过」是同一件事；构建产物 `dist/` 不上传、不发布。
- **发版**（`.github/workflows/release.yml`）：只改 `package.json` 的 `version` → 提交 → 打同名 tag（如 `v1.5.1`）并推送。工作流会先校验 tag 与 `package.json` 版本一致（不一致直接失败），再跑与 CI 同一套检查、构建，把 `dist/` 打包成 `balance-whale-widget-<tag>.zip` 并建 Release（变更说明由 GitHub 按 commit / PR 自动生成）。**uTools 市场的 `.upx` 仍需人工**在开发者工具里打包上传。

**新功能 · GitHub 加速（hosts 方案）**

- **一键加速 GitHub**：新增宿主叶子模块 `lib/hosts.js` 与设置页组件 `src/views/AccelView.vue`，走**改 hosts 文件**这条路（不装代理、不改系统代理）。流程：**DoH 实时解析**（2 个公共端点，按 5 分钟缓存）→ **HTTPS 探测 + 证书 SAN 校验**（避免解析到被劫持的 IP）→ **UAC 提权写入 hosts**（复用 `dsh.js` 导出的 `psExe()`）。
- **标记块必须写在文件最前**：改写范围严格限制在 `MARK_START` / `MARK_END` 之间（上限 64 条），且块要落在**文件最前** —— Windows 是 first-match 语义，写在后面会被其它工具的 `127.0.0.1` 条目抢先命中；块被挤出最前时 `degraded` 报警。**按字节读写**（不解码原文），避免中文注释被按 UTF-8 回写成乱码。
- **多来源 IP + 可追溯**：多个社区 hosts 源共同供表，另备 4 个 `github.com` 已知 IP；每个域名保留所有可达候选做运行期回退。支持手动编辑 IP 表、「检测连接」（不可达但仍是 DNS 当前答案的标 `stale` 黄而不红）、「刷新 IP 表」、「重新写入 hosts」，另有操作日志（50 条）与来源追踪表。
- **不走 IPC**：GitHub 加速与邮件通知的能力都通过 `window.services` 暴露（同 `dsh` / 备份），设置页侧未为它们新增 IPC 通道。

**新功能 · 提醒与通知**

- **今日预算提醒**：可设每日预算金额，当天用量超出时弹一次提醒气泡 + 第三行常驻「超预算 ¥x」，并**每天弹一次系统通知**。气泡与通知互不依赖（气泡可能正被计时 / 峰谷提醒占用）。
- **低余额预警升级为完整提醒**：余额低于阈值时除了数字变红，还会弹一次提醒气泡 + **每天弹一次系统通知**。与「今日预算提醒」各自独立；两者同时命中时以低余额为准（更紧急）。
- **余额大幅波动通知**：可设下降阈值（默认 5 元），单次采样余额下降 ≥ 阈值就弹系统通知。**不做「每天一次」去重**（基准随采样更新），只受免打扰约束。
- **提醒停留时长**：峰谷切换 / 今日预算 / 低余额 / 穿透说明这几类提醒气泡可选**常驻 / 5 / 8 / 15 秒**（默认 8 秒）。**注意**：计时到点气泡由挂件菜单「到点通知」旁的档位单独控制，两者互不影响。
- **免打扰时段**：可设起止时刻（**支持跨午夜**如 `23:00–07:00`），时段内「今日预算」「低余额」「余额波动」三类自动通知都不弹系统通知（前两类的气泡照常），且**不占用当天名额**（出时段后仍会补发一次）。
- **提醒文案可编辑**：低余额 / 今日预算 / 峰谷切换 / 鼠标穿透四类提醒的**气泡与系统通知共用同一份模板**，六条（峰谷与穿透**按状态各分两条**）都能改。气泡只有三行，模板**按行映射**：第 1 行标题 / 第 2 行大字 / 第 3 行说明，**超过三行并入说明行**；系统通知取全文并把换行合并成空格。占位符 `{balance}` `{threshold}` `{used}` `{budget}` `{over}` `{schedule}`，**未提供的原样保留**（能一眼看出写错）；**空模板 = 恢复内置默认**。多厂商模型的余额通知与余额大幅波动通知**有意保持写死**。

**新功能 · 素材与形象**

- **素材集中管理（独立「资源」Tab）**：形象 + **六段音效**（音色两段 + 四类提醒音）导入素材的**集中管理入口**，四张卡 —— 「资源概览」、「导入的形象」、「导入的音效」、「内置资源」（可预览 / 试听、**不可删**）。此前这些按钮藏在 `skin === 'custom'` / `soundSet === 'custom'` 的条件里，一旦切回内置形象 / 音色，素材在界面上就「消失」（磁盘上还占着），既看不到也删不掉；现在这块**不做任何门控**。每项显示文件名 + `体积 · 导入时间`。清除分两档：**「清除未使用（n）」**按「当前设置会不会用到」挑出未使用项，**先快照再逐个删，正在使用的一律保留**；**「清除全部素材」**逐个删，全清后把形象回退默认、音色回退「小黄鸭」。两者都**只删素材、不动其它设置**。
- **素材包（导出 / 导入）**：把导入的形象与音效打包成**一个 `.whaleassets` 文件**，换机器时一次带走。导入是**两段式**（与「备份与恢复」同一套）：先解析并列出条目让用户勾选，确认后才真正写入。写入语义：**形象是「补充」**（每张生成新 id 进画廊，不动已有画廊）、**音效是「同槽位覆盖」**（换格式不留旧文件）。**素材包不落任何存储键、不新增配置项**。
- **挂件形象切换**：**13 张内置形象**（默认 `DSniang1`；形象 id 即 `public/whale/` 下的图片文件名） / **自定义**（png / jpg / jpeg / webp / gif / apng、≤5MB，不收 SVG）。图片**复制**进插件数据目录，推送时读成 base64 data URL（挂件页面加载不了插件包外的 `file://`）；导入后自动切到这张，删除后若正用「自定义」自动回退默认形象。
- **自定义形象升级为画廊**：由「只存一张」改为**多张（最多 20）**。界面是**缩略图网格**：点缩略图即切换、「置顶」挪到第一位、「删」删掉该张（删的是当前那张时顺延到剩余第一张），当前那张带「使用中」角标。老数据**就地归一化**，不做数据迁移。**GIF / APNG 走原样复制**以保住动画，静态图走裁剪层。
- **形象裁剪**：两段式（选文件不落盘 → 裁剪层 → 确认才写入；**GIF / APNG 绕过裁剪层**）。裁剪层支持 8 手柄拖拽缩放、框内平移、框外压暗，一键**「自动裁掉透明边」**，导出**保留透明通道**。
- **音效试听与裁剪**：已导入的按压 / 释放音可点「试听」；导入改为「选文件 → 弹波形裁剪层 → 确认落盘」两段式。裁剪层用 canvas 画峰值波形，拖手柄选段（上限 10 秒，下限防长音频里手柄叠死），可试听选区，确认后导出 **16-bit PCM WAV**。
- **音效槽位由两段扩到六段**：新增**「提醒音效」分组**，低余额 / 今日预算 / 峰谷切换 / 鼠标穿透四类提醒各可导一段，合成六个槽位。与音色的关键差别：**四段提醒音没有内置回落，留空即静音**；播放只看全局「音效开关 + 音量」，**不受「音色」下拉影响**。
- **音效槽位升级为音效组**：每个槽位由「一段」改为「一个数组」，同一槽位可导多段、挂件每次**随机播一条且不连续重复同一条**，删到只剩一段就固定播它。老结构**就地升级成单元素数组**、不主动写回存储。
- **自定义气泡图**：最多 8 张。点小鲸鱼抽到「气泡图」那组台词时从图里**随机显示一张**，删光回退内置 `rua.gif`。与形象的四处**有意不同**：① **不裁剪、不重编码**（过一次 canvas 就把动画帧丢了）；② **没有「当前用哪张」**（有图就随机抽，网格里没有「使用中」角标与「置顶」）；③ 因此**不参与「清除未使用」统计**，只能靠「清除全部素材」删；④ 推送总量有预算（超出即跳过）。
- **气泡配色主题**：默认（蓝白）/ 深色 / 樱花。只重写 CSS 变量、**不重建 DOM**；「低余额」红色是状态色，不随主题变。换形象后**命中测试画布会按新图重建**（透明区穿透判定跟随新轮廓）。
- 「数据与隐私 → 清除选中数据」新增独立的**自定义形象**项：删图片与元信息并把空形象推给挂件；若形象正为「自定义」且未同时清「挂件设置」，会顺带**回退为默认形象**并广播给挂件。

- **低余额阈值**的默认值来源统一（内置 DeepSeek 与多厂商模型走同一份：人民币 10 / 美元 2）；阈值单位**跟随账本币种**显示「元 / 美元」。
- **自定义单价支持按模型覆盖**：按模型名**子串**匹配，只填三个单价。取价改为**三级顺序**：按模型覆盖 → 全局覆盖 → 内置价目表。
- **更新检查改为默认关闭**：原先默认开启，装完插件什么都不配、第一次呼出就会向第三方 GitHub 加速代理发一次请求。请求本身不含任何用户数据，但仍是「零配置状态下就有外发」，公开分发按隐私优先处理 —— 用户主动勾选才联网。
- **设置页结构整理**：原先 12 张卡片竖排一屏到底，找一项要滚很久。现按主题分 **7 个顶部 Tab**（外观 / 资源 / 用量 / 窗口 / 数据 / 帮助 / 开发者），Tab 条吸顶。同时按主题合并 / 拆分卡片：「台词库」+「提醒文案」合并为「文案」；「挂件行为」拆开 —— 用量口径并入「用量与账本」，其余归入新的「提醒与通知」。**纯前端结构调整，配置项与存储键一个没动**。
- 气泡三行字号整体上调约 9%，可用区域没动：长文案照旧自动等比缩小兜住，所以**既不会撑出气泡，气泡也不用跟着变大**。
- 随机台词改为**不连续重复**：同一句撞上就**在其余条目里等概率重抽**（不是简单取相邻那条）。组内只有 1 条时无从避免。
- 把散在 **3 处**的「今日已用 ¥x」措辞收进同一个函数（常驻主显示 / 峰谷组台词 / 多厂商模型的说明行），以后改文案只改一处。

**修复**

- 修复**挂件贴在屏幕上边时三点菜单看不见**：菜单原先固定往按钮**上方**展开，而窗口留白只有上 / 左单侧，挂件吸附到屏幕顶部后菜单上半截落在屏幕外。现改为**窗口四周各留透明留白、挂件本体在窗口内居中**，页面据此算出上 / 下**真正可见**的高度：上方装不下且下方更宽就改向按钮**下方**展开，高度不足时压 `max-height` 在菜单内滚动。
- 三点菜单的开关顺手做了几处修正：关菜单那一下**立即重算**鼠标穿透与菜单按钮显隐（原先要等下一次 `pointermove`，导致这一下点击被窗口吞掉）；点**鲸鱼本体**关菜单时这一下照常当点击 / 拖拽用；菜单开着时滚轮缩放挂件会**重新贴回按钮**；重开菜单**回到顶部**。
- 修复**峰谷组气泡的说明行太小**（挂件缩得越小越明显）：三行字号共用**同一个**缩放系数，而第 3 行是三行里唯一不换行的长行，按它算出的系数会把第 2 行的大字金额一起压小（最大尺寸下实测由 114u 压到约 61u）。现允许第 3 行折成两行并抬高说明行档位，625px 实测渲染字号由 **23.6 / 37.4 / 20.3px** 变为 **43.9 / 69.4 / 43.9px**。
- 修复**常驻主显示的说明行太小**（同一机制漏掉的另一条路径）：上一条只让**气泡台词**换行，**常驻主显示**走的是另一段代码、**从不带折行类名**，于是「今日已用 ¥x · 超预算 ¥y」与「已用 x% · M-D HH:MM 重置」仍按不换行撑宽、把三行一起压小（缩放系数仅 0.518 / 0.630）。现默认允许折行，两者回到 **0.973 / 1**；常规文案本来就不满一行宽，不受影响、也不会折行。
- 修正 **Flash 定价偏高 50%**：内置价目表原先每项都正好是正确值的 1.5 倍，导致「实时·令牌」模式算出的今日已用**偏高 50%**。同时补上当前模型名，并让取价在价目表未收录时**留一条日志**，便于官方上新 / 改名后及时发现。
- 修复**多厂商模型的 DeepSeek 模板可能取到美元余额**：该字段会同时给多种币种且**顺序不固定**，按下标取可能拿到美元那条，金额取错不报错、只把钱显示错。现改为**按币种挑条目**；条件不匹配时提示「字段取不到数值」，比静默取错币种好。

**构建与测试**

- 新增**构建期副本一致性校验**（挂在 `prebuild` 上）：同一份常量在宿主 / 设置页 / 浮动页 / 样式表里各有一份副本，这些副本消不掉（preload 不参与打包、浮动页没有 `require`、CSS 变量宿主读不到），改一处忘另一处只会静默不一致。脚本逐对比对，不一致直接让构建失败。**已知盲区**：音效六个槽位比不了，加槽位要手动核对两处。
- 新增**单元测试**（`npm test`，Node 内置 `node --test`，零依赖）：覆盖四组纯函数 —— 峰谷判定与模型定价、取余额的多币种挑选与字段路径解析、配置归一化、凭据加解密。前三组被用来算今日用量，**算错不报错、只会把钱算错**；第四组是**备份打开的唯一保障**。单测从 7 个扩到 **23 个**。
- 新增 **ESLint 静态检查**（`npm run lint`）：只为发现真问题（未定义 / 未使用变量、重复键、不可达代码、Vue 模板里的错误用法），**不含缩进 / 引号这类格式规则**。首次接入即清掉 5 处真问题（多余参数、无人调用的函数、只赋值不使用的变量等）。
- 新增**持续集成**：push 到 `main`、任何 PR、手动触发时，依次跑 `lint` → `typecheck` → `test` → `build`（Node 24 + `npm ci`）。**刻意只调用本地已有的 npm script、不额外引入工具链** —— 保证「本地能过」与「CI 能过」是同一件事。产物 `dist/` 不上传、不发布。
- 新增**发版自动化**：打 `v*` tag 时自动**校验 tag 与 `package.json` 版本一致**（不一致直接失败）→ 跑与 CI **同一套**检查 → 把 `dist/` 打成 zip 并建 Release。**边界**：uTools 市场的发布仍需人工打包 `.upx` 上传；README 的「版本记录」仍是人工整理的对外口径。
